# 心愿页互动小物架

日期：2026-10-28。

产品只使用祈福 `blessing` 和祈愿 `wish` 两类，目录与场景运行时分类保持一致。感谢、自省、礼敬、庆祝等只保留为具体内容表达，统一归入祈福；不再叠加第二套用途类型。心愿页只展示已收下且属于祈愿目录 `WISH_SCENE_IDS` 的小物，包括已经使用过的许愿物品。祈福类的陶牛、门松、千岁糖、风铃，以及原有感谢／自省场景留在原收藏页，不进入心愿页顶部。能否输入文字仍是独立权限：微屋、林村和三石虽不开放新的写愿输入，仍属祈愿类，可以保留陈列。

顶部、未用小物的许愿／还愿入口和新建愿望的免费场景入口复用同一分类判断；旧收藏的 `wishScene` 标记不能把祈福类物品重新带入。原始收藏、心愿和来源记录不删除。旧待处理草稿仍可从原独立接续入口保存／放弃，不因筛选而丢失文字。每份收藏独立保留，「待处理草稿、未用、已用」祈愿物品保持原排序，不作为写愿小物的祈愿收藏显示「已完成」并仅打开收藏详情，不计入未用许愿物品。横向只有一排，常规字号下显示约三件，其余通过触屏滑动、鼠标拖动、方向按钮或键盘左右键浏览；大字号下允许两件，优先保证名称可读。

小物使用现有场景的完成检查点和模型，作为只读展示，隐藏场景操作层与装饰环境。纸鹤点按时局部轻扇双翼，风铃的铃身、铃舌及纸条受控摆动；其他小物采用按结构选择的摇摆、轻飘、回正、下沉或明暗反馈，并配上纸、玻璃铃感、木、空壳、布等不同的轻柔合成音。连续点按有界重启，静音、震动及减少动态效果遵守应用设置。滑动不触发反馈，也不消耗收藏、保存心愿或跳转。名称和状态所在的独立按钮继续执行原来的进入仪式／查看收藏动作，旧草稿按原流程继续。

视觉沿用[正式小岛规范](island-shell.md)：薄荷波点背景、暖棕文字、圆体、木色搁板、软白边与原有四色底栏。局部使用 `--ink #4a2a12`、`--sand #fbf3dc`、`--rim #fffdf7`、`--butter #ffd966` 及现有圆体字体栈；不重做页面主题。每件小物放在木板上，作为这一小块的识别元素。

实现选择：原来的图标挂件无法显示完成后的实际物品；预先生成静态图片需要另行维护每种场景及变化；因此复用实际场景模型并只为可见位置创建渲染器，离屏、后台或离开页面时释放。WebGL 不可用或初始化失败时显示原有场景图标，反馈与名称入口仍可用。没有新增资源包、存档字段或场景仪式动作。
