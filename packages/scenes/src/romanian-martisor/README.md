## 当前拿近查看（2026-10-29）

首次点按物件、拖动后松手或点「拿近看看」，整体抬起绳环与红白双流苏，约 0.65 秒靠近。镜头默认用约 6 秒环绕一周，再用约 0.5 秒回到原安放视角；可点「继续安放」提前返回。单指拖动或方向键可随时接管，接管后停止自动绕看，准备好后自行继续。减少动态时直接进入稳定近景，不自动环绕，仍能手动转看或继续。

查看后将绳环送到开花树枝的承托范围，让枝面承托绳环、流苏垂下。 查看阶段不接纳安放输入，不保存进度或报告完成。界面呈现查看、安放两个动作点；旧 0／1／2 从原保存姿态开始查看，旧完成值 3 与最终接触条件保留，已完成状态不重播。取消、失焦、暂停或尺寸变化恢复未提交查看的相机、物件与环境；销毁时完整清理。

红白纤维春绳带两只流苏，佩戴结束后挂上开花果枝。对应罗马尼亚 Mărțișor 习俗中的片段；佩戴寄托健康与好运的信念有博物馆正文依据，不能解释为本应用带来健康。

1. 拿住红流苏，跟手提到树下春绳的抬起提示位置。
2. 跟手移到花枝自由端的提示位置，让开放中心的绳环套入。
3. 跟手放低到当前落区，绳环由枝面承托，流苏垂下。

纤维双股网格、无底板绳环、树枝与两流苏均为原创几何。枝轴z、中心(.55,1.5)、半径.055，绳环上内缘距中心.208，最终环心y1.347；动作沿自由端进入后轻放。固定环形与可见收束结、树下起点、套入方法、三段方向、花形与色彩、辅助按钮和反馈是产品简化，不是传统步骤或统一次数。无固定佩戴期限、愿望输入或收益/疗效承诺。不要将单独的三次拖动登记为已证实仪式程序。
