## 当前拿近查看与悬挂后把玩（2026-11-05）

首次点按物件、拖动后松手或点「拿近看看」，整体抬起护眼珠及完整金属挂环，约 0.65 秒靠近。镜头默认用约 6 秒环绕一周后停留，不计时自动返回；准备好后点「继续安放」，约 0.5 秒回到原安放视角。单指拖动或方向键可随时接管，接管后停止自动绕看。减少动态时直接进入稳定近景，不自动环绕，仍能手动转看或继续。

查看后把完整挂件送到木架横轴，让挂环落轴悬稳。 查看阶段不接纳安放输入，不保存进度或报告完成。悬稳只保存检查点 2，继续点按轻拨、拖动微调朝向，或用「轻拨挂件」按钮与方向键把玩；可反复操作，准备好后明确点「结束欣赏」才保存 3 并报告完成。轻摆与转动始终围绕木架横轴上缘 (.37, 1.8155, .42)，不会把挂件从支撑处移走。

旧 0／1 保留原姿态并从查看开始；旧部分进度 2 迁移为已悬好、可继续把玩，旧完成值 3 静默恢复，不再奖励或回调。悬挂到把玩的同一手势尾部、按钮双击及宿主回调重入不能直接结束。取消、多指干扰、失焦、暂停或尺寸变化撤回未提交调整；减少动态保留直接转向与轻拨反馈，关闭惯性摆动。查看时不运行悬挂姿态更新；销毁清理全部监听和资源。
