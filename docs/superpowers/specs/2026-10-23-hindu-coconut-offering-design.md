# 椰果献愿设计

本轮只实现 hindu-coconut-offering，完成后停止。延续用户自主选题要求及既有 Three.js 流程。独立工作区基线 0bbdb141 包含 master 与20项已验收场景；保留主目录未提交内容，只做本地提交。

拟呈现去除纤维外皮的褐色硬壳椰果，上托、右移、下击石面，裂成两半露出白瓤和少量椰水。浅盘围住击石台面。一个可辨椰果为主体，不增加神像、咒语或主持角色。根代理与研究代理均已实际读 Plano 寺庙及 Kauai 修道院相关正文，使用新专卡 hindu-coconut-offering。保留供献神祇、象头神祝福与新开端语境；三段操作、次数、分半方式、承托、动画是产品设计。

## 方案

实现者选择破椰短片段。只放完整椰果会缺少来源明确的破椰动作；完整 puja 会引入无证礼序及新器物。复用既有对象手势、键盘和宿主风格。褐壳 #775039、纤维 #9a714a、白瓤 #f0e9d2、蓝灰石 #71858b、水 #8ebac1；沿用宿主字体与工具栏。

## 验收

验证真实物件命中、方向、长拖、取消、暂停、回调重入、静默恢复、减少动态、键盘、资源释放、壳厚与凹面、接触和裂开连续性。同步目录/叙事/意图/引擎/来源/场景池/原生封面。检查320、390、1280宽实际界面、鼠标与模拟触摸、生产和离线构建。独立复核后只本地提交，不合并推送或恢复自动化。
