# 木版留春

## 2026-10-19 来源核查修正

以木版、墨、纸与棕擦的手工转印关系为依据，制作原创枝叶图案的当代工艺欣赏场景。不是经书印制、族谱复制或宗教仪式；不复刻馆藏作品，也不对心愿作灵验承诺。文化来源采用雕版刷印专卡。C / 低是本应用的设计分级。

## 动作

1. 从左侧木柄拿起棕擦，移到纸背，左右刷过后松手。需要至少 0.75 世界单位的纸面接触行程和 0.45 单位横向跨度；直接放下工具、无移动或在纸外挥动均不计入。
2. 捏住右下方的真实纸角，向屏幕上方拉动至少 42 px 后松手。纸张绕压住的后缘抬起并略微弯曲，显露纸背原先朝下的墨印。
3. 轻点印纸静看，或明确提交 1–40 字的心愿。草稿、恢复进度及还愿回访不会另存心愿。键盘可依次使用原生辅助按钮完成同等步骤。

木版有独立的木质厚度、挖刻刀痕和上墨枝叶浮雕；印纸有上下表面、弯曲边缘及随纸变形的印纹。棕擦底部的棕纤维与木柄是可见实体。交互射线检查最近的可见不透明网格，不穿过其他物体命中。环境保持透明，廊台由宿主提供。
