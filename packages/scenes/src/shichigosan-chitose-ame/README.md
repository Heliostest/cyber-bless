# 千岁赠糖

ID与来源slug：`shichigosan-chitose-ame`；引擎 `@1`。

七五三成长庆贺中的家长赠糖片段：将装有红白千岁饴的纸袋提起、递近眼前孩子、放低让孩子接稳，送上健康成长与长寿祝愿。三短拖、两支数量、轨迹、纸袋花纹与衣着均为产品设计；没有演出参拜、祈祷、祓除和吃糖，不称完整仪式。

实际操作为提手向上、向右、向下短拖。按住时预览当步位移，合格释放后完成运动；最后一步等孩子双手接触提手才记录完成。真实袋内底面承托包装糖，提手接于袋面，最终双手接稳。错误方向、长拖、回折、空白起手和取消不提交，键盘提供等价入口，恢复与减少动画采用同一检查点。
