# 还愿只记录小善事

用户要求：还愿不再使用仪式。

还愿页保留「做一件小善事」、简短说明、善事文字记录和如愿纪念章，移除方式选择、仪式完成条件和小物入口。新提交统一记录为 `kindness`，旧未完成心愿及草稿中的 `ritual` 不阻挡提交，保留原草稿文字。心愿详情对未完成记录提示小善事。

旧存档继续接受 `ritual`；已完成的历史记录、笔记、会话、小物与纪念章不改写。旧会话可收尾，完成出口改为查看心愿，不再引导把仪式作为还愿步骤。

唯一实施方向是精简现有表单并保留历史读兼容；仅隐藏选项仍会让旧值阻挡提交，删除旧数据字段则会损失真实历史。复用既有八语言文案与布局，不新增依赖、不改存档版本、不修改场景真实文化背景。
