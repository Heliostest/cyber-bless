## 当前间距：48 CSS 像素

按用户追加要求，云带整体再上移 24 CSS 像素。层间偏移、色阶、柔边和透明度保持，六层上沿现在为 48、64、81、99、118、138 像素；场景相机、前景遮挡和适用范围不修改。这是同一产品背景的布局参数调整，文化影响沿用本记录，不新增文化主张或外部来源读取记录。

先让新的 48 像素行为断言在旧 72 像素代码上失败，再调整参数。最终真实 WebGL 的 24 组尺寸/DPR/时间实测为 48～48.5 CSS 像素，18 个独立层样本的间距、色阶、柔边及辅助深度回归通过。最新证据为 `artifacts/toon-cloud/inset48-*.log` 与 `inset48/`；旧全场景评估表对应 72 像素版本，不将旧统计冒作新间距的全量复测。

本轮 239 项环境测试、应用构建及 158 场修订指纹检查通过。门柱、签纸和风铃的实际浏览器预览无页面/控制台错误，三个挂载退出均释放七个云资源；前后图为 `artifacts/toon-cloud/inset48-comparison.png`。首轮截图受并行构建的开发热更新打断，屏蔽审计页 HMR 后完整复测通过，未改动生产生命周期。

## 首次布局：72 CSS 像素（历史）

- 固定距**场景画布顶部 72 CSS 像素**；不是整个 App 窗口，也不是设备物理像素。初稿 96 像素在纸鹤等窄天空镜头仍偏低，实际查看后收紧为 72。
- 六层云使用视口空间绘制，保持原相机和前景布局。取 `renderer.getSize()` 的逻辑尺寸，避免 DPR、FOV、相机俯仰和横竖比例改变间距。
- CPU 根据当前可见宽度、云相位、圆盘轮廓及柔边计算最外侧上沿，不只锚定平面的中心。固定 CSS 图案尺度，压缩层间垂直间隔；可见最高点随漂移保持在同一上沿，蓝天仍有留白。
- 普通深度测试继续让草地、器物和其他前景遮挡云。72 像素测量的是云层自身的上沿；木梁等前景遮住最高点时仍保留遮挡，不强行覆盖前景造出边缘。辅助深度/描边通道可能替换顶点 shader，因此平面仍保留远处的世界坐标代理，防止它们在原点成为遮挡主体的方块。
- 缓存按逻辑宽高和云时间失效，每帧只计算一次；预览不推进时间，尺寸变化不重建几何或材质。暂停、减少动态、独立挂载和幂等销毁保持原有机制。

- 新布局的渲染尺寸适配、零尺寸和资源释放用例先 RED（2 项失败），随后通过；`@wbr/scene-runtime` 全套 15 文件、239 项通过。
- 可重复执行的真实 WebGL 检查：`node scripts/verify-toon-cloud-viewport.mjs`（先启动开发服务器，可通过 `WBR_URL` 指定地址）。24 组逻辑尺寸/DPR/时间：284×320、350×480、768×400、1280×600，DPR 1/2，时间 0/17.5/120 秒。读取实际渲染 alpha，最高可见边缘为 **72～72.5 CSS 像素**；大幅改变相机位置、俯仰和 FOV 后 alpha 逐字节一致。
