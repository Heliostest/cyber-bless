# App 仪式视觉风格：接入评估与交付

用户要求将 Shader Lab 的风格能力接入正式 App，在仪式音效、震动旁提供入口，并确认按仪式分别保存。开发面板继续保留。该改动不修改当前默认风格，也不改变场景目录开放范围。

## 接入判断

正式入口放在共享 `packages/app`，由 `FeedbackControls` 提供“视觉风格”图标。按用户后续调整，三个图标收进紧凑的 Animal Island UI pill：奶油色底、粗白边、薄荷底托，单个按钮为 36×44px。Web 与原生 `'use dom' BlessingDom` 均使用同一个实现。只在当前仪式存在匹配 App 作用域的渲染器时显示；加载中、纯 2D 后备、渲染器已销毁时不提供无效入口。标题按页面中心对齐并为两侧对称留空，保持原来的音效、震动开关语义。

菜单使用 App 的暖纸色、薄荷选中态与底部布局，提供八种已有风格。“微调效果”折起风格列表，显示对应滑杆；“看画面”收为底栏，“继续调整”返回原位置，始终预览同一画布。选择不重建引擎、相机或仪式进度。新用户跟随内容默认，当前为柔和卡通；“恢复默认”只清除这一仪式的视觉偏好。

菜单背景阻挡交互，打开时通过既有 pause/resume 清除未完成手势，木鱼包装层也清除按压所有权与后续 click。然后恢复同一实例，使画面仍可实时更新。关闭、遮罩、Escape、完成和 Android 返回都能退出；返回先消费菜单，再允许正常页面返回。焦点限制在菜单内，退出还给入口；安全区、滚动边界与短屏均单独检查。多个 App 实例的 renderer、偏好、菜单预览、输入取消和返回事件以各自 `.app-shell` 为作用域，互不串用。

## 保存与运行时

- `packages/core/src/visual-style.ts` 集中维护已知风格、参数初值／范围／步进及校验。先前 runtime 参数模块保留转导出，开发面板与 App 共用一套定义。
- `State.visualStyles?` 按稳定仪式 ID 保存 `{ style, parameters }`，通过 `scene.visual` 动作进入原有主机保存队列。兼容目录允许的大小写、点、下划线、`@` 与连字符 ID，不接收远端代码。
- Web 仍使用个人存档键，原生仍经 Promise bridge 写 AsyncStorage，不将开发 localStorage 冒充 App 持久化。schema 仍为 v1；旧存档没有该可选字段时保持默认，损坏的视觉条目单独丢弃／校正，不阻止心愿和进度读取。
- 选择风格立即提交；滑杆即时更新既有渲染资源，180ms 合并持久化。菜单关闭、卸载、隐藏、pagehide 和原生 `active=false` 时提交最后数值；visibility capture 先于 App 的保存队列 flush 执行。保存错误沿用现有重试入口。
- 正式偏好不依赖 debug enable，不导入开发覆盖。开发覆盖仍有优先级，正式编辑明确清除当前仪式的调试项；清除调试项回到已保存的用户选择。
- 临时菜单预览有独立 owner，退出释放，场景卸载移除正式 owner。风格失败沿用原始光照回退，菜单反映实际效果。没有新增 canvas、WebGL context、常驻循环、远端 shader、资源下载或原生权限。

只提供用户可逆的整体显示偏好，未改器物、材质身份、纹样、动作、完成条件、标题、介绍、寓意、来源绑定或技术 ID。不将滤镜名描述为当地传统。沿用 [2026-10-19 全场景核查](2026-10-19-scene-culture-audit.md)及 [Moebius](2026-10-22-moebius-rendering.md)、[卡通描边](2026-10-22-toon-outline-rendering.md)、[网点与像素](2026-10-22-halftone-pixel-rendering.md)记录；本轮没有重新访问文化来源，没有新增文化事实。

正式 App 仍按既有规则开放 64 个场景；茶具等开发检查场景未因此重新上架。正式入口验证选择当前可见的彩陶公鸡与纸鹤，开发检查页仍可检查茶具等其余场景。相关 README 与共享调试／移动文档同步；来源卡、宿主目录、注册表、metadata、原生标题与存档技术 ID 无需改变。

- 生产 Web 构建通过。`scripts/test-app-visual-style.mjs` 从生产 App 的“小天地 → 回看仪式”进入，逐项切换八种风格，确认未回退、画布不替换、进度不改变；参数刷新恢复、跨仪式隔离、恢复默认、离线继续操作通过。检查 320×568、390×844、844×390 和 1280×900，菜单均在视口内，无页面／控制台错误。截图及报告在 `artifacts/app-visual-style/`。

- 独立审阅发现的跨 App 作用域与后台保存窗口已修复并复审。开发预览与手机真机不同：仍需在真实 iOS／Android 设备验收帧率、发热、系统返回键及安全区；没有发布云构建或商店版本。
