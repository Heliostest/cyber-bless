# 竹音轻摇

以印度尼西亚公开竹乐器 Angklung 为背景的原创当代互动场景。竹架、两根不同长度的空腔竹管、上部开槽、竹节、藤绑及下横轨均由程序生成。`indonesian-angklung` 是独立公开工艺卡，C / 低是产品设计分级。此场景不归入 Sunda Wiwitan 信仰卡，不展示宗教仪式，不声称教授完整制琴、调音或演奏技艺，也不保存心愿。

主体直接置于宿主的阳光廊台环境，不使用小桌或倾斜展示板。竹管有实际厚壁空腔和朝前开槽，上部保留后侧竹舌；下部竹脚落在横轨之间的承托面，绕竹脚中心轻摆。四根藤绑的一端连接横梁表面，另一端连接竹管上部表面，拖动和回稳时复用顶点与法线缓冲更新曲线，不创建新的 GPU 几何。

## 动作与恢复

1. 按住竹架、横柄或任意竹管，可自由来回或斜向摇动。
2. 有效移动时发出同一音色的短音及轻／中等震动；可以连续摇、松手后再摇，也可使用键盘辅助「轻摇一下」。
3. 首次有效发声后出现「结束仪式」按钮，用它手动完成，摇动次数与回稳时间不会自动结束。

不再要求固定方向、42px 手势或等待回稳。横向位移最多 .28、纵向最多 .20 场景单位，竹管滞后轻摆，松手后以小步长阻尼弹簧回到居中。减少动态将手持幅度缩为四分之一，松手归零。旧检查点 0–3 均居中静默恢复：0 未演奏，1／2 可继续自由摇动，3 已结束。首次有效节奏上报 2 一次；后续摇动不重复写进度，按钮才上报 3 与完成事件。

本物体使用同一个原创轻柔合成音：392 Hz 基频与低音量的 784 Hz 八度泛音，持续 .12 秒、增益 .003–.006。有效移动而非松手触发短音与震动，速度决定轻重；静止、轻微抖动、越过位移边界后的继续拖动和被动回稳不产生新节奏。单段有效位移至少 16px、反馈最小间隔 110ms，反向后重新累计净位移。宿主实时声音与震动开关生效，没有复制录音或传统曲目。这是产品节奏反馈，不模拟准确调音或真实竹管共振。

## 真实表面与自动化锚点

| 检查点 | 网格名称 | 局部表面锚点 | 屏幕动作 |
| --- | --- | --- | --- |
| 0–2 | `angklung-frame-grip` | `[0, 0, 0.10]` | 任意方向连续拖动 |
| 0–2 | `angklung-tube-long-body` / `angklung-tube-short-body` | `[0, 0.7, 0.19]` | 任意方向连续拖动 |
| 已摇动后 | 原生「结束体验」按钮 | — | 点击／Enter／Space |

锚点经网格的 `localToWorld` 后投影，横柄提示仅为引导。任何最前命中的真实竹架子网格均能开始摇动，空白与外部不透明遮挡不能穿透抓取，无隐形命中板。多指、非有限坐标、取消及捕获丢失中止当前抓取；已响过的节奏不撤销，也不会因此完成体验。

原生辅助按钮最小 44×44 px，可反复产生一次轻摇；独立结束按钮展示完整标签。持有或多指时两按钮禁用。暂停／失焦取消未结束的抓取、冻结已释放的余摆；恢复后可以继续。同步宿主反馈回调不能注入输入、越过完成守卫，销毁后不再发声、渲染或报告完成。

稳定组名为 `angklung-world`、`angklung-subject`、`angklung-frame`、`angklung-tube-long`、`angklung-tube-short`。藤绑网格为 `angklung-lashing-{long|short}-{front|back}`；两端节点分别为 `angklung-suspension-{long|short}-frame-{front|back}` 与 `angklung-suspension-{long|short}-tube-{front|back}`。竹脚与承托中心为 `angklung-foot-{long|short}` 与 `angklung-socket-{long|short}`。
