# 镜饼迎岁

来源：日本正月迎接年神时的镜饼供物。两层圆饼相叠、顶放橙（だいだい），寄托家族代代兴盛的祝愿。见[专卡](../../../../content/traditions/kagami-mochi-offering.md)与[逐项核查](../../../../docs/research/2026-10-19-kagami-mochi-offering.md)，两条农林水产省相关正文已实际读，失败PDF未引用为证据。

呈现准备供物的片段：向上短拖大圆饼至纸面中央、小圆饼叠上、橙置顶。预备食品、三步短拖、轨迹、尺寸、配色和低木纸面支撑是产品简化，无完整祭祀、固定日期或应验宣称，不挪用镜开食用求健康。BLESSING场景，无许愿框。

物件射线只接受当前可见实体，遮挡、反向、短拖、横移、回撤、取消及跨指针输入不推进。松手后完成落座才记录一步；暂停冻结，恢复精确，还原检查点不发反馈。支持44px键盘按钮、减少动画、音效开关与资源清理。场景与模型测试覆盖这些行为和实际承托关系；来源与视觉另行独立审查。
