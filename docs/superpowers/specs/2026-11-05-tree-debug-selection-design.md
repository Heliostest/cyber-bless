# 调试台树木选择

用户选择同时接入 Quaternius Stylized Nature MegaKit 和 Just a simple tree，在现有调试台切换。复用真实场景、相机、交互与布局，保留原有树木作为默认与恢复项。选择只存在本次调试会话，折叠面板保留，卸载调试台恢复。

采用两套离线、固定版本、保留授权的 GLB 资产，各两种阔叶变体；共享环境按原有位置和高度实例化。Quaternius 使用免费 Standard 实物模型，Just 使用 MIT 源生成器离线生成，保留叶卡、簇法线与 AO。不引入现代编辑器的整套 WebGPU 依赖。相比运行时嵌入两种编辑器，这条路线更适合当前 Three 0.170/WebGL 和离线移动包；单纯替换材质不能满足树形变化。

只切换共享环境中的背景树。菩提树、许愿树等场景主题器物、动作及文化来源不变；不将通用阔叶模型当作特定文化树种。日夜共享环境均支持，没有环境树的场景显示无可切换项。

异步加载时保留当前画面，成功再替换；失败显示状态并保留原有树。取消、快速切换和退出后到达的资源必须释放，不能覆盖较新选择。材质保留 alpha-mask 与源法线，重复树实例化，风遵循暂停／减少动态效果。正式默认、正式存档不变。两套资源和许可证同步进入 Web/Expo 离线目录。

验证包含调试作用域与恢复、同一画布切换、失败／过期加载、alpha-mask 与实例变换、释放资源、离线打包、真实 WebGL 日夜截图和相关回归。
