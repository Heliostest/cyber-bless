# 葫芦刻光

原创干葫芦、叶片和山丘纹样。参考秘鲁公开刻葫芦工艺，以曲面刻线、轻拭、静看组成三步互动。

- 场景：`peruvian-engraved-gourd`；来源卡：`content/traditions/peruvian-mate-burilado.md`。
- 向右轻拖壳面刻出细纹，向下轻拭显出纹理，轻点静看或明确提交个人心愿。
- 仅保留承托葫芦的软垫圈；使用明亮日光和柔和卡通渲染。
- 支持物体手势、键盘辅助动作、减少动态效果、暂停取消与进度恢复。
- 几何、纹理和动作由程序原创。刻纹及擦拭是视觉化的工艺缩略，不是完整雕刻教程。

模块测试使用真实 Three.js 几何、投射和材质，仅替代 WebGL 硬件接口。跨场景适配器、移动触摸及生产渲染由仓库验收脚本覆盖。
