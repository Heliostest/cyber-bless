# 完成仪式后许愿的小物使用状态

核查日期：2026-11-02。涉及宿主的每日、首次开场与可选心愿保存流程；用户反馈场景为 `tanzaku-tanabata`（短册系竹）。

## 问题与修复范围

心愿架按每个收藏副本的 `spentAt` 显示「未用／已用」。从收藏小物进入仪式时已有消费动作，但每日仪式结束后直接保存可选心愿只创建了心愿，没有更新刚获得的小物。开场第三场还会先保存心愿、后创建小物，存在同样遗漏。

- 新心愿可选保存 `sourceCollectibleId`，指向本次确切的收藏副本。已有小物的使用标记与心愿在同一次 reducer 更新中保存；失败时不会留下部分消费。
- 开场第三场使用尚未收下的 `opening:<sceneId>` 精确关联；收下时按该关联标记已用。写愿后、收下前重载会恢复已保存状态，避免重复绑定同一个小物。
- 兼容旧场景先回传文字、再回传完成检查点的顺序，包括同一批回调。
- 无填写、取消填写保留未用；回看、还愿和其他日期的同场景副本不因新愿被顺带消费。不额外写入还愿笔记。
- 新字段可选，保留 version=1 旧存档。旧版本已经出现的不一致没有确切副本关联，不按场景名猜测回填；已有心愿保留。
