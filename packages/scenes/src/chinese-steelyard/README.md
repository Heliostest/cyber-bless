移砣沿杆找平仍是独立操作；之后握提环拿起同一整秤并放回合并为一次连续操作。保持梁、盘、砣和连接绳的既有约束，不提供自由翻转。原位也是终点，须先实际移离再回位，避免原地点击完成；这是产品输入防误触。旧 2 的已提起存档可直接放回。普通离手留位；取消、失焦、暂停和尺寸改变恢复。旧检查点与最终 3 保持。

下方 2026-10-26 及更早的固定分段控制说明为历史实现，以本节为当前操作。路径合并、自由查看、触控容差与辅助按钮均属产品输入安排，不新增传统步骤或功效；原器物、来源事实、技术 ID、引擎与存档格式不变。实际边界与验证见[C 组连续安放审阅](../../../../docs/research/2026-10-28-continuous-placement-audit-c.md)。
