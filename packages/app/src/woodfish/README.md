# 敲一敲木鱼

## 2026-10-27 统一仪式页面结构

木鱼改用与其他仪式相同的 `library-scene-stage`：Three.js 画布与透明输入层只占上方画布区，底部共享托盘显示提示／手势指引、计数、辅助轻敲及达量后的结束按钮。移除场景外的独立计数、提示与结束按钮，以及旧会话的大计数、进度条和反馈面板；旧会话保留暂停与恢复。模型按实际画布尺寸取景，不把托盘算入相机尺寸。共享手势指引不再需要木鱼专属的外置 shelf。

本次为页面结构与布局调整：器物、材质、动作、十二次最低量、持续轻敲、主动结束、来源身份、技术 ID 和存档保持兼容，未新增文化主张。沿用下文 2026-10-20 的介绍核查；验证范围见[本轮记录](../../../../docs/research/2026-10-27-woodfish-shared-layout.md)。

本场景的宿主实现位于 [`woodfish.tsx`](../woodfish.tsx) 与 [`woodfish-scene.ts`](../woodfish-scene.ts)。至少十二次轻敲后显示「结束仪式」，仍可继续敲击；只有主动结束才结算本次体验。旧会话入口同样等待主动结束，随后等木槌落定再进入完成页。此目录仅保存场景说明，不另建引擎模块。

## 2026-10-26 全屏取景修复

窄而高的全屏画布此前只保持固定垂直取景范围，导致木鱼与木槌被横向裁切。现在正交相机同时保留最小水平和垂直范围，随画布比例调整取景；覆盖实际 App 入口及场景检查页。此次仅修复相机取景，器物、材质、敲击动作、完成条件、文字及来源绑定均未变化；文化主张沿用下文 2026-10-20 的介绍核查与对应研究记录，不以渲染验证替代文化证据。

验证：木鱼动作与输入测试 9 项、模型资源检查及生产构建通过；浏览器场景检查页在默认尺寸与 390px 宽度下确认完整取景和敲击计数，320px 宽度下画布保持非零尺寸与 `ready` 状态。未复现完全空白，尚不能将此取景问题视为所有设备空白现象的原因。

## 2026-10-26 移除图片降级

用户确认 iPhone / TestFlight 显示为图片后，移除了木鱼在加载中／失败后的参考 UI 图片、图片弹跳和“轻量模式仍可轻敲”分支。3D 首帧就绪前、模型失败或上下文丢失后均不能记下轻敲；失败显示原因与重试，内置场景和旧会话同样适用。加载器保留具体错误，不再用图片掩盖失败。全场景核查、存档兼容及验证边界见[清理记录](../../../../docs/research/2026-10-26-threejs-only-rituals.md)。器物、材质、敲击与十二次最低量、介绍和文化归属沿用既有核查，无新增文化事实。

## 2026-10-24 持续轻敲

最低十二次、继续操作、结束按钮与计数显示都是产品引导，未改变木鱼与佛教诵唱、警醒象征的文化关联。沿用下文已读器物资料与介绍核查，不将本次技术验证当作新文化证据。宿主不因达到次数就停用，也不在结束前发放小物或还愿记录；技术ID和引擎版本保持不变。共享输入、存档及浏览器验证见[本轮汇总](../../../../docs/research/2026-10-24-scene-interaction-review.md)。

## 2026-10-20 介绍核查

用户介绍经核心目录的 `narrative` 进入“了解这个仪式”，正文在 [`scene-narratives/original.ts`](../../../core/src/scene-narratives/original.ts) 维护。木鱼、木槌与诵唱用途依据 [汉传佛教来源卡的木鱼专段](../../../../content/traditions/chinese-buddhism.md)，该卡其他议题不为本场景提供动作依据。

本次补入中国云南与日本馆藏实例及其年代，保留鱼形警醒的宗教象征；不将实物断代当作起源、不将十二次轻敲当作寺院规则。已读段落、访问状态与起源资料缺口见[逐项研究](../../../../docs/research/2026-10-20-scene-narratives-original.md#woodfish--敲一敲木鱼)。本次只扩充介绍，不改手感、声音、震动、次数或完成路径。
