# 特色树形统一使用 Just a simple tree

日期：2026-11-05。用户比较后明确要求特色树种都使用此库；继续遵守「先在调试台预览」的范围。

樱花现由固定 MIT 源码的 oak／wood 分枝、叶簇散布、簇法线和顶点 AO 管线生成，两种变体采用低处分叉、开张树冠、较扁的花簇及原创五瓣缺口花纹。它是产品开花树美术改编，不是上游内置樱花物种，也不声明具体栽培品种。未复用此前 Jogoss 模型的几何、纹理或代码。柏、柳、层叠针叶树及原有橡树沿用先前资源；参数、来源和哈希见[素材记录](../../assets/environments/trees/simple-tree/README.md)。

四类特色树形都解析到 `simple-tree/`，樱花分别加载 `cherry-round.glb` 和 `cherry-cluster.glb`。Quaternius 与原始橡树来源比较项继续可选。十二份替代 GLB 及 CC0／MIT 完整通知随 Web／Expo 离线打包；旧外部樱花与原许可作为仓库档案保留，不再打包或请求，其专属调试署名 UI 移除。

九个地区／季节建议与排除项未变化，仍依据[已读证据与支持边界](2026-11-05-regional-tree-evidence.md)。本次改变生成来源及视觉造型，不新增仪式植物、起源、寓意、资格或节期主张；来源卡、宿主目录、注册表与模块 metadata 的既有文化绑定不因树木美术而变更。用户可见树形名称不增加植物学鉴定承诺。正式背景、文化主题树、存档与正式分享截图继续使用既定行为。
