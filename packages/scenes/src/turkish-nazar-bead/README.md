# 蓝珠祈安

ID/引擎：`turkish-nazar-bead` / `turkish-nazar-bead@1`。来源：`turkish-nazar-bead`；C级、低敏感、drag。

在土耳其公开护眼珠使用背景下，寄托日常避厄护佑的心意。备好的蓝玻璃扁圆珠有白/浅蓝/黑眼形与真实上孔，原创刚性金属挂环穿过珠孔；放在陶托上，整体提起，移到侧立木架，再让挂环落在横轴上悬稳。

拿住蓝珠后可连续移动，单指拿放、双指或 Shift／右键拖动转看正反面。松手可保留位置再拿取；把完整挂件送到最终横轴目标后短程归正、落环悬稳。自由查看不计进度，也不要求转满一圈。键盘可用辅助按钮的方向键转看、Enter 一次安放、Esc 放回。

真实可见网格命中、可取消的自由搬运，落定后只上报既有完成进度 3。44px 按钮支持键盘，减少动态直接落位；取消、失焦、停用或尺寸变化时回到当前存档检查点，已接受动画在暂停时冻结。旧 0／1／2 存档保持各自原姿态入口并可直接挂稳，不重放中间回调。静默恢复不保存或重放反馈；无愿望表单。模型与材质引用不在逐帧更换。

玻璃眼形、配色、悬孔与护佑背景有直接正文；本场具体尺寸/比例/金属挂环与木架/陶托/自由拿放与查看/落定容差/时长/声音/庭院/结束语属于产品。不是制珠教学、完整宗教礼法或某件馆藏复刻，也不保证护佑实现。物类跨多国使用，不能说成土耳其独有或统一伊斯兰教义。
