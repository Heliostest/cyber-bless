# 分地区树种调试预览

用户要求增加樱花、柏树等树形，按各仪式的地区选择更合适、可观赏的背景树；已明确选择本轮只在调试台预览，不更新正式默认。

保留原有三档来源选择，新增「按场景推荐」与可用的具体树形。推荐按明确场景 ID、场地与季节记录，不用国家前缀自动推断。无充分对应证据、缺合适模型或开放地形不适合种树的场景保留原景。调试推荐是产品园林选型，不作为仪式必需植物、起源、寓意或“最具代表性”的事实主张。

优先复用固定 MIT/CC0 来源。Just a simple tree 的 cypress 为意大利柱形柏、willow 为垂柳；其 pine 几何描述为冷杉式层叠针叶树，UI 不标成日本庭园黑松。免费 Quaternius Standard 只有 Common/Dead/Pine/Twisted 系列，不能凭完整付费套装宣传虚报樱花、白桦或棕榈。樱花需要可追溯的实际樱花树资产或明确的原创植物造型，不能仅将橡树涂粉并冒称源工具内置樱花。

保留现有事务式加载、同一场景实例、实例化、减动态、作用域隔离与恢复。所有新增模型/许可随 Web/Expo 离线打包，用户无付费购买。正式内容树、菩提/许愿等文化主题树和文化字段不替换。

实际阅读来源、支持范围与模型限制存 research 记录；模型来源许可不充当地区/传统证据。先覆盖核实且资产可用的推荐，逐场景列清回退原因，调试台支持手动比较。
