以纽埃公开的黄螺壳贝链工艺为背景，用已备好的材料做三步互动。当前来源为 `niue-kahoa-hihi` 贝链专卡，C / 低是本应用的设计分级。场景只补入最后一枚、收拢长串、静看或自愿写心意，不模拟采集活体、清理或穿孔准备过程，不声称完整教学、宗教仪式或结果效力。

32 枚原创小螺壳在浅蓝灰椭圆托盘上组成暖黄弧线。每枚采用同一份有内壁的渐缩螺旋几何、3.7 圈细螺纹、奶白色环形壳口和贯通的顶端预备孔。顶孔内半径为 0.022，留有 0.006 壁厚，以容纳半径 0.006 的线及其在刚性壳内的小幅弯曲。细线实际穿过最后一枚壳的两端开口，并连接整串；较均匀的弧长间距让尖端与壳口保持可辨。托盘有浅圆边，底面直接平放在宽木桌上；俯视镜头突出贝链，桌面延伸出画面边缘。材质沿用 `CEL_STYLE` 柔和三渲二，壳体用零金属度、粗糙度约 0.6 的轻微表面光泽。

## 三个动作

1. 从上方真实的最后一枚黄螺壳开始，向屏幕左方拖动至少 **40 px** 后松手。推荐 **60 px**。物体沿露出的细线滑入；需要实际 `pointermove`。
2. 从上方真实的双股细线端开始，向屏幕上方拖动至少 **40 px** 后松手。推荐 **60 px**。细线与贝链一起缓缓收拢到展示弧线。
3. 轻点任一真实螺壳静看，或明确提交现有心愿表单。轻点全程与终点位移都小于 **12 px**。只有明确提交的 1–40 字心意会去除两端空格后保存一次；静看草稿、恢复和还愿不另存。

两个拖动阶段支持同向长拖、合理斜拖及10–20px的小幅纠正，达到完整姿态后继续同向拖动仍可完成。明显反向起步、退回起点、过短拖动、没有移动事件、从背景起步和双指争抢都不完成。起点与静看终点须命中最近可见的不透明实体，提示也在该实体表面。

原生辅助按钮至少 44×44 px，使用 Enter / Space 完成等价步骤，接受后的过渡中禁用。减少动态会立即落到等价结果。取消、失焦和宿主暂停会复原未接受的拖动；已接受的动画在暂停期间冻结。每次观察到 inactive 边界都递增生命周期版本，即使此前已暂停，避免反馈准备期间的短暂停顿使旧输入复活。窗口捕获层与命中层都屏蔽同步宿主回调重入。销毁逐项释放几何、材质、提示、监听器、心愿组件和渲染器。
