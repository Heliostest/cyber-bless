眼前只呈现午夜之前备好葡萄的片段：十二颗原创绿色、平底示意葡萄分装在三只陶盘中，每盘四颗，依次从左准备台移到右侧餐台。后方方钟是原创静态午夜前示意，不鸣十二声钟，也不模拟吞吃。三盘分组、陶盘、平底形体、台架、钟面和时间、庭院、三次向右短拖与时长均为产品安排，不是传统食用顺序或完整迎岁仪式；完成仅指备盘完成。十二颗总数有直接来源，不给每盘或每颗另加独立寓意。
