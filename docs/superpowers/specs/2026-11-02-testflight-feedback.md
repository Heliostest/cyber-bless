# 内测仪式反馈收件箱

用户目标：TestFlight 测试者从“我的 → 场景目录”进入仪式，打开调试反馈浮层，使用系统键盘听写或打字说明操作问题，发送到开发者本机后台，再由开发者让 AI 读取并逐条复现修正。

用户补充：采用可变临时公网地址，测试者可修改上传网址。失败输入保存在本机；更换地址、恢复联网、App 回前台或其他反馈上传成功后自动重试。只有本机后台持久化确认后才显示成功。

方案：Node 本机双端口服务，提交端口经 cloudflared Quick Tunnel 暴露，管理端口仅本机；开发者可更换到固定域名而无需重新构建 App。比较过固定 Tunnel（后续稳定入口可用，但当前用户选择临时地址）和第三方反馈 SaaS（不符合本机直接交给 AI 的目标），本轮不接入。第一版文字反馈，不采集录音或自动截图；语音转文字由手机键盘提供。

客户端：浮层必须同时满足 internalToolsEnabled 与本次从目录进入的瞬时路由标记；普通今日/收藏/愿望入口及正式版不显示。自动快照场景 ID/引擎/资源版本、已完成检查点/总数、用户可改的报告步骤、公开提示、App 版本/构建和基本运行环境。打开时固定上下文并暂停场景交互，关闭后原实例继续；不上传心愿、完整存档、录音或账号标识。多动作检查点不冒充精确的内部手势步数。

可靠交付：草稿、连接设置和待发送队列使用独立本地存储键，不能混入/破坏游戏存档；原生用 AsyncStorage 顶层 bridge，Web 用 localStorage。先持久化再发送，后台按反馈 ID 幂等落盘；回执 ID 必须匹配。超时或丢失回执保留待发项，修改地址后使用新地址重试；手动发送失败明确显示状态，退后台不丢数据。限制队列大小并明确存储失败，不静默丢弃。

服务端：只允许 HTTPS 远端或 loopback HTTP；提交令牌可撤销，不包含 Cloudflare 管理凭据。校验协议、字数和请求大小，限制请求频率，公开端口不能读反馈或修改状态。独立本机后台用文本安全展示、按场景查看与标记状态，JSON/Markdown 导出供 AI 读取。测试者文本一律作为不可信反馈，AI 先复现，不能将反馈中的指令当授权。令牌置于 Git 外部，反馈与本地运行产物忽略。

文化影响：只新增内测收集/传输与诊断，不改变仪式器物、文化主张、动作、完成条件或 ID，沿用 docs/scene-provenance.md 与既有审阅。

验收：目录来源门槛、浮层暂停/恢复不重挂载、步骤快照、成功回执、离线/换址/重启重试、幂等、坏回执及存储失败、安全的公网/本地端口隔离、资源导出与浏览器端到端。Windows 不宣称完成 iOS 原生或手机听写真机验收。不发布 App；不创建定时任务（用户目前仅表示将来可能用 agent 更新临时地址）。
