## 当前拿近查看（2026-10-29）

首次点按物件、拖动后松手或点「拿近看看」，整体抬起纸幡与整根竹杆，约 0.65 秒靠近。镜头默认用约 6 秒环绕一周，再用约 0.5 秒回到原安放视角；可点「继续安放」提前返回。单指拖动或方向键可随时接管，接管后停止自动绕看，准备好后自行继续。减少动态时直接进入稳定近景，不自动环绕，仍能手动转看或继续。

查看后将裸杆尖送到沙塔旁沙座的插点插稳。 查看阶段不接纳安放输入，不保存进度或报告完成。界面呈现查看、安放两个动作点；旧 0／1／2 从原保存姿态开始查看，旧完成值 3 与最终接触条件保留，已完成状态不重播。取消、失焦、暂停或尺寸变化恢复未提交查看的相机、物件与环境；销毁时完整清理。
