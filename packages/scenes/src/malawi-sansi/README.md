# 铁舌轻鸣

原创九键木板示意琴，参考 Mbira/Sansi 的木板与金属簧片结构。九根铁舌均支持点按或向下短拖松手，九个原生按钮与数字键 1–9 从左到右对应各键。根部保持固定，末端弯曲，释放后独立阻尼回弹；余音可叠加，连续演奏不等待上一键落定。每个有效拨奏即时提供独立音高和触觉反馈，音效与震动遵循 App 实时设置。C 大调音列和泛音为原创界面配音，不代表当地调律或传统曲目。

首次演奏保存进度 2，此后无限演奏不重复推进；点击「结束体验」才保存进度 3 并派发一次完成事件。进度 1/2 的旧记录仍可继续演奏，恢复和进入均不自动发声。取消、反向、横移、多指、失焦和暂停不会误触发；画布内的空白处也保留给场景手势，画布外正常滚动页面，见[2026-10-23宿主触控修正](../../../../docs/research/2026-10-23-scene-touch-scroll.md)。减少动态效果跳过视觉余振，保留用户启用的声音和震动。不创建心愿。共享阳光花园、柔和三渲二；木板平放，无额外小桌或展板。

文化范围、可靠公开来源与原创部分见 content/traditions/mbira-sansi-craft.md。这是材料与声音的当代互动场景，不是仪式模拟或完整演奏教学。证据：artifacts/malawi-sansi；接续进度：artifacts/hourly-scenes/progress.md。
