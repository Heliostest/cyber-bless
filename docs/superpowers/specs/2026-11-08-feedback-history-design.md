# 复测历史反馈

用户已确认在仪式反馈面板补充历史反馈，查看原问题、对应步骤、旧版本和处理状态，以便核对复测结果。

直接在现有面板展示当前仪式的问题记录，包括已修复及旧修订；按接收时间倒序，每页 20 条，可继续加载和刷新。保留空、加载失败与未配置邀请码状态。使用纯文本展示用户意见。

实现选择：复用现有反馈同步桥，通过带类型的 JSON 查询调用新增邀请码鉴权的只读历史接口。旧状态查询及回复保持原样；不增加原生桥函数。相比在所有状态回复附加正文，此方式只在打开历史时读取，旧客户端也不受影响；相比另建管理页面，更方便边体验边核对。

接口只返回当前仪式的意见、步骤、时间、版本和处理状态，省略邀请码、投稿人身份及完整设备诊断。倒序游标分页绑定仪式，排除“测试通过”报告；历史读取不会修改原反馈、通过凭据、上传队列或玩家存档。仅在内测反馈面板可见。

技术分发/UI 变更不修改场景器物、动作、文化主张或来源。按既有来源核查记录沿用原场景内容。实现中的分页、传输和刷新细节由 Codex 按现有工程模式决定。
