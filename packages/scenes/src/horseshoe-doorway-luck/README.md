# 蹄铁护家

Three.js程序原创场景，ID/engine：horseshoe-doorway-luck / horseshoe-doorway-luck@1。C级、低敏感度、祈福类、drag；来源专卡同ID。

三枚U形铁色蹄铁起始以平底实托在左准备台，右侧双柱门架横梁上有三对固定柱。每次向右短拖／键盘按钮完成一枚抬起、移近、对孔滑入、微降挂稳。每个整数检查点未来蹄铁有台承托，已完成蹄铁以上孔顶接双柱；进度在动画落稳之后保存，减少动画及恢复同姿态。暂停／取消／多指／重入／退出与资源回收沿宿主契约处理。
