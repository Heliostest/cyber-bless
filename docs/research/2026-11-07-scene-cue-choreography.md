# 提示框、连接线、触摸点的连贯动效

日期：2026-11-07。范围：共享场景操作提示的入场、退场与步骤切换。

采用一组统一进度：提示框先轻浮入，线条从框体延伸至真实触摸锚点，点位随后亮起，整体约 0.45 秒。退场先淡去触摸点，再回收线条并淡出框体，约 0.24 秒。不同对象交接时新提示稍作错开，减少两组文字叠在一起；同一对象只换文字时保留线和点，框体位置与大小柔和过渡。

实际输入始终由场景负责，不因视觉延时禁止手势；退出中的提示是无输入能力的短暂残影，不参与命中测试或当前操作文案，锚点继续跟随对象。快速返回同一提示时复用原组，先恢复本帧选中的组，再限制其余残影最多三组，避免多组往返时重播。文字交叉渐变被退场打断时，以独立透明度一起淡出当前两层文字，保持视觉连续。减少动态效果、暂停、隐藏、离屏或卸载时立即停止残影并清理；高光等待整组提示稳定后才重新计时。

验证结果：

- `npm.cmd run test -w @wbr/scene-runtime`：34 个文件、361 项通过，其中提示测试 30 项；覆盖线段生长、移动锚点、纹理回收、多组快速往返、交叉渐变中退场与减少动态效果。
- `npm.cmd run test -w @wbr/app`：69 个文件、1,708 项通过。
- `npm.cmd run build -w @wbr/cyber-bless`：类型检查及生产构建通过；保留现有包体积提示。
- 本机 Edge 以真实 DOM 点位与 WebGL 画面捕捉 55 帧完整入场／换词／换对象／退场动图；快速返回复用原节点和纹理，八次往返后纹理数保持为 2，卸载归零；减少动态效果后无额外动画重绘，无浏览器／WebGL 错误。
- 木鱼、折纸、绘马在 320／390／430 像素宽度共九组实际页面检查通过；本地复现脚本和截图位于忽略目录 `artifacts/scene-cue-choreography/` 与 `artifacts/verify-scene-cue-choreography*.mjs`。
- 独立审查发现的多组恢复顺序与退场透明度连续性问题均已补充回归并复查通过。同步场景测试版本指纹。
