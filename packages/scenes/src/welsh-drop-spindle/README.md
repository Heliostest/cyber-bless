## 2026-11-22 羊毛束、交叉绕纱团与双股牵伸线连续性优化

保留原有自动取景范围与固定镜头位置、低位木纺轮三步动作（轻旋、缓落、提回）与既有暖木／乳白配色，细化羊毛纤维与纱线连接表现：上方原毛束由平滑球体改为具梳理绒纹的封闭羊毛簇与向下收束的牵伸毛锥（仍保持不随纺锤扭转）；杆身纱团在保留环绕木杆中空结构的前提下，加入程序交叉绕线贴图与 16 道正反斜向交叉的双股毛线缠绕层；新增由纱团上肩顺木杆螺旋引出并在杆顶系出半结（half-hitch）的连续引线，与垂悬的双股加捻牵伸线直接相接；垂悬线改为预分配原位更新的双股螺旋封闭几何，在轻旋与下放阶段同步呈现加捻与顺畅伸长，同时为木杆与纺轮补齐程序木纹。

全部新旧部件均保持零 WASM 的确定性解析姿态与封闭外向流形结构，正常、减少动画及恢复检查点姿态完全一致。本轮属于产品视觉与材料连接优化，仍维持既有简化边界（短动作仅为视觉示意，不宣称模拟完整纤维牵伸或特定地区纺法），沿用既有 `welsh-drop-spindle` 来源核查、操作条件、文案、技术 ID 与存档兼容性，外链未重读。
