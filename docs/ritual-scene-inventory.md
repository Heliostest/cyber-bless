## 文件组织

- 各场景目录的 `index.ts` 保存 metadata 和创建入口；`scene.ts` 管理场景、交互和生命周期。部分场景把几何构造放在同目录 `model.ts`，主表同时列出；纸鹤另有 `origami-sheet.ts`。`README.md` 是说明资料。
- [packages/scenes/src/procedural-kit.ts](../packages/scenes/src/procedural-kit.ts) 提供灯光、光晕、舞台和释放工具；[packages/scenes/src/cozy-furniture.ts](../packages/scenes/src/cozy-furniture.ts) 创建共享桌台；这些是程序化代码，不是下载模型。
- [packages/scene-runtime/src/debug-render-style.ts](../packages/scene-runtime/src/debug-render-style.ts) 通过 [packages/scene-runtime/src/cozy-environment.ts](../packages/scene-runtime/src/cozy-environment.ts) 挂载共享环境；按 [packages/scene-runtime/src/environment-profiles.ts](../packages/scene-runtime/src/environment-profiles.ts) 选择日夜与布局，按 [packages/scene-runtime/src/tree-profiles.ts](../packages/scene-runtime/src/tree-profiles.ts) 选择默认树型。
- 场景中的 Canvas 字样、渐变、光晕、程序化木纹以及合成物件音属于运行时生成内容；不能据此登记为 PNG、GLB 或录音文件。

- 共享渲染库导入 [packages/scene-runtime/src/icon-style-palettes.generated.json](../packages/scene-runtime/src/icon-style-palettes.generated.json) 和 [packages/scene-runtime/src/komorebi/color-curves.json](../packages/scene-runtime/src/komorebi/color-curves.json)：前者提供图标色板校准参数，后者提供 Komorebi 调色曲线。它们随 JS 打包，在相应风格启用时参与渲染，不是逐场加载的模型或图片，也不在 `public` 素材复制表中。
- 158 个场景各有 [assets/scene-icons/soft3d](../assets/scene-icons/soft3d) 下的 `<scene-id>.webp` 图标，对应关系见 [packages/app/src/scene-icon-assets.ts](../packages/app/src/scene-icon-assets.ts)。它们用于界面和收藏展示，不是 Three.js 场景贴图或模型。
- 字体位于 [assets/fonts](../assets/fonts)，由 [packages/app/src/assets.ts](../packages/app/src/assets.ts) 声明；共享 UI 和完成音效位于 [assets/ui-sounds/soft-garden-v1](../assets/ui-sounds/soft-garden-v1)，映射见 [packages/app/src/ui-sound-assets.ts](../packages/app/src/ui-sound-assets.ts)。场景自身的敲击／摩擦／演奏等声音主要由代码合成，未逐场列为录音依赖。

## 制作资料与打包目录

- 木鱼制作源在 [design/woodfish](../design/woodfish)，包括 `woodfish.blend` 与 UV 制作图；[assets/woodfish/blender-v2](../assets/woodfish/blender-v2) 同时保存贴图拆图和模型清单。当前运行时通过 GLB 读取内嵌贴图，不逐张加载这些拆图。旧 `bundled-v1`、`generated-v1`、`body.bin` 和旧贴图未列入当前打包资源表。
- 环境原始来源在 [assets/environments/source](../assets/environments/source)、[assets/environments/trees/source](../assets/environments/trees/source) 以及各来源子目录；模型、贴图、转换结果、来源说明与许可证需区分。[assets/environments/trees/regional](../assets/environments/trees/regional) 中保留的旧外部模型不在当前默认选择与打包清单中。
- [scripts/prepare-app-assets.mjs](../scripts/prepare-app-assets.mjs) 当前列出 **207 个随包资源文件**，包含 158 个图标、木鱼 GLB、两份 HDR、20 份树木 GLB，以及字体、UI 音效和许可。额外树模型来自 `quaternius/`、`simple-tree/`、`komorebi/`；`maple-{round,cluster}.glb` 等供比较选择，主表只标默认使用者。
- 该脚本把列入清单的素材复制到 [apps/cyber-bless/public](../apps/cyber-bless/public) 与 [apps/mobile-expo/public](../apps/mobile-expo/public)，并生成 `wbr-assets.json` 的字节数和 SHA-256。两处 `public` 都是构建产物，修改应落在源素材、场景代码或打包清单。
- 当前内容随 App 安装包提供；[docs/scene-content.md](../docs/scene-content.md) 顶部记录了 2026-11-02 的内置内容策略。历史下载与发布工具不能用来判断当前实际打包的是哪一版模型。
