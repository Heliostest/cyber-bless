# 绘牌记谢

## 2026-10-24 触摸容错

归途起笔暖色点补上真实可见表面附近22 CSS px内触摸容差，手持画笔不会遮挡自身目标，其他前景仍阻挡。窗光直线描绘接受完整down→up坐标位移，即使手机没有提供中间move事件；明显离线、反向、零位移、取消仍不完成。归途、窗光与可选感谢留言仍为原有产品表达，未新增文化主张。[逐场审阅与验证](../../../../docs/research/2026-10-24-scene-interaction-review-a.md)。

场景技术 ID：`italian-ex-voto`。当前呈现：陶牌绘归途与窗光、静看或留言；现代感谢小画。

## 2026-10-20 介绍扩充核查

当前简介已补充地域、文化语境及有据的历史节点，保留来源 `italian-ex-voto`。核查范围：卡萨利纳圣所十七世纪中叶敬礼及 1657 建筑起始，德鲁塔匠人受信众委托绘制蒙恩陶牌。

边界：圣所建造日期不等于全意大利 ex-voto 起源；眼前家景非圣所图像复刻，个人留言未实际献入圣所。

来源正文的完整链接、实际阅读位置、访问状态及产品简化见[B 组逐项记录](../../../../docs/research/2026-10-20-scene-narratives-b.md#italian-ex-voto)与[来源卡](../../../../content/traditions/italian-ex-voto.md)。本节不更改现有交互；用户介绍集中维护于 `packages/core/src/scene-narratives/b.ts`。

## 2026-10-23 产品交互容错修正

窗光按真实输入线段的覆盖判断，不再要求至少几个事件或限制相邻事件必须足够近；快速、缓慢描线都可完成。短暂偏线可回正，已描的色段与百分比保留到松手落定。

小对象起点采用可见表面附近的触摸容差，遮挡物仍会阻止拾取。取消、失焦或宿主暂停会丢弃未提交的本次手势，恢复后需重新拾取；辅助按钮仍可完成相同步骤。

本次仅调整产品输入容错、进度反馈和生命周期处理，不新增或改变文化主张、器物、原有动作次序及次数。技术 ID、来源分类和已保存检查点保持兼容；不把容错阈值写成传统要求。核查范围与验证见[本轮交互修复记录](../../../../docs/research/2026-10-23-scene-interaction-fixes.md)，文化事实仍沿用本 README 所链接的既有核查记录。

完整覆盖原有路线后，末点接受可见标记附近的 22 CSS 像素触摸余量；忽略手中物件及本次绘制的颜料，其他前景遮挡仍会阻止提交。走完路线后若离开末点，提示返回标记附近松手，不会把已有覆盖量显示成尚未描绘。


## 2026-10-26 当前跟手安放

本轮只将第一步画笔到归途起点改为跟手到目标自动落稳；其他旋转、描线、抚触或结束动作保留原语义。不再以固定方向、最短拖距或必须松手判断摆放成功。同一根手指的后续移动与释放不操作下一步；取消只撤回尚未接受的拿取。键盘辅助、减少动画、旧检查点和原有文化语境保留。此前段落中关于这些搬运步骤的短拖、20%预览和松手才接受描述为旧实现，以本节为当前机制。屏幕落区、吸附和短程落稳是产品输入安排，不新增传统礼序、次数或功效。[逐步审阅和本轮验证](../../../../docs/research/2026-10-26-spatial-placement-audit-a.md)。
