`lanna-sand-pagoda@1`／来源 `lanna-sand-pagoda`。兰纳新年寺院沙塔旁插置纸竹长幡的修福片段，保留佛教修福与救度亡者的信仰背景，不宣称完整仪轨或功效达成。

拖实际纸幡向上、向右、向下：提起→移到已堆好的沙塔旁→插稳。松手且动作落定才报告进度，长拖与小幅纠正遵循共享规则；44px辅助按钮、静默恢复、取消回原位、暂停冻结，无许愿表单。

原创塔形、无字浅橙锯尾纸面、固定纸顶的两条线环、木托、侧位与深度、三方向和时长是产品设计，不是传统定式。纸幡有厚度并连接横竹；仅裸杆尖进入沙座，不穿沙塔。
