# 风铃：把玩、悬挂与听声

场景 ID：`furin-wind-chime`。核查日期：2026-11-05。用户要求在已有拨弄、听声前增加把玩与悬挂。

## 实际呈现与产品流程

1. 风铃先置于左侧临时展示架。点按物品或「拿近看看」，进入近景；左右拖动或方向键转看玻璃花纹、铃舌和纸条。可自行决定看多久，明确继续后才退出。
2. 回到全景，拖动上方悬绳靠近木檐挂钩，松手后挂稳；按钮提供同一安放动作的辅助入口。未对准、第二指针、取消或暂停不算完成。
3. 挂稳后才启用原有点铃／拂动纸条，再听铃声与余音，沿用原静候收尾。

拿近时沿用共享 `close-inspection.ts`，仅风铃关闭计时自动退出；悬挂时风铃整体随拖动，挂稳后继续围绕固定挂点摆动，铃舌和纸条仍跟随。退出、缩放及失焦取消未完成拖动；暂停冻结安放动画。临时展示架、挂钩提示圈、相机转看、拖放范围、按钮和五个检查点均为产品安排。
