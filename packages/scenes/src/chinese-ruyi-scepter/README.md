# 如意寄愿

chinese-ruyi-scepter@1，C／低／drag，来源[chinese-ruyi-scepter](../../../../content/traditions/chinese-ruyi-scepter.md)，[证据记录](../../../../docs/research/2026-10-23-chinese-ruyi-scepter.md)。

馆藏说明将中国如意与如愿、吉祥护符、礼赠祝愿和陈设联系在一起，云头是所述如意的一种形制；材质有差异，玉如意有直接馆藏实例。这里保留真实吉祥寄愿背景，不改写成原本只作装饰，也不把信念写成产品功效。

眼前为原创青玉色云头曲柄如意的陈设片段，从左侧准备双托抬起、移近右侧木座、放稳。单件封闭实体轮廓、具体颜色与尺寸、软垫双托木座、庭院石台、三次上/右/下短拖、顺序/时长/声音/反馈和结语是产品安排。没有铭文、宗教符号、丝穗、开光或完整仪轨，不复制某件馆藏；不规定祝愿必须三次，不作现实应验承诺。

真实不透明云头命中，单件如意连续抬起/移动/放低。按住仅预览20%，合格释放后0.85秒落定才推进。未完成拖动取消回检查点，已接受动画暂停冻结、恢复续行；还原不另存愿望。支持键盘代替，触摸事件模拟不等于真机。来源、技术、实际网格和当前生产实图证据位于artifacts/chinese-ruyi-scepter/。
