# 仪式视觉风格胶卷菜单

2026-10-28：将仪式设置中的视觉风格选择改为靠近屏幕底部的单行胶卷，沿用 [Animal Island 壳层](island-shell.md) 的沙色面板、软白粗边、圆体字、薄荷选中态与按压台阶。卡片展示当前仪式经各 shader 真实渲染的缩略图，保留圆角相框和托盘齿孔，不新增打包图片或 WebGL 上下文。

## 实现与交互

- 复用现有设置弹窗与八种风格，胶卷独立横向滚动并居中吸附，两端留白以便首尾卡居中；手机原生滑动，桌面鼠标拖动。
- 鼠标移动超过 6px 后识别为拖动，释放时不误点到其他卡；方向键与 Home / End 浏览卡片。左右滚动时最靠近中心的卡片直接实时预览，点卡片会将它居中并预览，不再逐次弹出确认。
- 打开、结束微调或返回编辑时把当前项带回可见位置。滚动选择不会反过来重定位胶卷，避免拖动被打断。键盘焦点跟随居中，尊重系统及应用内减少动态设置。
- 指针聚焦不移动卡片，避免点击时目标滑走；点击后再将卡片居中。失去按住状态的鼠标移动会清理旧拖动。辅助说明保留给读屏，效果回退时在面板内显示。
- 所有风格、参数和恢复默认都是草稿，仅点「完成」保存并关闭。当前／全部仪式改为菜单内的范围切换，默认仅当前；范围切换本身不写设置，其他仪式在保存前不受影响。
- 关闭、外点、Escape、原生返回、卸载或渲染器退出会撤销草稿并还原原有画面；切入后台不自动保存。保留焦点恢复、滚动锁与渲染器退出清理。
- 手机横屏使用紧凑的标题和缩略卡，并按安全区内的实际可用高度容纳胶卷及范围按钮；参数区域独立纵向滚动，关闭及完成按钮留在固定区域。
- 放大版卡片宽 112px，照片以 4:3 比例占满约 98×73.5px 的预览区，内边距缩为 4px，标题单行省略显示以减少空白；完整标题仍保留在 DOM 中供读屏读取。横屏保留同等预览尺寸，胶卷首尾留白按实际卡宽居中。

## 真实缩略图

- 所有仪式经共享 `createDebugRenderStyle` 提供截图能力，复用当前 scene、camera 和 renderer。独立临时 shader 管线渲染后立即截取真实画布，恢复主样式及 renderer 状态后再让出执行；不运行场景 tick、动作、完成、提示层或存档回调。
- 每张截图保留真实渲染比例，通过居中等比裁切铺满 160×120 WebP，去除截图内的留白；只裁切缩略图，主画面的相机和取景保持原样，不套用 CSS 滤镜冒充 shader。示意色块和假风景已移除；等待时显示中性的相机图标，失败或 shader 回退时不冒充所请求的风格。缩略图禁用原生图片拖拽，手势由胶卷接收。
- 每次打开菜单重新按帧生成。菜单内仅缓存本次 renderer 版本与各 shader 相关参数；微调合并后只重画受影响项。首个有效场景帧、HDR 加载、尺寸变化及木鱼模型装入都会更新版本，避免缓存空场景；注册替换和不同 App scope 不共用图像。
- 菜单关闭即取消队列，销毁 renderer 后旧捕获回调失效。截图不改变画布尺寸、设备像素比、选中风格、保存数据或仪式进度；环境准备使用 `advanceMotion:false`，不会因八次截图额外推进风和环境时钟。
