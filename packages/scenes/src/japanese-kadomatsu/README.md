# 门松迎岁 / japanese-kadomatsu

门口成对松竹门松迎接年神的宗教语境，见[专卡](../../../../content/traditions/japanese-kadomatsu.md)与[逐项研究](../../../../docs/research/2026-10-23-japanese-kadomatsu.md)。三根斜切异高竹、松枝、草底有当代活动文字依据；本场选用该形制，不规定全国统一根数或含义。

左束已经摆好，右束从木托向上提、向右移到门边、向下落稳，组成一对。真实空心竹内壁、斜切口和孔底为连续闭合实体，颜色不冒充孔；松针为错列封闭锥体合批。草束初始接触托盘顶.20，最终接触石面.08，平移前先抬至.66；门框在松针后方，双束与托盘全路径避碰。网格/连续性/检查点恢复复用同一资源。

原创造型、配色、草束绳圈、木门、托盘、石面、尺寸与三段跟手安放/时长/反馈/回访都是产品安排，安放不代表迎神祭祀或祝圣完成、也不保证现实护佑。无砍竹、编草、梅枝、短册、供物、焚烧或神明显现。真实遮挡命中、目标范围判定、取消恢复、暂停重入隔离、44px键盘与完整释放遵循宿主契约；无强制写愿。
