# 葫芦刻光

## 当前产品收尾（2026-10-31）

进入独立的末尾静看／静候段后，使用柔和光泽变化（`glow`）；共享收尾不额外移动或转动目标，固定器物仍留在安放处。该段累计活动时间为3秒，减少动态为0.6秒并关闭共享收尾的位移／旋转；进度结束自动完成，无须再点物件或辅助按钮。前面的真实操作和既有动作动画不包含在这3秒内。

本场目标：`shell`。

独立模块若提供原生写愿表单，输入框获得焦点、IME组合输入或存在非空白未提交草稿时暂停自动计时，保留文字；明确提交仍沿用原保存路径。App继续在动作完成后提供可选祈愿，不把文字输入变成完成门槛。

暂停、失焦或页面隐藏时不计时；退出销毁不补发完成。恢复到原末尾静看检查点会重新播放收尾，已完成存档不重复奖励；尚未完成的物件操作保持原验收。

来源继续使用 `peruvian-mate-burilado`，文化支持范围不变。3秒、0.6秒、柔光、轻摆、轻浮及自动结算均为产品表现，不是传统期限、仪式动作或功效。较早记录中的“再点静看／静听／静立”及以该点按结算的说明不再是当前完成条件。现有文化事实、外链读取状态、技术ID、引擎版本与存档格式保持；逐场范围与验证边界见[自动收尾集中记录](../../../../docs/research/2026-10-31-automatic-quiet-endings.md)。

原创干葫芦、叶片和山丘纹样。参考秘鲁公开刻葫芦工艺，以曲面刻线、轻拭、静看组成三步互动。

- 场景：`peruvian-engraved-gourd`；来源卡：`content/traditions/peruvian-mate-burilado.md`。
- 向右轻拖壳面刻出细纹，向下轻拭显出纹理，轻点静看或明确提交个人心愿。
- 仅保留承托葫芦的软垫圈；使用明亮日光和柔和卡通渲染。
- 支持物体手势、键盘辅助动作、减少动态效果、暂停取消与进度恢复。
- 几何、纹理和动作由程序原创。刻纹及擦拭是视觉化的工艺缩略，不是完整雕刻教程。

模块测试使用真实 Three.js 几何、投射和材质，仅替代 WebGL 硬件接口。跨场景适配器、移动触摸及生产渲染由仓库验收脚本覆盖。
