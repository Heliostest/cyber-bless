# 提示标牌居中与磨砂玻璃

日期：2026-11-07。用户反馈：正文和手势图标偏离垂直中心，浅色实底标牌过于简单。

设计：正文按实际字形的 ascent/descent 居中，每行和手势图标共用正文区的中心线；辅助说明位于独立下行。玻璃底色只覆盖约 5%～15%，收细高光边缘并取消内层斜面，透出场景轮廓。文字在明亮背景为深墨绿，在较暗背景为浅色，不随底色透明度降低。

实现：沿用 Three.js 同画布标牌和现有动效，复制已绘制的场景颜色到共享纹理，仅在提示区域采样虚化；正文、图标和边缘保持清晰。每个场景复用一张背景纹理，不新增世界渲染遍次或 CPU 像素回读，尺寸变化与卸载时释放。退场提示复用同一玻璃程序。

技术依据：实际阅读本地 Three.js r170 的 Sprite shader、FramebufferTexture、WebGLRenderer.copyFramebufferToTexture 实现，并阅读 [FramebufferTexture 官方正文](https://threejs.org/docs/pages/FramebufferTexture.html) 与 [WebGLRenderer 官方正文](https://threejs.org/docs/pages/WebGLRenderer.html)（2026-11-07）。

文化影响：按 [场景来源规范](../scene-provenance.md) 第 1、3、6 节，本次仅修复共享布局与材质呈现。沿用 [2026-11-06 的核查范围](2026-11-06-scene-cue-motion.md#文化影响核查) 与其中既有来源入口。器物、材料、动作、完成条件、文案、来源身份和技术 ID 均不变；玻璃提示属于产品辅助界面，不新增文化主张，来源卡／注册表／metadata／场景 README 无对应事实变更。

验证计划：实际浏览器测量中英文、单行和多行正文与图标的像素中心；检查日景、夜景、窄屏、不同 DPR、换词及减少动态效果；运行相关生命周期与资源测试、类型检查和构建，同步场景测试版本指纹。

## 实际验证与兼容性处理

- 真实 Edge / WebGL 检查：木鱼日景、纸鹤、法语木牌及英文夜景提灯，宽度 320／390／430px；减少动态效果切换与页面无横向溢出。
- 按纹理字形像素测量，中文、英文、法语的单行／双行正文相对手势图标中心偏差均不超过 0.25px（DPR 2）。
- DPR 1 补查包含细线抗锯齿像素后，中文偏差 0px，英文与多行提示偏差不超过 0.5px；透色、虚化、逐帧 GL 错误及卸载释放均通过。
- GPU 连续帧测试：红背景与蓝背景得到不同透色；黑白条纹的标准差由 127.25 降至约 22.06；逐次复制 GL 错误为 0，卸载后该测试渲染器纹理数回到 0。背景较暗时字形从深色 `[16,45,41]` 切换到浅色 `[241,250,247]`。浏览器脚本与结果在本地 `artifacts/verify-scene-cue-glass.mjs`、`artifacts/scene-cue-glass-report.json`。
- 已实际定位并修复 r170 的两项复制限制：RGBA8 默认帧缓冲不直接复制到 sRGB 内部纹理，改用原始 RGBA8 并对每个采样做色彩解码；复制前通过 Three 状态缓存显式激活纹理单元 0，避免缓存绑定使后续复制写进文字贴图。相关回归覆盖已缓存背景的连续换色，不能只验证第一帧。
- 保留原有轻浮入、换词与实时进度可读性，退场材质使用独立的旧尺寸 uniform；背景纹理每场景共享，尺寸变化和卸载时释放。
- 初版运行时 33 个测试文件共 349 项通过；本次通透度修订复跑共享提示／渲染／纹理生命周期 40 项通过，TypeScript／Vite 生产构建通过；158 个场景测试版本指纹已生成并核对。仍有现有的大 chunk 提示。

视觉复核纠正：最初白色覆盖约 54%～76%，加上线性颜色混合与双层亮边，虽然技术上有虚化与透色，画面仍像实底卡片。后续降低底色覆盖、减轻模糊（采样步长 4.5px 改为 3px）、去掉内层斜面并让暗景文字变浅。玻璃主体保留 10% 的直接透射，正文不因此淡化。早期的低条纹方差并不代表视觉目标已经达成；最终仍以日夜实际画面和用户反馈核对。

文化核查清单结论：本次仅涉及呈现和资源生命周期；无新增文化主张、来源错绑、寓意／规则变更及用户文案变更。来源卡、宿主目录、注册表、模块 metadata 与 README 无相应事实修改；以上技术结果不作为文化事实的证据。
