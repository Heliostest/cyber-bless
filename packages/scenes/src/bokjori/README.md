# 竹筛迎岁

## 当前产品收尾（2026-10-31）

进入独立的末尾静看／静候段后，使用悬挂物的轻摆（`sway`），只作小幅转动，不让物件离开挂点漂走。该段累计活动时间为3秒，减少动态为0.6秒并关闭共享收尾的位移／旋转；进度结束自动完成，无须再点物件或辅助按钮。前面的真实操作和既有动作动画不包含在这3秒内。

本场目标：`scoop`。共享段结束后接续原有约0.55秒收稳动画，普通模式共约3.55秒；减少动态时原落定立即结算。

独立模块若提供原生写愿表单，输入框获得焦点、IME组合输入或存在非空白未提交草稿时暂停自动计时，保留文字；明确提交仍沿用原保存路径。App继续在动作完成后提供可选祈愿，不把文字输入变成完成门槛。

暂停、失焦或页面隐藏时不计时；退出销毁不补发完成。恢复到原末尾静看检查点会重新播放收尾，已完成存档不重复奖励；尚未完成的物件操作保持原验收。

来源继续使用 `bokjori`，文化支持范围不变。3秒、0.6秒、柔光、轻摆、轻浮及自动结算均为产品表现，不是传统期限、仪式动作或功效。较早记录中的“再点静看／静听／静立”及以该点按结算的说明不再是当前完成条件。现有文化事实、外链读取状态、技术ID、引擎版本与存档格式保持；逐场范围与验证边界见[自动收尾集中记录](../../../../docs/research/2026-10-31-automatic-quiet-endings.md)。

## 2026-10-24 触摸容错

竹筛与米盘、木挂点采用真实可见表面附近22 CSS px内触摸容差，握持偏心但竹筛实际握点已落到目的面也可提交；到位显示可以松手。手持竹筛不会遮挡自己的目的面，其他前景物仍阻挡。保留原舀米、挂起、静看和文化边界，未新增文化主张。[逐场审阅与验证](../../../../docs/research/2026-10-24-scene-interaction-review-a.md)。
