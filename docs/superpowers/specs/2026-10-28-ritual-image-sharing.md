# 仪式结束后的图片分享

用户希望在仪式结束后，通过分享按钮把带场景画面的图片发送到社交媒体或即时通信应用；已明确选择图片分享。

采用当前真实渲染帧生成本地 PNG 图片卡，内容为场景画面、当前语言的仪式标题与应用名。完成后出现「分享画面」，先预览，随后用户自行选择系统分享或保存图片。保持原有收下、收藏、祈愿、还愿流程。

方案比较：纯文字分享无法满足图片要求；平台专用 SDK 会重复接入各家应用。选择 Web Share 文件分享与 Expo 原生系统分享，浏览器不支持时提供图片下载。接收目标由系统与已安装应用决定，不宣称分享已经送达。

界面沿用现有薄荷色页面与奶油色面板，1080×1350 图片以场景为主体，不截图按钮、提示和私人心愿。图片在本地生成，不上传服务器。画面尚未就绪、编码失败与系统分享失败均可重试或保存；取消分享不报错。

覆盖普通场景、每日场景、开场场景和旧会话完成页。旧会话在离开渲染页前保存瞬时帧；重新打开且没有画面时保留原文字分享能力。

本次是产品辅助按钮、截图与完成反馈变化；器物、材质、仪式动作、完成条件、文化说明及来源绑定不变。文化检查依据 docs/scene-provenance.md，沿用 docs/research/2026-10-19-scene-culture-audit.md；不引入传统步骤、寓意、功效或地域主张。唯一画面例外为分享时隐藏用户写入的私人文字，正常场景不变。

开工时工作区已有未完成合并及 i18n 修改，保留它们，不顺手处理冲突、不提交或发布。整合过程中外部工作已解决合并冲突，现可运行构建和完成流程回归。系统分享仍需 iOS/Android 真机验收。
