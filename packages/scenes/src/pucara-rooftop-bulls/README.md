# 陶牛护家 / pucara-rooftop-bulls

秘鲁南部Toritos de Pucará成对陶牛置屋顶、寄托家庭护佑与丰足的信念，见[专卡](../../../../content/traditions/pucara-rooftop-bulls.md)及[逐项研究](../../../../docs/research/2026-10-23-pucara-rooftop-bulls.md)。MINCETUR与MNCP博物馆相关正文有据；头背把手、背孔及圆眼由PROMPERÚ旅游综述补充器形。保留Pachamama、牲畜标记礼俗及容器历史，不把它说成原本只是摆件。

一对原创奶油／赭色陶牛站在木承板上，UP托起、UP移向屋脊、DOWN落稳。四足、双角、伸舌、卷尾、圆眼、把手和真实背孔可辨；孔含内壁与内底，不以深色盖片冒充。承板初始底.20接低架；搬运高度1.30高于屋脊承台1.10；最终板底1.10，八足均接板顶.06。承台下轮廓贴合双坡屋面，不悬浮，不靠改变比例穿模。603实际顶点姿态检查净空，检查点连续且资源不重建。

具体器形、色彩、花饰、木板、屋形、低架、承台、三段方向／路径／时长、轻音、结束与回访为产品安排，不称传统固定礼序、完整仪式或实际护佑保证。无十字架、供物、供液、动物仪式、祭司、神明显现或写愿表单。完成仅表示眼前陈设安放妥当。
