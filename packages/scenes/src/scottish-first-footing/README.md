## 当前拿近查看（2026-10-29）

首次点按物件、拖动后松手或点「拿近看看」，整体抬起带来的整块煤礼，约 0.65 秒靠近。镜头可用约 6 秒环绕一周，之后停留在近景；由用户点「继续安放」后，再用约 0.5 秒回到原安放视角。单指拖动或方向键可随时接管，接管后停止自动绕看，准备好后自行继续。减少动态时直接进入稳定近景，不自动环绕，仍能手动转看或继续。

查看后仍作为新年午夜后的首位来客，携煤礼穿过敞开的主人家门洞，再从炉膛正面送入；保留门柱、门槛与炉壁净空检查。 查看阶段不接纳安放输入，不保存进度或报告完成。界面呈现查看、安放两个动作点；旧 0／1／2 从原保存姿态开始查看，旧完成值 3 与最终接触条件保留，已完成状态不重播。取消、失焦、暂停或尺寸变化恢复未提交查看的相机、物件与环境；销毁时完整清理。

## 2026-10-28 历史连续搬运

从旧 0／1／2 检查点均可拿住同一块煤，在敞开门内自由绕行，再从炉膛正面送到最终目标，一次完成只上报 3。煤块按水平面跟手，拾取时沿视线抬到搬运高度以保持抓点；真实煤块边界须全部穿过门洞，沿途扫掠检查门柱、门槛和炉壁，不能隔墙直送。中途没有必须停靠的存档点，旧 0／1／2／3 仍静默恢复。

可用两指、Shift + 鼠标或右键水平旋看；保留煤块平底向下，不开放俯仰。查看和转满一圈都不计进度，靠近门柱的旋转同样检查整段中间姿态。普通离手保留当前姿态，再次拿起或辅助按钮可接续；取消、暂停、失焦和尺寸变化恢复当前旧检查点，已接受的落定动画暂停时冻结。辅助按钮从实际停放姿态选择经过净空的路径再送入炉中，原生按钮支持键盘，不把路径节点逐个报告为进度。

首屏仍明确新年午夜后首位来客向主人家赠煤及祝愿的语境。自由查看、连续路线、水平搬运、物理净空和辅助路径均是产品安排，不是 First-footing 的统一礼序。模型原有 303 姿态几何审查保留；新增 helper／scene／model 定向测试及边界见[连续拿放审阅 C](../../../../docs/research/2026-10-28-continuous-placement-audit-c.md)。以下固定分段操作段落为历史记录。
