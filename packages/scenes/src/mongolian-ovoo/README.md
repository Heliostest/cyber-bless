# 敖包祈护 · mongolian-ovoo

蒙古一些敖包礼敬中的顺时针三圈与添石，向山岳和湖泊祈求护佑。[来源卡](../../../../content/traditions/mongolian-ovoo.md)与[核查记录](../../../../docs/research/2026-10-20-mongolian-ovoo.md)限定了证据范围。

三次向左短拖分别让来访者取起地面石子、顺时针走一圈，再以短弧添入石堆。可键盘操作同一动作按钮。取消、逆向、过长、多指与折返不推进，失焦/后台/卸载与恢复保持状态一致。三圈有据；每圈一石、六秒时长、动作分段、服饰与场地是产品安排。没有愿望输入，不模拟其他供物或完整仪式效力。

晴朗草地、石质敖包、系巾与普通衣着的来访者，使用柔和色阶、细轮廓和材质差异。无额外桌面或展示板。来源等级C、敏感度中，进入blessing正式池。

验收覆盖320/390/1280全部步骤、实际鼠标与320/390原生触摸事件模拟、离线、小组件与独立复核。触摸事件模拟不代表真机测试；真实结果及截图见artifacts/mongolian-ovoo。
