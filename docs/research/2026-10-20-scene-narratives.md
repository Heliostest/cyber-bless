## 范围与实现

开始时核对 `git status` 与当前真实渲染链路：`packages/core/src/daily-scenes.ts` → `packages/app/src/scene-library.tsx` → `RitualNarrativeBlurb`。`/scene-review` 遍历同一份 `builtInScenes`，共 131 项，其中 App 可见 64 项，隐藏 67 项。此次覆盖两者，保留隐藏策略与历史存档兼容。

131 项介绍均已替换为两段文字，每篇 201–270 字符（不计换行）。内容在 `packages/core/src/scene-narratives/` 维护，宿主 `narrative` 引用相应条目。125 张来源卡保留传统事实、产品呈现与外部资料，131 份场景 README 链到本轮逐项记录，不另复制一份完整用户文案。注册表和模块 metadata 没有介绍字段，来源分类与标题未因本轮扩充改变，无需重复写入长文。

折叠块仍使用原有“了解这个仪式”标题并默认收起。内部按空行生成段落，提供有名称、可聚焦的滚动阅读区，保留原 40vh 阅读高度并适配动态视口。顶部完成状态、完成按钮和收藏按钮的 DOM 及布局不变。

此次介绍扩充不改手感、音效、震动、完成条件、技术 ID、引擎版本、来源绑定或 App 上架范围。开始时已有的竹音轻摇自由摇动改动及发布相关工作保持原状；对其来源卡和 README 只追加本轮介绍核查记录。完成内容核查时尚未提交或推送。

后续按用户要求提交并推送时，将已完成的[竹音自由摇动](2026-10-20-angklung-free-shake.md)作为独立依赖提交，再提交介绍扩充，保证介绍所述操作与入库实现一致。商店发布配置等无关工作不纳入这次提交；本记录中的“不改交互”指介绍扩充本身。

另收窄两处与新介绍不一致的旧提示：舟模回访不再泛称“海上谢恩传统”，改为航海记忆；陶鸡的静看、回访和结束文字改为欣赏叶芽彩纹与手作，不继续断言固定“好运寓意”。只改文字，未改动作分支或完成判定。具体证据缺口见 A 组记录。
