## 2026-11-05 左右独立轻拍

当前物件仍为草地上的两副系绳凹木壳。左、右各熟悉一次后，可分别轻点两侧木壳，也可向下轻压后松开；接触时发出可选合成木质短音，上壳随即在约 0.18 秒内张开。下一拍不必等待回弹结束；快速左右交替或重复同侧都不会联动另一侧。左右原生按钮也可用 Enter／空格操作，反馈期间保留键盘焦点。点击单独的「结束仪式」才收尾。

保存值保持 `0..3`：`0` 待左侧熟悉、`1` 待右侧熟悉、`2` 自由轻拍、`3` 已结束。旧 `3` 存档只静默恢复，不重播或补发完成事件。取消、失去捕获、第二根手指、离焦及暂停会撤销未完成的按压；尚未松手时不发碰合音或推进。减弱动态时省略开合动画，仍可轻拍和使用按钮。
