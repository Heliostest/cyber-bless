# 白线祝归 / lao-baci-wrist

欢迎归来亲友的 Baci 系腕祝福片段。拿起白棉线、绕腕、收结，均操作真实线绳网格；辅助按钮提供同一动作的键盘入口。不把应用完成视为整场仪式完成。

[来源卡](../../../../content/traditions/lao-baci-phi.md)和[逐项研究](../../../../docs/research/2026-10-23-lao-baci-wrist.md)记录证据、信仰背景及产品边界。三分镜、单缕线、原创线结、手部与席面是简化，不规定传统结数、腕侧或佩戴期限。

手势依次上、右、上；无效拖动、取消、失焦恢复原姿；落定后上报进度。线圈从手上方移到指尖外、放宽过手再回到腕部的路径是产品动画，不是考证出的结法。正常动画、减少动画与存档恢复应得到一致网格。销毁释放网格、材质、音效、指针、轮廓与监听器。

验收覆盖模型、手势、恢复、暂停、销毁、三宽度全步骤鼠标、原生触摸事件模拟、离线与原生小组件封面。模拟不是真机测试。最终记录见 artifacts/lao-baci-wrist/validation.md。
