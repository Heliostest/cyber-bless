# 彩枝贺年 / bulgarian-survakane

保加利亚新年Survakane拍背送祝愿片段。对应源卡 `content/traditions/bulgarian-survakane.md` 和核查 `docs/research/2026-10-19-bulgarian-survakane.md`。

向上短拖提起彩枝，向右短拖移至亲友背后，再向上短拖轻拍背部并撤回。实际不透明枝柄命中，同一枝杖连续移动，接触时不穿过人体或座凳。完成语表达送上祝愿，不保证健康。三操作、单次接触、人物/衣服/矮凳、装饰取样/比例/日光为产品安排；隐含第一人称持枝者，没有建模儿童身体。

普通动态落定才推进；减弱动态直接到同一检查点；键盘辅助同样执行动作；取消恢复；拒绝空白、明显反向、纯横向、退回起点、多指和仅抬手；同向长拖、合理斜拖及小幅纠正可完成。0/1/2/3检查点静默恢复，释放事件、几何、材质、音频与GPU。BLESSING池，无愿望输入；独立图标和完成态三档封面，宿主回访与感谢是应用记录。

## 2026-10-20 当前介绍核查

已按实际器物与用户提示扩充介绍。山茱萸枝、羊毛线爆米花装饰、坐着的亲友；提枝→移到背后→轻拍收回。

核查重点：无确证统一起源；枝材信念按博物馆记述归属，不能承诺健康。孩子身体、完整祝词和拜年往来未展现；三短拖只是控制。

逐项证据、实际阅读位置和访问状态见[本轮介绍研究记录](../../../../docs/research/2026-10-20-scene-narratives-a.md#bulgarian-survakane)。


## 2026-10-23 操作容错

箭头与方向判定共用动作方向配置；正确方向支持短拖、长拖、合理斜拖及小幅纠正，达到条件时显示可以松手。明显反向、回到起点、取消和多指仍不推进。仅调整产品输入容错与完成提示，未改变器物、文化主张、三步动作顺序、来源归属、技术 ID 或存档。核查与验证见[本轮修复记录](../../../../docs/research/2026-10-23-scene-interaction-fixes.md)。
