## 设计约束

延续以实物为入口的三步流程：整理或完成手作、安放、轻点静看。辅助按钮保留键盘通路。两项提供可选心愿；静看不保存草稿，回看不再提供输入。背景使用已批准的晴朗渐变、低山与边缘植被，不增加漂浮装饰。

| 场景 | 物件与材料 | 流程 | 归类 / 背景 |
|---|---|---|---|
| 蓝白晾晴 | 原创蓝白扎染布、盆、晾架 | 漂洗显纹 → 晾起 → 静看或写愿 | 许愿 / 廊下 |
| 彩墙寄家 | 简洁的原创彩墙小屋 | 添上彩片 → 移至底座 → 静看 | 祈福 / 庭院 |
| 铜碗拾暖 | 厚壁铜碗、软垫、绒托 | 轻拭 → 安放 → 静看 | 祈福 / 廊下 |
| 木勺寄情 | 凹勺面、镂空心形木柄、擦布 | 轻拭 → 安放 → 静看或写愿 | 许愿 / 廊下 |

所有造型和图案为原创的公共手工艺欣赏练习。每场景阅读本地 C 级卡片与配图、核对可读的机构来源，在各模块 README 区分照片内容与所做物件。敏感度枚举仅有低/中/高，卡片的中低或低至中使用中，并注明归一化。

## 验收

真实不透明物件首个射线命中；持物拖动时排除持物组再判目标；错放、遮挡、小幅移动、异指针、多点触控不进度。取消、失焦和暂停恢复整件或冻结已接受动画。恢复各检查点不产生保存、触感或完成副作用。检查 320 / 390 / 1280 宽度下主体、提示和完成流程，真实 WebGL 截图、全场景 GPU 释放及布局回归。优先检查布与架、碗与托、勺与托的几何接触。
