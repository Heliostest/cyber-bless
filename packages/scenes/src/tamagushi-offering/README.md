# 玉串奉愿

`tamagushi-offering`／同名来源 slug，原生拖动三段：双手离案托持玉串顺时针90度；换持并继续180度，使根朝神前；向前落案后撤手。参考东京大神宫与神社本庁公开说明，是奉玉串的物件片段，保留向神明祈愿的语境，不宣称完整祈祷或现实效验。

榊枝、纸垂和持奉关联见 [专用来源卡](../../../../content/traditions/tamagushi-offering.md)、[研究记录](../../../../docs/research/2026-10-20-tamagushi-offering.md)。三正文与四动作图实际已读。手形、叶/纸排布、换持路径、两条承托木、供案比例、日光庭院、两次转向短拖和最后跟手供放为产品安排；手臂有意延伸出第一人称画面的下缘。弃用无手桌面滑转方案，原因和证据保留在研究记录。

真实网格命中、单指所有权、错误方向/多指/退回起点拒绝，同向长拖与小幅纠正可完成、暂停与取消恢复、键盘辅助、减少动画、静默进度恢复及资源释放使用现有宿主接口。完成进度在动作落定后报告。离线封面使用实际最终WebGL场景；未采用外部贴图或伪文字。
