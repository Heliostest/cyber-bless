# 纸鸢乘风

以潍坊公开风筝手作为背景的当代互动场景。纸鸢采用原创燕形轮廓、分叉尾、青绿纸面与朱红、米白、赭黄的简洁色块；未复制传统工匠的具体纹样。`chinese-folk-and-confucian` 是应用的地区索引，C / 低是产品设计分级，不是文化授权或传统等级。场景不声称教授完整的非遗技艺，不提供仪式效力承诺，也不保存心愿。

## 物体与动作

纸鸢与木线轮直接置于宿主的阳光草地场景，不添加桌子或展示底座。三维主体包括薄厚明确的不透明纸面、对称的弯竹骨、绑扎线、三股提线、提线结、绕满牵线的木线轮。木线轮的出线点与提线结之间始终连接同一根牵线；拖动、接受后的过渡和轻微风动均更新其真实几何。风动只在已抬升、宿主活动且未设置减少动态时出现；静态检查点的物理状态一致。动态牵线复用原始 GPU 顶点与法线缓冲，不逐帧创建几何。

1. 从右侧备好的纸翼开始，向屏幕左上短拖，纸翼贴合现有竹骨。
2. 从木线轮的横柄开始，向下短拖，线轮稍降，牵线带动纸鸢抬升。
3. 原位轻点浅色胸口静看，不保存文字或额外触发动作。

纸翼是已经裁好、绘好的材料，贴合动作不展示胶水或完整工序；牵线抬升是缩略的手作欣赏表达，不是风筝空气动力学或放飞教学。

原生辅助按钮最小 44×44 px，通过 Enter / Space 与真实物体交互完成相同步骤。过渡期间禁用物体与按钮输入。检查点 0–3 及返回访问均静默恢复，不报告新进度、触发反馈或保存心愿。每个暂停、失焦或销毁边界使输入生命周期失效；宿主反馈回调内派发的同步事件不能取消真实指针或跳过步骤。
