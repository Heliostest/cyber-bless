# Craft furniture provenance

Reviewed 2026-10-14.

The furniture generated by `packages/scenes/src/cozy-furniture.ts` is original
procedural geometry authored for this project. It does not contain downloaded
meshes, textures, copied model topology, or an asset loader. Scene work surfaces
retain their existing dimensions and contact heights.

Two official open asset collections were researched for a compatible visual
direction: simplified timber forms, softened edges and readable construction.

- [Kenney Furniture Kit](https://kenney.nl/assets/furniture-kit): the official
  page lists 140 files and Creative Commons CC0. This collection was considered
  as a source; **no Kenney model is included** in these craft tables.
- [KayKit Furniture Bits by Kay Lousberg](https://kaylousberg.itch.io/furniture-bits):
  the official page describes 50+ low-poly models in the free CC0 collection,
  available in OBJ, FBX and glTF. This collection was considered as a source;
  **no KayKit model or texture is included** in these craft tables.

The final design uses individually rounded planks, breadboard ends, quiet grain,
wooden pegs, and varied trestle, arched-panel or joined-leg bases. These are generic
furniture construction details, not reconstructions of any maker's design.
Using authored dimensions keeps existing craft objects, interaction anchors,
and grounded resting poses unchanged. Resources follow the scenes' existing
Three.js tree disposal; no network request or independent animation loop is added.
