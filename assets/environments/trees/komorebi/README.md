# Komorebi · Tree 1

Two local GLBs exported directly from the frozen Komorebi tree generator: round source variant 0 and asymmetric source variant 3. Source, hash manifest, reproduction command, adapter boundaries and licensing are documented in [the Komorebi snapshot](../../komorebi/README.md).

An optional console tree selection as of 2026-11-06. The user requested the previous per-scene tree defaults after the initial rollout; Komorebi meadow, lighting and tone remain the defaults. These tree models load only when selected. Cultural subject trees remain as authored; no vegetation is added to empty settings. No tree species or regional association is inferred from these generic product models. Source leaf pigments, oval geometry, woody branches and GPU wind anchors are reused; color/depth/distance passes share the adapted wind clock. See the [rollout and revision](../../../../docs/research/2026-11-06-komorebi-defaults.md).
