# 熏籽祈安

`persian-esfand@1`，BLESSING，来源`persian-esfand`，无许愿输入。

伊朗家庭焚Esfand种子避邪眼与护家心意的一个物件片段：提起预先盛籽的锅，放到炉上加热，再挥巾散烟。锅、种子、炉盘和布巾都是真实实体网格；木柄与布巾为实际最近不透明命中的拖拽对象。烟为独立透明效果。

上/右/下三次短拖分别触发准备、加热、散烟。有效释放后实体运动结束才写检查点，支持正常/减少动画、失焦/取消/后台、恢复及键盘按钮，拒绝错误方向/短拖/跳跃/多指等输入。44px辅助按钮不等于物件本身每个投影都达到44px。

USC的具体家庭口述与Iranica学者综述直接对应文化范围。原创厨房短台、单炉盘、外观、预装21粒种子和三分段不是统一礼序。未模拟祷词、头顶绕圈或医疗/空气净化功效。
