## 当前产品收尾（2026-10-31）

进入独立的末尾静看／静候段后，使用柔和光泽变化（`glow`）；共享收尾不额外移动或转动目标，固定器物仍留在安放处。该段累计活动时间为3秒，减少动态为0.6秒并关闭共享收尾的位移／旋转；进度结束自动完成，无须再点物件或辅助按钮。前面的真实操作和既有动作动画不包含在这3秒内。

本场目标：`face`。

独立模块若提供原生写愿表单，输入框获得焦点、IME组合输入或存在非空白未提交草稿时暂停自动计时，保留文字；明确提交仍沿用原保存路径。App继续在动作完成后提供可选祈愿，不把文字输入变成完成门槛。

暂停、失焦或页面隐藏时不计时；退出销毁不补发完成。恢复到原末尾静看检查点会重新播放收尾，已完成存档不重复奖励；尚未完成的物件操作保持原验收。

来源继续使用 `chinese-woodblock-print`，文化支持范围不变。3秒、0.6秒、柔光、轻摆、轻浮及自动结算均为产品表现，不是传统期限、仪式动作或功效。较早记录中的“再点静看／静听／静立”及以该点按结算的说明不再是当前完成条件。现有文化事实、外链读取状态、技术ID、引擎版本与存档格式保持；逐场范围与验证边界见[自动收尾集中记录](../../../../docs/research/2026-10-31-automatic-quiet-endings.md)。

## 动作

1. 从左侧木柄拿起棕擦，移到纸背，左右刷过后松手。纸面接触量可以跨多次正常松手累积，达到 0.75 世界单位行程和 0.45 单位横向范围后可继续揭纸；提示会显示当前进度。直接放下工具、无移动或在纸外挥动均不计入，取消本笔不清除之前正常松手留下的刷印量。
2. 捏住右下方的真实纸角，向屏幕上方拉动至少 42 px 后松手。纸张绕压住的后缘抬起并略微弯曲，显露纸背原先朝下的墨印。
3. 轻点印纸静看，或明确提交 1–40 字的心愿。草稿、恢复进度及还愿回访不会另存心愿。键盘可依次使用原生辅助按钮完成同等步骤。

木版有独立的木质厚度、挖刻刀痕和上墨枝叶浮雕；印纸有上下表面、弯曲边缘及随纸变形的印纹。棕擦底部的棕纤维与木柄是可见实体。交互射线检查最近的可见不透明网格，不穿过其他物体命中。环境保持透明，廊台由宿主提供。
