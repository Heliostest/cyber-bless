# Soft Garden 接入

用户已试听并确认 Soft Garden v1 十段原创音效，明确要求接入 App。沿用其已确认的音色、时序和相对动态；导出时统一乘以 0.45，适配频繁操作的轻提示电平。

采用预渲染 WAV 接入现有本地 UI 播放器。这与用户试听的确定性合成配方一致，也复用 Web／Expo 离线素材管线。实时合成会增加两套音色一致性的维护负担，因此不采用。用户随后要求仅保留新音效，因此旧 Kenney 素材与构建文件删除，来源历史由研究记录和 Git 历史保留；预留的 notice 语义复用本套 select。

进入、返回、选择、展开、收起、开关，以及保存、收集、完成，均使用新文件。结果音仍优先于导航音，静音／失焦／后台立即停播，解码完成不得补播过期动作。材质交互继续使用现有材质合成器。调试提示显示实际新文件路径。

不改变场景表现、文化来源、操作步骤、文案、技术 ID、存档或发布状态。无新依赖。校验两宿主离线哈希、结果音时长、成功后才反馈、失焦静音和真实浏览器播放。
