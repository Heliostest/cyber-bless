基于thisisFINLAND现场报道的当代芬兰埃斯波邻里拜访：挥装饰猫柳枝送健康祝愿，递枝，再收下主人放入篮中的包装巧克力蛋。[来源卡](../../../../content/traditions/finnish-virpominen.md)与[核查记录](../../../../docs/research/2026-10-23-finnish-virpominen.md)区分具体实例、正教版本差异和产品简化。

按住柳枝向右短拖挥枝；再次拿住柳枝，跟手递到主人接取处；按住巧克力蛋，跟手送到篮底提示位置，到位后主人松手并退出。全部为真实网格。纸花、配色、房门、手掌、编篮、摆放与分段动画为原创分镜，不是传统固定次数或制式。柳枝交接与礼物落篮具有连续轨迹，取消恢复检查点，暂停冻结动作；44px辅助按钮支持键盘。

开始时master为b213141，包含已提交视觉菜单和现有筛选规则。只在独立分支开发；旧场景、存档、预览、主目录未提交内容和上一项分支均保留。验证与截图见 `artifacts/finnish-virpominen/validation.md`；原生触摸模拟不等同手机真机。
