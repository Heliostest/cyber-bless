# 纸翼转风

## 2026-11-05 连续把玩与主动放回

当前操作为：握住真实木柄托起整只风车，再在纸翼上左右拨动。叶片立即跟随手指改变转角，放手后的续转速度取自最近的拖动速度并逐渐衰减；停住再松手不会重新获得拨动力。可反复抓取任一纸翼，不设次数或停留期限。握住木柄送回原来的位置，或选择“放回风车”，才完成体验。按钮也可托起、起转和反复续转；减弱动态保留直接跟手，停用自动续转。

存档仍为 `0..3`：0 未托起、1 已托起、2 已把玩且仍可继续、3 已放回。旧的 3 静默恢复为完成，不重放动作或派发完成；旧的 1、2 进入可继续把玩的提起姿态。未到位摆放、取消、多指、失焦或暂停不推进；已到位的指针尾事件不能开始下一动作。暂停冻结动画，恢复后继续；资源释放后输入失效。

本轮改变顺序、连续输入和完成选择，均属于产品行为。器物形制、材料、标题、技术 ID、引擎与来源 slug 保持；来源只支持一般纸风车结构及风驱转动，不支持本应用的拿起、手拨、速度映射、衰减或放回要求。未重新访问文化外链，沿用[来源卡](../../../../content/traditions/paper-pinwheel.md)及既有逐场核查的已读范围和访问状态。下方较早操作记录属于当时实现，当前操作以本节为准。

技术验证：本地真实 Three.js 几何与投影指针测试覆盖反复把玩、拖速差异、主动放回、三种画布宽度、减弱动态、取消、多指、暂停、回调中暂停／销毁、旧完成存档及按钮双击尾事件；模型测试覆盖刚体、封闭曲面、地面净空及检查点连续性。日志见 `artifacts/ritual-interactions/toys/`；这些测试不代替文化证据或真机触控验收。
