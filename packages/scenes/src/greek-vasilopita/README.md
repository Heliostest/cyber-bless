# 新岁分糕

`greek-vasilopita@1`：希腊东正教家庭新年 Vasilopita 分食片段，明确给家人送健康幸福祝愿。依据 [来源卡](../../../../content/traditions/greek-vasilopita.md) 与 [逐项核对](../../../../docs/research/2026-10-20-greek-vasilopita.md)。

糕已切好。托起家人份，送至盘中，取出其中硬币；六份数量、固定含币份、三短拖、糕铲与盘、露币凹槽、庭院餐桌和外观均为产品安排。没有演示完整家庭/教会礼序或保证好运，不把取币称为固定传统步骤。

实体糕、铲、盘及硬币采用真实网格；侧向空腔提供取币通路。取币阶段切换至切面近景，竖币离开槽口后抬升、转平落盘；币槽形态、币的朝向与镜头均为便于看清物件的产品安排。支持物件命中、有效方向短拖后动画落定、键盘辅助、暂停/焦点/取消/重入/恢复、减少动态及完整释放。阶段只在落定后推进；不创建愿望。
