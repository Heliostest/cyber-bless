## 呈现与动作

三颗扁圆实体小石分别写有五、大、力，散在少量普通小石之间，旁边是一只敞口青绿色布袋。按住当前字石向右短拖：石头先离地，再水平越过袋口，最后降入袋内；三颗按顺序收好。布袋有厚壁、内腔及底面，石头不会穿过侧壁。没有额外许愿框。

物件表面最近的不透明命中决定能否起拖。反向、过短、过长、横向偏离、折返、折线路径、多指、取消、失焦和暂停均不进度。只在落定后保存检查点；键盘按钮和减少动态使用相同终态。支持0–3断点及回访静默恢复，不把进入、恢复或进度3等同愿成或还愿。

## 来源边界

住吉大社官方资料直接支持五所御前拾五、大、力三字石、装袋携带与祈愿信仰，来源 slug `sumiyoshi-godairiki`。固定顺序、短拖、原创形状与配色、舞台、音效和动画是产品简化；不推定起源年代、资格、节期、袋色寓意、每石各有一个愿望或应验概率。不把宗教御守背景改写成普通石子收纳。

宿主通用的「还愿」入口也可使用此许愿小物：用户已把个人心愿标为实现后，重走场景会留下应用内感谢记录。该记录机制属于产品新增，不是神社送还原石、另添感谢小石的仪式，场景模型没有演出后两项。进入/恢复/普通完成不会自动判定愿望实现或写入还愿记录。
