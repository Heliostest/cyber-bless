# 复测历史反馈交付核查

用户确认在仪式反馈面板查看原问题、步骤、旧版本与处理状态。实现记录见[设计](../superpowers/specs/2026-11-08-feedback-history-design.md)和[操作说明](../testflight-feedback.md#在仪式里核对历史问题)。

## 已实现

- 待复测仪式自动展开历史，其他状态可手动展开；旧修订、旧构建和已修复问题均保留。正文和当时提示按纯文本展示，不混入本次草稿或自动确认通过。
- 按接收时间倒序，每页 20 条；同时间的记录以 ID 确定顺序，游标绑定当前仪式。只返回意见、步骤、版本、状态和时间，不返回投稿人身份、邀请码、通过凭据或完整设备诊断。
- 复用现有 JSON 反馈桥，旧状态协议不变。读取不写反馈存储或玩家存档；切换目标、邀请码及生命周期后拒绝过期回复。
- 网络/旧后台失败明确报错，已读取记录可继续对照；刷新成功后更新，不把失败当作空历史。历史正文只在当前面板内存中保留。
- 上传界面说明问题描述可供内测人员复测核对。八语言均完成完整性检查和 agent 自审，不宣称母语审校。

## 实际验证

- `npm run feedback:test`：119 项通过，包括真实 HTTP 鉴权、原反馈协议、上传队列、版本化复测确认以及新历史读取/分页/安全显示；随后补充的旧后台初次读取失败/重试测试也通过。
- Web 生产构建通过，含 i18n 提取、ICU、生成文件和类型检查。
- `EXPO_OFFLINE=1 npm run mobile:verify` 通过：按锁定 SDK 检查，双平台嵌入导出核对 207 项资源，iOS 核对 477 项 Widget 封面。未执行真实手机设备验收或新的原生包发布。
- 真实本机 HTTP + Playwright/Edge：八语言 390px，23 条记录分页、长文本/HTML 字符按文本显示、失败保留已读记录，无页面错误、无横向溢出；测试收件记录逐字节数据未变。
- 独立审阅未发现 P0/P1/P2 问题；审阅者独立复跑 shared、runtime、client/UI 和 server 测试通过。
- 重启既有后台后，实际公网历史接口无邀请码 401、有效邀请码 200。用既有 `korean-sotdae` 已修复意见核对正文、步骤和状态一致，11 条原收件数据未改变；校验过程不输出邀请码或原意见。

## 来源与交付边界

本次仅历史反馈协议和 UI，不改变场景器物、动作、完成条件、标题、寓意或来源绑定；沿用[既有文化核查](2026-10-19-scene-culture-audit.md)。历史提示/意见是旧记录，不作为文化事实来源。

工作区同时出现的提示连接线调整及其仪式测试修订由另一项工作维护，本次保留并不纳入历史反馈提交。此次没有合并、推送、发布新内测更新通道或原生包；手机需安装包含本界面的 App，或在已接入热更新的内测包上应用相应新版。现有旧热更新候选不会因本次源码修改自动改变。

本机验证证据位于忽略目录 `artifacts/feedback-history/`（测试日志、八语言截图、浏览器报告及不含正文/邀请码的实际服务探测报告）。
