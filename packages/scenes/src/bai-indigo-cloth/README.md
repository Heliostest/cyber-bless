## 原创转译及局限

蓝白留纹为代码生成的错列椭圆环与窄边带，没有复制传承人、工坊或照片的可识别图样。盆、矮托布架、木晾架和尺寸均为现代展示道具原创造型，不声称还原特定村落或作坊。盆呈陶色，仅为当代展陈选择；资料中的漂洗器具包括木缸和水池。

交互从已经染过的扎布开始，将拆线、展开和漂洗压缩为第一检查点的视觉转场。它不是完整技艺教程，没有演示染液配方、缝扎方法或实际多次浸染。静看与可选心愿是本应用的现代交互，没有被解释为传统规则。

`indigo-tied-cloth` 初始位置 `[-1.03,.36,.89]`；实际布体底面接触凳面。`indigo-open-cloth` 在检查点 1 位于 `[-.78,.79,.49]`，在检查点 2、3 位于 `[.84,1.90,-.06]`。布的折顶内半径 `.070` 与两个木支撑的半径 `.070` 接触。正反面、圆弧折顶和四周厚边共用一个拓扑闭合的网格，厚度 `.006`，留白为同网格顶点颜色，没有独立悬空纹样或白色遮挡板。

拖动会移动整个物件组。取消、失焦、第二根手指或宿主暂停使未接受的拖动完整复位；已经接受的短动画暂停后续播。输入以所有可见不透明物件的首个真实射线命中为准，落点检测排除当前持有组，没有透明放大命中框。原生按钮提供键盘辅助操作。
