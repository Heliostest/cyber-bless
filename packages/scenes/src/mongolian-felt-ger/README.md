# 毡屋向阳

当代蒙古包工艺欣赏，三步：从红色木格端头向右短拖、从红色顶圈向上短拖、从白毡卷向下短拖。每步可用辅助按钮的 Enter/Space 完成。

保存 0–3 整数进度。恢复静默，不建立心愿；完成仅派发一次事件。普通与减少动态效果使用同一最终形态。物体前表面命中后才获取手势，错误方向、短拖、迂回、非有限坐标、多点、取消和失焦均不推进。

原创木格、顶圈、椽杆、支柱、毡卷、带开口的厚度覆层与门板；共享阳光草地和柔和三渲二。模型省略实际结构连接、施工顺序与杆件数量，不是建筑教学。资料见 content/traditions/mongolian-ger-craft.md。
