# 微屋寄愿 / alasita-miniature-house

基于拉巴斯Alasita获取愿望微型物的公开实践，MUSEF正文直接列出城市illas包含房屋。复用[aymara卡的Alasita专段](../../../../content/traditions/aymara.md)，[逐项核查](../../../../docs/research/2026-10-23-alasita-miniature-house.md)记录证据和访问状态。真实背景包含Ekeko信仰、安第斯祝圣与天主教祝福，本场聚焦器物与选取片段。

按住房屋向上短拖提起，向右短拖转看，再向下短拖安放到前方软垫。屋顶瓦脊、门窗、底座、承台和软垫均为真实封闭网格；最近可见网格命中后才接受输入。先离台再向前，先移到垫上方再下降；取消恢复检查点，暂停冻结。44px辅助按钮支持键盘。

房型、哑光涂色、三件陈列物的数量、台面/软垫、三段轨迹、时长和回访记录均为产品安排，不是传统规格或礼序。不模拟宗教主持或祝圣，不把安放等同现实祝福完成；没有期限、财富或房产效验承诺。原创建模，不复制馆藏、人物或民族纹样。

起始master为`f907a485e56c38d1ee3bc8bc07643c1557a26f2a`。独立分支实现，主目录未提交内容和旧预览保留。本轮只做这一项，验收与本地提交后停止。验证见本工作区`artifacts/alasita-miniature-house/validation.md`；触摸模拟不等于真机。
