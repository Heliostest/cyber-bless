# 毛线织暖

## 2026-10-19 来源核查修正

现关联改为直接对应器物、工艺或节庆行为的专卡。原地区或宗教总卡不足以单独证明本场景的文化来源；具体证据及产品动作边界见下方审阅记录。

当前来源：`content/traditions/faroese-wool-knitting.md`。核查依据与原关联的问题见[全场景来源审阅](../../../../docs/research/2026-10-19-scene-culture-audit.md)。


以法罗群岛日常羊毛与编织文化为背景，展示一针普通下针的缩略过程：右针穿入末端旧圈，工作线绕针，抽出新圈，旧圈滑下。奶白与灰色条带、织片比例、木针和支架均为原创设计；这不是完整毛衣制作，也不声称针法专属于法罗群岛。当前来源为 `faroese-wool-knitting` 羊毛针织专卡，C / 低是本应用的设计分级。场景属于公开手作欣赏与当代祝福体验，不提供心愿表单或效力承诺。

织片直接平放在自然木色工作台上，宽桌面延伸出画面边缘，俯视镜头突出羊毛与木针。90 个短 V 形线圈共享一个 `TubeGeometry`，相邻行以前后深度交错；奶白与灰色毛线保留真实孔隙，并以较密行距和较粗线径形成可辨认的织物。线团有立体绕线，按真实最低顶点直接落在桌面上；工作线从线团连接到活动线圈。两支木针有锥形针尖、小支托和真实线圈关系。旧圈先越过左针尖再落下，已有织片不凭空增长。全部使用 Three 官方几何、粗糙材质和默认柔和 `CEL_STYLE`；细毛线及木针关闭轮廓以避免小屏黑线堆积。

## 三个动作

1. 从右侧木针实体开始，向屏幕左上方短拖后松手，右针进入末端旧圈。建议 `screenDelta: [-48, -36]`，总长 60 px。接受后的过渡演示工作线绕针。
2. 从同一支右针开始，向屏幕右下方短拖后松手，把新线圈带出旧圈。建议 `screenDelta: [42, 46]`，总长约 62 px。接受后的过渡先让旧圈越过左针尖，再落入织片。
3. 原位轻点织片静看；全程移动与松手距离都需小于 12 px。

前两个动作沿建议方向至少42px；没有固定最大拖距。接受同向长拖、合理斜拖和10–20px的小幅纠正，到位后继续同向拖不会失去成功资格。有效按下后的释放终点也参与采样，因此不要求浏览器一定发送中间 `pointermove`。错误起点、明显反向、退回起点、过短距离、无按下的孤立释放、多指和取消不会完成。起点和静看终点均要求首先命中实际可见不透明实体。

原生辅助按钮至少 44×44 px，通过浏览器原生 Enter / Space 激活，与物体手势完成相同步骤。已接受动作的过渡期间，按钮、物体输入与提示均禁用。减少动态立即得到同一结果。检查点 0–3 静默恢复，不报告额外进度或触发反馈。场景不调用 `saveWish`。

- [Visit Faroe Islands — The Faroese Wool](https://visitfaroeislands.com/en/see-do/cultural-experiences/heim-experiences/the-faroese-wool)：自然毛色、羊毛与编织社群背景。

- [Craft Yarn Council — Instructor Handbook](https://www.craftyarncouncil.com/files/CIP/CYC_CIP_Knit_Program.pdf)：普通下针的穿入、绕线、抽出与退旧圈机制，仅作一般针法依据。
