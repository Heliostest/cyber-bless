# 仪式随包发布与内测目录

用户决定（2026-11-02）：所有提供给玩家的仪式及资源随 App 打包，新增仪式通过 App 更新发布，不提供运行时下载。完成一次仪式即可永久解锁该仪式的玩家侧入口，无需领取小物。回访、重玩和重置当前进度不撤销解锁；旧存档中的完成记录和已经领取的小物保留解锁资格。

“我的 → 场景目录”仅用于开发和 TestFlight 验收，不是玩家的解锁目录。内测目录可直接试玩现有可见场景；正式版隐藏入口并阻止直接导航。Web 开发环境启用，生产环境默认关闭；iOS 根据运行时分发环境识别 TestFlight，不能仅靠会随同一构建进入 App Store 的环境变量开放。检测失败时关闭。

旧远程目录配置、旧存档中的 manifest URL 和旧下载缓存不能覆盖内置场景。目录不再显示需下载或按需准备，也不引导用户管理下载缓存。保留现有场景技术 ID、引擎版本、存档和既有场景可见性规则。

文化影响：本次只改变发布、导航和产品解锁机制，不修改器物、动作、完成条件、来源或文化主张。依照 docs/scene-provenance.md，沿用 docs/research/2026-10-19-scene-culture-audit.md 的既有核查。

验收：内测目录可进入所有现有可见场景且全为内置；正式版隐藏且不可直接进入；带旧远程地址的存档离线可加载；完成但未领取即解锁且重启/重玩后仍然解锁；移动端嵌入资源校验通过。Windows 不宣称完成 Swift 原生编译或 TestFlight 真机验收。
