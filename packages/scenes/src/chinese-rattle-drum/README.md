# 拨浪轻响

## 2026-10-24 交互审阅

至少完成三次有效操作后显示「结束仪式」，可以继续演奏或操作，主动选择结束才提交完成。三次是应用的最低体验量，非传统数量要求；旧完成存档保持静默完成，进度 2 恢复后保留结束资格。触屏采用可见器物附近的有限容错，仍检查遮挡、取消和多指。

逐场发现、处理、来源边界与验证见[本轮 C 组记录](../../../../docs/research/2026-10-24-scene-interaction-review-c.md#逐场记录)。

主动结束时，普通动画先用约 0.6 秒回正并收低木柄，木珠垂回后才提交完成；减少动态则直接落定。收尾从当前转柄相位连续开始，期间暂停输入，失焦/暂停冻结并可恢复，退出不延迟回报完成。收尾仍是产品动画，不增加传统次数或规则。

场景 ID：`chinese-rattle-drum`；来源：`chinese-rattle-drum`。

## 2026-10-20 当前介绍核查

已按实际器物与用户提示扩充介绍。单个双面鼓、木柄、两根绳和木珠；右旋→左旋→收低，木珠交替击皮。

核查重点：画作可证明南宋图像语境，不证明最初发明、现模型精确形制或古代礼乐身份。Grinnell 1517 页/接口超时、黄岩博物馆页超时，未称已读；新介绍不依赖这些失访源的玩具年代。

逐项证据、实际阅读位置和访问状态见[本轮介绍研究记录](../../../../docs/research/2026-10-20-scene-narratives-a.md#chinese-rattle-drum)。


## 2026-10-23 操作容错

箭头与方向判定共用动作方向配置；正确方向支持短拖、长拖、合理斜拖及小幅纠正，达到条件时显示可以松手。明显反向、回到起点、取消和多指仍不推进。仅调整产品输入容错与完成提示，未改变器物、文化主张、三步动作顺序、来源归属、技术 ID 或存档。核查与验证见[本轮修复记录](../../../../docs/research/2026-10-23-scene-interaction-fixes.md)。
