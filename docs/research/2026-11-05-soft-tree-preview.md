# 柔和树影与圆润叶簇

日期：2026-11-05。用户反馈近景树影太硬，叶子不够圆润。继续仅调试预览，不改变正式默认和文化主题树。

## 原因与处理

已读本地固定来源 `foliage.js` 的 `bakeCards` 和 `glb.js`：叶卡每个顶点保留朝外簇法线，与卡片三角形朝向独立。已读项目锁定的 Three r170 `normal_fragment_begin`：普通双面材质会在背面再次翻转法线。真实 WebGL 对照中，同一朝外法线的卡片仅翻转三角形顺序，原普通材质中心像素最大通道差为139，印证了异常明暗碎块的原因。

`tree-foliage.ts` 仅为 Simple Tree 来源的叶材质保留两面一致的簇法线，将烘焙顶点色反差系数降为0.68；普通 PBR／Lambert 光照使用低峰值包裹漫反射，让亮暗过渡更柔和。墨线等分段风格保留自身光照。`toon-surfaces.ts` 为适配材质重建相同处理，避免 clone 后丢失编译回调。源 GLB、几何、法线、叶片遮罩及配色数据均不改。没有额外渲染通道、贴图或第三方依赖。

替代树实际可见时，共享主光使用支持 radius 的 PCF 过滤，半径12、投影强度为进入预览前的52%。保存每盏主光原强度和过滤半径，在原景准备、正式截图和卸载时恢复。夜景灯火位置、动画和光强不改；近景布局与中央留白也不改。

试用 alpha-to-coverage 后发现当前画面会出现白边，已撤下；沿用原透明裁剪，不以半透明白边冒充柔和轮廓。图片对照保存于 `artifacts/tree-softness/`，实景截图在 `artifacts/tree-framing/`。
