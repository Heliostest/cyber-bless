## 2026-10-24 方向容错

取消旧84px上限与9px回退限制，采用共享方向判定，支持同向长拖、合理斜拖、小幅纠正和稀疏触摸事件，到位显示可以松手。明确反向、回起点、取消、多指与遮挡仍不推进。保留抚额、祈学问背景和来源，不新增文化主张。[逐场审阅与验证](../../../../docs/research/2026-10-24-scene-interaction-review-a.md)。

有限呈现京都北野天满宫抚卧牛头、祈学问成就的信仰片段。[来源卡](../../../../content/traditions/kitano-nadeushi.md)与[逐项核查](../../../../docs/research/2026-10-23-kitano-nadeushi.md)记录已读证据和未采用的主张。

拿住手掌跟手到牛额前的提示位置；按住牛头向右短拖，轻抚额面；再拿住手掌跟手收回到提示位置。三段操作和动画是产品分镜，不是传统礼序或次数。石卧牛保持静止。取消、失焦和指针归属丢失恢复尚未接受的当前检查点；暂停冻结运动；键盘辅助按钮与真实物件操作共用状态机。

石牛的角、耳、口鼻、卧腿、尾部与手掌均为真实网格；没有图片替代。造型、材质配色、石座和环境不是特定馆藏复刻。手掌接触、全路径构图和生命周期分别验证；320/390/1280鼠标、320/390原生触摸模拟与离线验证报告在 `artifacts/kitano-nadeushi/validation.md`。模拟不等同真机测试。
