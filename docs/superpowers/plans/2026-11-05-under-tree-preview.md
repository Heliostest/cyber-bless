# 树下近景调试构图

用户要求树木靠近，树干局部出画，弯垂的枝叶遮住少量画面上部。沿用调试预览范围，仅改变已选替代树的布局，不移动正式环境或交互主体。

- [x] 为靠前两棵建立基于当前镜头的左右框景：根部／局部枝干出画，树干贴近侧边，叶冠主要从上方探入；其余树适当收近以保留纵深。
- [x] 根据实际模型叶冠范围定尺度，保持来源几何与树种轮廓。窗口尺寸变化时重排；镜头在互动中移动时树木保持世界坐标。
- [x] 延续加载、取消、资源释放、减动态、原景恢复及正式分享隔离；验证低视角／俯视、日夜和移动尺寸。结果见研究记录。

这是园林构图调整，无新增植栽传统、文化寓意、物种或地域主张。沿用地区树形证据和场景来源核查范围，不改来源卡、宿主目录、注册表或 metadata。
