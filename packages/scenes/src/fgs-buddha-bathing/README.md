ID：`fgs-buddha-bathing`；来源：`fgs-buddha-bathing`；版本 `@1`。

佛诞三杓浴肩片段，以佛光山公开讲解为限。依太子像自身右、左、右肩倾水，分别发愿止恶、行善、度众生。眼前器物为原创太子像、莲座、厚壁水盆与木杓；晴光庭院为背景。

每一步按住真实杓柄向上短拖，预览抬杓；合格释放后，水杓提起移向肩部、倾水并收回，完成后才记录进度。键盘按钮提供等价入口；错误方向、明显退回起点、空白起手、取消不提交；同向长拖与小幅纠正可完成。恢复与减少动画复用同一检查点。三短拖、回盆轨迹和色彩材质是产品安排，未演出的礼拜/跪坐不计为已完成。

## 2026-10-20 当前介绍核查

已按实际器物与用户提示扩充介绍。太子像一手指天一手指地、莲座水盆木杓；右肩/左肩/右肩三杓，与止恶/行善/度众生对应。
