# 调试台水体渲染

用户要求：盘点仪式中的水，并把 Shader Gallery 的 Toon Water 移植为调试台可选的渲染方法。

## 接入选择

采用水体材质覆盖：在现有开发版调试台选择当前场景的「原有水体 / Toon Water」。默认原有水体，关闭水体调试或卸载调试台立即撤销覆盖；收起面板仍可观察效果。选择只保存在当前调试会话，不写正式存档。

将水体做成全场景视觉风格会连带改变其他器物；逐场景重写水面会重复生命周期与释放逻辑。两者都不适合本次范围。

## 渲染与边界

- 以本地 `D:/ws/art/shader/shader-gallery/src/three-materials/water-material.js` 为移植源，保留 Water Toon Torrent 的 gyroid/fbm、流动相位与分阶配色。
- 不增加几何起伏，复用实际水面、容器水、水流与水滴网格；原交互几何、放置坐标和既有水位动画继续使用。
- 共享浅水效果明确标记水面；已有 `ritualOptics.kind=water` 材质接入。酒液与浮水画颜料承载液明确排除；普通材质的椰子水和菩提供水显式标记。
- 无 UV 的洗钱池使用局部 XZ 投影，不修改或替换几何。保留透明度、面向、深度与可见性；兼容共享视觉风格和雾。
- 动画服从场景 active/reducedMotion；捕图与视觉风格缩略图不推进水纹时间。每帧覆盖后在 finally 恢复原材质，释放只处理覆盖层拥有的材质。
- 场景 ID、标题、动作、完成条件、文化来源与正式视觉偏好不变。本次是技术渲染变更，文化核查沿用既有记录并在水体盘点中逐项列出。

## 验证

实际材质恢复、无 UV、水位与射线、双 App 作用域隔离、退出与卸载、减少动态、真实 WebGL 各视觉风格、面板实操与生产构建。
