# 首批器物风格化材质

2026-11-05，用户确认前一轮建议：保留柔和卡通，为木牌、陶鸡、铃、御守增加可辨的手作表面，并做实际前后对比。

- 目标：木纹及端面色差、彩绘陶面的细颗粒与柔亮反光、铃的宽高光、袋与绳的织纹。沿用原有器物材料身份、颜色、纹样、几何、交互和文化绑定。
- 选择：共用程序表面补丁，按实际材质明确接入，随物体局部坐标移动。已有纸布透光等 `ritual-optics` 继续独立工作。小屏幕按像素足迹减弱细纹。
- 备选：整套写实 PBR 会改变整体风格和资源成本；仅添加贴图会被现有卡通转换丢掉部分细节。采用保留卡通体积、局部保留反光的方案。
- 技术：现有 Three.js r170 / WebGL，无新依赖、网络材质请求、透射或额外渲染目标。只有陶面、金属保留 Standard 的物理高光；木布继续走卡通着色。
- 验收：四场原图、柔和卡通、墨线、水粉实编译与显示；320/390 像素；完成/恢复/退出兼容；精确恢复原材质，不释放场景拥有的贴图。
- 文化边界：只增强既有材料的美术表现，不宣称具体木种、陶釉、织法、合金或传统工序。沿用既有来源核查并逐场记录支持范围；不把技术纹理反推为传统事实。

实施细节由本次实现确定：程序噪声、纹理幅度和宽高光数值由当前画面对比调校；不新增产品设置项。
