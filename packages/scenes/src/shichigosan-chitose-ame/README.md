# 千岁赠糖

## 当前拿近查看（2026-10-29）

首次点按物件、拖动后松手或点「拿近看看」，整体抬起糖袋、提手和袋内包装糖，约 0.65 秒靠近。镜头默认用约 6 秒环绕一周，再用约 0.5 秒回到原安放视角；可点「继续安放」提前返回。单指拖动或方向键可随时接管，接管后停止自动绕看，准备好后自行继续。减少动态时直接进入稳定近景，不自动环绕，仍能手动转看或继续。

查看后把糖袋递向孩子，放低后仍等孩子双手接稳提手，再确认交接完成。 查看阶段不接纳安放输入，不保存进度或报告完成。界面呈现查看、安放两个动作点；旧 0／1／2 从原保存姿态开始查看，旧完成值 3 与最终接触条件保留，已完成状态不重播。取消、失焦、暂停或尺寸变化恢复未提交查看的相机、物件与环境；销毁时完整清理。

## 2026-10-28 历史连续拿取

拿住糖袋可连续递向孩子，可选择转动查看；不要求在提起、递近两个空中停点重新拿取。进入最终接收范围后，仍保留放低、孩子双手伸入提手并接稳的交接动画，之后才报告旧进度 3。旧 0、1、2 姿态静默恢复后均可直接递送；普通离手保留位置，取消、失焦、停用和 resize 撤回未提交拿取。辅助按钮一次递送，减少动态与恢复采用同一最终接触姿态。

连续输入和查看均为产品安排，不要求转满一圈，不增加传统礼序或健康功效。以下三停点／三次拖动是历史实现。文化范围与验证见[B 组记录](../../../../docs/research/2026-10-28-continuous-placement-audit-b.md)，[来源卡产品呈现](../../../../content/traditions/shichigosan-chitose-ame.md)同步。
