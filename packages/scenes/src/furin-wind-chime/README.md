# 风铃一响

## 当前产品收尾（2026-10-31）

进入独立的末尾静看／静候段后，使用悬挂物的轻摆（`sway`），只作小幅转动，不让物件离开挂点漂走。该段累计活动时间为3秒，减少动态为0.6秒并关闭共享收尾的位移／旋转；进度结束自动完成，无须再点物件或辅助按钮。前面的真实操作和既有动作动画不包含在这3秒内。

本场目标：`pivot`。

独立模块若提供原生写愿表单，输入框获得焦点、IME组合输入或存在非空白未提交草稿时暂停自动计时，保留文字；明确提交仍沿用原保存路径。App继续在动作完成后提供可选祈愿，不把文字输入变成完成门槛。

暂停、失焦或页面隐藏时不计时；退出销毁不补发完成。恢复到原末尾静看检查点会重新播放收尾，已完成存档不重复奖励；尚未完成的物件操作保持原验收。

来源继续使用 `furin-wind-chime`，文化支持范围不变。3秒、0.6秒、柔光、轻摆、轻浮及自动结算均为产品表现，不是传统期限、仪式动作或功效。较早记录中的“再点静看／静听／静立”及以该点按结算的说明不再是当前完成条件。现有文化事实、外链读取状态、技术ID、引擎版本与存档格式保持；逐场范围与验证边界见[自动收尾集中记录](../../../../docs/research/2026-10-31-automatic-quiet-endings.md)。

## 2026-10-28 收藏陈列点按反馈

新增完成模型的 `tapPreview()`：在原轻风摆动上叠加短暂、有上限的摆动，铃舌和纸条跟随，随后恢复原轻风基线。它仅供宿主收藏展示使用；不推进或重做聆听步骤，不改祈福分类、完成条件、文案、来源或存档。玻璃铃感短音由宿主合成并受声音开关控制，不能称作器物实录或传统规定音色。减少动态效果、暂停及退出时清理；来源卡已同步产品新增边界，见[小物反馈记录](../../../../docs/research/2026-10-28-wish-object-feedback.md)。
