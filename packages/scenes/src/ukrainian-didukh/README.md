# 迪杜赫麦束 / ukrainian-didukh

关联乌克兰家庭圣诞前夜把 Didukh 麦束带入家中的公开习俗，保留收获、丰足与祖先护家信念，不承诺现实效力。直接器物、动作与信仰依据见[专卡](../../../../content/traditions/ukrainian-didukh.md)；逐项支持范围、失败访问与去重见[研究记录](../../../../docs/research/2026-10-24-ukrainian-didukh.md)。

本场景将完整穗头麦秆、分叉支脚和彩带制作成原创麦束：UP 整理麦秆，RIGHT 系合彩带，DOWN 立稳于家居屋角。秆数、金色配色、模型比例、家具、三段定向输入、时长与完成反馈为产品安排，不是传统规定的三步；未复刻某件馆藏或来源照片。

传统屋角位于圣像下，此处省略圣像并简化家居环境；没有表演完整圣诞晚餐、祭献、焚烧和后续处置。没有统一公历日期、固定数量、期限或资格要求。完成只确认眼前麦束已立稳，个人祝愿属于当前表达，不表示先祖已经应允或现实护佑生效。

基线 `b79e92d2`，独立分支 `codex/ukrainian-didukh`。具体实体锚点、模型承托、持续拖动与回访恢复，以实现和本次技术验证记录为准；来源审阅与技术验证分别进行。

## 模型与技术验证（2026-10-24）

`createDidukhModel()` 返回同一 `didukh-subject` 场景与 `didukh-sheaf` 麦束。模型包含 19 个完整麦穗、228 颗成对籽粒、228 条芒刺和 27 根底部张开的麦秆；这些数量只服务当前画面。籽粒与芒刺采用实例化，麦秆与布带使用封闭实体。蓝色束带、柔珊瑚色蝴蝶结、蜜色木地板及石灰／泥灰家居屋角属于原创造型。

起始秆脚与木展盘顶面 `y=.22` 接触，第三步先水平离开展盘再下降，最终 27 个平切秆脚落在 `y=0` 地板上。模型不依赖隐藏支柱。麦束最终包围盒约 `[-.050,0,-.492]` 至 `[1.085,2.360,.355]`；完整布景包围盒约 `[-1.55,-.12,-1.10]` 至 `[1.55,2.80,1.20]`。

三个输入均拾取实际麦束，锚点为 `didukh-sheaf` 局部坐标：`[0,.9,.223]`、`[0,.9,.223]`、`[0,.9,.171]`，位于可见蝴蝶结前侧；相机方向建议 `[0,2,7]`。邻接姿态端点逐子节点完全一致，直接恢复存档步骤不需要先播放动画。

`model.test.ts` 的 8 项测试已通过：实际前侧网格可拾取；完整穗头及籽粒避开秆芯；所有独立几何体有限、封闭、无退化三角形且体积为正；初始展盘与最终地板精确接触；全动作 93 个采样状态中麦束不穿透支撑或墙面；连续端点、直接恢复及输入截断一致；动画不新增资源且唯一几何体／材质只释放一次；57 个 InstancedMesh 在重复 dispose 时也各自只释放一次，回归测试覆盖其独立 GPU 资源。此处验证几何和生命周期，不代替上述来源审阅。

## 最终交付验证

本场景 76 项测试通过：8 项模型、66 项交互、2 项目录检查。相关宿主注册、来源分类、叙事、意图和生命周期检查及正式构建通过。共享庭院针对此场景采用 `floor=-.15`，使原本位于 `y=.012` 的公共小径不再盖住 `y=0` 木地板；对应运行时回归与同组 81 项测试通过，未变更文化主张。
