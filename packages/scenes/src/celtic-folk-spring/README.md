# 泉边一念

## 当前产品收尾（2026-10-31）

进入独立的末尾静看／静候段后，使用原有水面或悬浮物的轻浮起落（`bob`），只用于本场景原有的漂浮呈现。该段累计活动时间为3秒，减少动态为0.6秒并关闭共享收尾的位移／旋转；进度结束自动完成，无须再点物件或辅助按钮。前面的真实操作和既有动作动画不包含在这3秒内。

本场目标：`token`。

独立模块若提供原生写愿表单，输入框获得焦点、IME组合输入或存在非空白未提交草稿时暂停自动计时，保留文字；明确提交仍沿用原保存路径。App继续在动作完成后提供可选祈愿，不把文字输入变成完成门槛。

暂停、失焦或页面隐藏时不计时；退出销毁不补发完成。恢复到原末尾静看检查点会重新播放收尾，已完成存档不重复奖励；尚未完成的物件操作保持原验收。

来源仍为 `product-original`，不新建传统卡。3秒、0.6秒、柔光、轻摆、轻浮及自动结算均为产品表现，不是传统期限、仪式动作或功效。较早记录中的“再点静看／静听／静立”及以该点按结算的说明不再是当前完成条件。现有文化事实、外链读取状态、技术ID、引擎版本与存档格式保持；逐场范围与验证边界见[自动收尾集中记录](../../../../docs/research/2026-10-31-automatic-quiet-endings.md)。

## 2026-10-19 来源核查修正

原场景将俯身、无名信物入水和留言组合为泉边体验；现有凯尔特概览不能证明这套动作对应某地传统。现改为不作地域归属的泉景体验。

当前来源：`product-original`，App 目录省略 traditionSlug。核查依据与原关联的问题见[全场景来源审阅](../../../../docs/research/2026-10-19-scene-culture-audit.md)。

## 2026-10-19 写愿与完成

保留泉沿俯身与信物放到泉面的动作。最后以「静看片刻」完成，不要求输入文字，也不读取未提交草稿。独立模块保留可选表单，只有明确提交才交给宿主保存；主应用将写愿放在完成后的自愿记录中。全部 78 项的核对与产品简化边界见[写愿门槛审阅](../../../../docs/research/2026-10-19-wish-completion-gates.md)。

## 2026-10-20 介绍扩充

介绍补充泉沿、水面、金色信物和光点，把放下与停留作为个人联想，不声称凯尔特圣泉传统或疗愈效力。正文在 [`scene-narratives/original.ts`](../../../core/src/scene-narratives/original.ts) 维护，实际呈现与文化归属不适用项见[本轮研究](../../../../docs/research/2026-10-20-scene-narratives-original.md#六个产品原创场景)。本次不改变前述写愿、结束或隐藏策略。


## 2026-10-26 当前跟手安放

本轮只将信物到泉面改为跟手到目标自动落稳；其他旋转、描线、抚触或结束动作保留原语义。不再以固定方向、最短拖距或必须松手判断摆放成功。同一根手指的后续移动与释放不操作下一步；取消只撤回尚未接受的拿取。键盘辅助、减少动画、旧检查点和原有文化语境保留。此前段落中关于这些搬运步骤的短拖、20%预览和松手才接受描述为旧实现，以本节为当前机制。屏幕落区、吸附和短程落稳是产品输入安排，不新增传统礼序、次数或功效。[逐步审阅和本轮验证](../../../../docs/research/2026-10-26-spatial-placement-audit-a.md)。
