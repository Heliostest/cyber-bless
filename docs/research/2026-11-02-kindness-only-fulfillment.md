# 还愿改为记录一件小善事

核查日期：2026-11-02。依据用户「还愿不要用仪式来还愿了」的要求，修改心愿宿主流程。

## 产品变化与兼容

- 还愿页直接展示「做一件小善事」及既有帮助／感谢说明、记录输入和纪念章，移除方式选择、仪式完成状态和小物入口。新还愿不消耗收藏，也不新增仪式会话。
- 新 `wish.fulfill` 统一写 `kindness`；旧未完成 `ritual` 计划和草稿不再触发仪式门槛，保留草稿文字、输入法组合和字素限制。
- 未完成心愿显示小善事提示；历史已经完成的 `ritual` 记录照实展示，保存方式、系统笔记、关联会话、小物和纪念章不改写。旧存档 v1 继续读取，已完成的重复提交保持幂等。
- 旧仪式会话可结束，出口改为「去心愿看看」，返回详情；新的善事记录通过详情进入还愿表单。
- 复用既有八语言消息，保留历史仪式还愿的翻译分支。

## 文化影响核查

本轮移除的是应用自行安排的还愿入口、流程条件与提示，不改变任何场景的器物、材质、动作、完成条件、文化介绍、信仰语境或来源绑定。达摩另一目、御守返纳等既有场景及旧会话仍保留原实际含义，没有把真实宗教实践改写成「本来只是小善事」。小善事是应用当前的新还愿记录方式，不宣称是一切社群的还愿规则。

已按[场景来源规范](../scene-provenance.md)判定范围，沿用[场景心意核查](2026-10-19-ritual-intentions.md)、[动作与可选记录核查](2026-10-19-ritual-wish-flow.md)和[既有心愿宿主核查](2026-10-27-wishes-simplification.md)。本轮没有新增文化主张，没有重新读取外部来源，也不将技术测试作为文化事实证据。

来源卡、场景 README、宿主目录、注册表、模块 metadata 与原生标题无受影响文化字段，无需改写。技术 ID、引擎标识与存档版本保持不变。
