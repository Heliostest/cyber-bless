# 开樽祝愿

日本清酒镜开的有限开樽片段：取起系红白带的木槌，轻叩预松盖板接缝的一端，再收回木槌。木槌是实际命中和抓取的物件；错误表面、反向或无效轨迹不会推进。动作落定才保存进度。

具体来源和访问状态见[专卡](../../../../content/traditions/kagami-biraki-sake.md)及[研究核查](../../../../docs/research/2026-10-20-kagami-biraki-sake.md)。保留庆贺新开始、健康与幸福的祝愿背景；只选择月桂冠的一种公开开盖方法，不声称普遍统一礼序。两半盖平移及收槌到地面是产品分镜，未表现饮用、分享或完整神事。

`createKagamiBirakiModel` 提供中空木樽、编织菰层、封闭酒体、预松盖及木槌。轻叩发生在盖缝端部，盖片一直平置于樽沿；木槌先升起再移动，最后槌头接触地面。`pose` 保持三个检查点连续，普通动画、减少动画与进度恢复一致。程序纹理在dispose时单独释放。

技术ID `kagami-biraki-sake`，引擎@1，来源同名专卡，C／中；blessing池、optionalWish=false。取槌／收槌跟手到位、叩击短拖、时长、配色、模型尺寸、盖片数量及庭园日景均为原创简化。历史测试、浏览器截图、原生触摸事件模拟和独立审阅存于 `artifacts/kagami-biraki-sake/`；本轮验证见下节，触摸模拟不代表真机。
