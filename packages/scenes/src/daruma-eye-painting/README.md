## 2026-11-10 点睛顺序对齐、毛笔落座与手机手感

先点的一目改为观者右侧（达摩自身左目），与本场介绍“先带着心愿点上面对达摩时右侧的一目”及来源卡 2026-10-19 已读的高崎市说明一致。此前三维呈现把观者左侧当作第一目，与已核查主张相反；本次修正的是呈现，不新增主张。补目仍为另一目，回访条件不变。

毛笔改为两节竹杆、深色笔箍、浅色笔毫与蘸墨笔尖，斜靠在木座右前方的小木块上，不再悬空，也不再在手机宽度下出画；拿起时笔身转为书写姿态，松手回到木块。

手机输入：达摩、毛笔与空白眼圈均以实际可见几何加约 22 像素指尖余量判定，更近的表面仍优先；拖动的笔尖一碰到空白眼圈即点上，不必找准松手位置，同一次触摸之后的移动和松手不会操作下一步。新点的眼珠像墨点一样轻轻晕开到原大小；减少动态时直接显示。

文化影响：点睛两阶段、补目条件、留愿与归座流程、文字、来源 `daruma-eye-painting`、引擎与存档保持。笔托木块、竹节与笔毫配色是产品美术，不新增工艺、步骤或功效主张。证据沿用来源卡 2026-10-19 已读高崎市页面（先点观者右眼），本轮未重新访问外链。[审阅、取舍与验证记录](../../../../docs/architecture/2026-11-10-ritual-prop-visual-mobile-audit.md)。
