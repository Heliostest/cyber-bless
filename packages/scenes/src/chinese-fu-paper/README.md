# 贴福迎春

ID／引擎：`chinese-fu-paper` / `chinese-fu-paper@1`。来源：`chinese-fu-paper`，C级、低敏感、`drag`。

春节门上贴福寄托迎纳家宅祝福的心意。本场是一张备好红纸从托架移到木门贴稳的短片段。所选正向不构成统一朝向规则，原创黑色几何字形没有借用书家字体。

1. 按住福字向上短拖，从小托架提起。
2. 向右短拖，整体移到门前。
3. 向上短拖，沿深度方向靠门贴稳。

完成条件为每段有效方向拖动释放后真实动画落位；反向、过短、过大横向偏移、取消和多触点不推进。44px辅助按钮支持键盘，减少动态可立即落位。取消恢复当前检查点，重新进入不重复进度反馈，不写入愿望文本。

红纸、贴门与纳福背景有直接依据；具体菱形尺寸、字形、木门、托架、单张、陈设、三步路径、时长与声音属于产品呈现，不是完整年俗规程，也不是实际效果保证。

[来源卡](../../../../content/traditions/chinese-fu-paper.md)；[逐项研究与访问状态](../../../../docs/research/2026-10-23-chinese-fu-paper.md)。对应正文是台湾文献馆辞典、上海市政府、爱丁堡大学孔子学院、恭王府博物馆的贴福说明。四条已读正文；Smithsonian访问拒绝不计作已读。不同材料的方向、数量、时辰规则不外推。

模型按检查点连续刚体平移；字形与红纸同组，无每帧网格重建。测试使用真实Three.js顶点、射线与方向提示，仅替换GPU工作；另有实体鼠标、触屏、键盘、恢复及封面实图核验。交付证据在 `artifacts/chinese-fu-paper/`。
