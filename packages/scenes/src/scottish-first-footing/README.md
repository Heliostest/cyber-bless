# 煤火迎年 / scottish-first-footing

## 2026-10-28 当前连续搬运

从旧 0／1／2 检查点均可拿住同一块煤，在敞开门内自由绕行，再从炉膛正面送到最终目标，一次完成只上报 3。煤块按水平面跟手，拾取时沿视线抬到搬运高度以保持抓点；真实煤块边界须全部穿过门洞，沿途扫掠检查门柱、门槛和炉壁，不能隔墙直送。中途没有必须停靠的存档点，旧 0／1／2／3 仍静默恢复。

可用两指、Shift + 鼠标或右键水平旋看；保留煤块平底向下，不开放俯仰。查看和转满一圈都不计进度，靠近门柱的旋转同样检查整段中间姿态。普通离手保留当前姿态，再次拿起或辅助按钮可接续；取消、暂停、失焦和尺寸变化恢复当前旧检查点，已接受的落定动画暂停时冻结。辅助按钮从实际停放姿态选择经过净空的路径再送入炉中，原生按钮支持键盘，不把路径节点逐个报告为进度。

首屏仍明确新年午夜后首位来客向主人家赠煤及祝愿的语境。自由查看、连续路线、水平搬运、物理净空和辅助路径均是产品安排，不是 First-footing 的统一礼序。模型原有 303 姿态几何审查保留；新增 helper／scene／model 定向测试及边界见[连续拿放审阅 C](../../../../docs/research/2026-10-28-continuous-placement-audit-c.md)。以下固定分段操作段落为历史记录。

苏格兰 First-footing 携煤新年祝福片段。实际首屏和介绍明确：新年午夜后，你作为首位来客，向主人家送上煤礼及温暖安康的祝愿。煤从室外布垫拿起，经真实敞开的门框进入木地板区域，再从炉膛正面送入主人炉火；不是捡煤为自己取暖。

依次拿住煤礼提起、携过门槛、送近炉火，煤块跟随手指进入当前目标范围即自动接受；拾取只接受无遮挡的真实煤块网格。辅助按钮支持键盘。正常、减少动画与静默存档恢复共享同一姿态；未接受的拿取取消、暂停、失焦时恢复，落定后才报进度，销毁释放网格、材质、灯光、音效、提示和监听器。

三分镜、匿名视角、单块煤、布垫、建筑、火焰与动画为原创简化，不是固定仪轨、数量或资格；不声称整场拜访已完成或好运必然发生。[来源卡](../../../../content/traditions/scottish-first-footing.md)与[逐项研究](../../../../docs/research/2026-10-23-scottish-first-footing.md)分别记录传统事实和产品表达。

此前验收覆盖实际煤块顶点及结构净空、门槛空间、生命周期、主物拾取与遮挡、三宽全步骤鼠标、原生触摸事件模拟、离线和原生小组件封面；模拟不是真机测试。此前报告位于本工作区 `artifacts/scottish-first-footing/validation.md`，本轮当前控制以顶部说明和审阅 C 为准。


## 2026-10-26 当前跟手安放

本轮的物件搬运步骤改为拿住真实物件跟随手指，移到当前提示范围即自动落稳。不再以固定方向、最短拖距或必须松手判断摆放成功。同一根手指的后续移动与释放不操作下一步；取消只撤回尚未接受的拿取。键盘辅助、减少动画、旧检查点和原有文化语境保留。此前段落中关于这些搬运步骤的短拖、20%预览和松手才接受描述为旧实现，以本节为当前机制。屏幕落区、吸附和短程落稳是产品输入安排，不新增传统礼序、次数或功效。[逐步审阅和本轮验证](../../../../docs/research/2026-10-26-spatial-placement-audit-a.md)。
