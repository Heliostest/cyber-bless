## 2026-10-28 当前连续操作

拿起糕铲并把家人份送入盘中合并为一次连续搬运，可选择转动查看。糕片和糕铲虽然是兄弟节点，平移与旋看均按同一刚体变换同步；落到盘中后才抽出糕铲。旧 0/1 到 2 后仍单独取出槽内硬币，保留家庭分糕与藏币语境，不把取币写为统一仪轨。普通离手留位；取消、失焦、暂停和尺寸改变同时恢复糕与铲。最终仍为 3。

下方 2026-10-26 及更早的固定分段控制说明为历史实现，以本节为当前操作。路径合并、自由查看、触控容差与辅助按钮均属产品输入安排，不新增传统步骤或功效；原器物、来源事实、技术 ID、引擎与存档格式不变。实际边界与验证见[C 组连续安放审阅](../../../../docs/research/2026-10-28-continuous-placement-audit-c.md)。

托起家人份并送到盘中，糕片与糕铲一起跟手；随后将凹槽中的硬币送到盘边范围。铲退出、硬币离槽与转平落盘继续由短动作接续。

操作 0、1、2 在持有移动中按真实物件锚点或布面覆盖核对目标，到位即接续落定，不再以指定方向、固定拖距或松手作为摆放成功条件。未到位的取消恢复当前检查点；已经接受的同次触摸不能操作下一步。辅助按钮、减弱动态、暂停恢复和旧整数／variant 存档保持。
