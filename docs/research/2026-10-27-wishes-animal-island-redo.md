# 心愿页 Animal Island 风格回退与重做

日期：2026-10-27。

## 纠正范围

用户要求精简要素，并未要求更换正式 UI。首轮误用扁平浅绿底、深绿正文、普通标题和细分隔列表，覆盖了 Animal Island 的风格，已撤回这套处理。

本次重新阅读 [正式小岛 UI 规范](../design/island-shell.md)，恢复原有波点地面、燕尾飘带、圆体与字重、暖棕文字、沙色 HUD 卡片、软白边、糖果渐变按钮、按压台阶及四色浮动底栏。`App.tsx` 的 `wish-space` 类名改动已回退；`wishes.css` 仅保留版式和内容间距，不再覆盖根 token、标题、导航、按钮皮肤或卡片材质。

精简发生在内容：去掉重复静态灯图和宣传横幅，保留一处“去许愿”入口，心愿卡正文占主导；选择页使用双列小物卡片，直接选项只显示实际场景徽章与名称。未恢复直接填表保存的旧路径，仍先完成已有互动，再可选记愿。旧心愿、小物消耗、待处理草稿与奖励落点保持兼容。

## 来源影响核查

已重新阅读 [场景来源核查规范](../scene-provenance.md)。本次只恢复宿主视觉和精简选择页重复提示；没有修改场景器物、材料、动作、完成条件、介绍、传统事实或来源绑定。实际心意说明仍由场景原有内容呈现，沿用[既有来源影响核查](2026-10-27-wishes-simplification.md)与其中引用的场景心意、可选记录记录。没有重新登记外部来源读取状态，也没有新增文化事实。

核查：实际宿主内容已对照；无新增文化主张、错绑、寓意或规则；来源卡／注册表／模块 metadata／场景 README／原生标题未变，无需为本次布局改动同步更换来源。技术 ID 和存档版本未变。
