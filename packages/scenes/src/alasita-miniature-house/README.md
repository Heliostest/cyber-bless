查看后将完整小屋送到前方软垫放稳。 查看阶段不接纳安放输入，不保存进度或报告完成。界面呈现查看、安放两个动作点；旧 0／1／2 从原保存姿态开始查看，旧完成值 3 与最终接触条件保留，已完成状态不重播。取消、失焦、暂停或尺寸变化恢复未提交查看的相机、物件与环境；销毁时完整清理。
