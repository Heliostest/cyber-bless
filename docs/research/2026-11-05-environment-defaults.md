# 场景推荐树木与暖阳小镇成为默认

日期：2026-11-05。用户在确认全粉樱花后明确要求默认使用场景推荐树木及暖阳小镇配色。本记录替代此前「仅调试预览／正式默认不变」的状态说明。

## 最终行为

- 所有共享环境默认采用 `tiny-delivery` 的清亮蓝天、鲜绿草木、暖沙道路与柔和阴影；夜景仍保留夜景。
- 树木默认采用 `scene`。沿用已有九个映射：纸伞、绘马、铃绳、签筒和一般鸟居采用产品春景粉樱；厄尔士山木偶采用层叠针叶；空竹采用柳形；那不勒斯红角与瓦伦西亚折扇采用柱形柏。两份樱花资源均为用户指定的粉色。
- 没有明确推荐、固定正月／夏／秋语境、特定主题树及未核实地域的条目仍使用原树，不按国家名称推断树种。海岸无背景树的场景不强加树木。
- 正式渲染独立于调试台。调试台继续提供原有树木／色调和所有手动比较项，退出时恢复本轮正式默认，不写存档。
- 保留一套推荐树作为正式基准，临时比较独立加载和释放；分享同步捕获正式推荐树与暖阳配色，再恢复屏幕上的调试选择。默认树及天空尚未完成加载时暂不输出分享图；加载失败保留可用原景。
