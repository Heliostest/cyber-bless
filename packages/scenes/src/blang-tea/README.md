# 茶山一盏

## 当前产品收尾（2026-10-31）

进入独立的末尾静看／静候段后，使用柔和光泽变化（`glow`）；共享收尾不额外移动或转动目标，固定器物仍留在安放处。该段累计活动时间为3秒，减少动态为0.6秒并关闭共享收尾的位移／旋转；进度结束自动完成，无须再点物件或辅助按钮。前面的真实操作和既有动作动画不包含在这3秒内。

本场目标：`cup`。

独立模块若提供原生写愿表单，输入框获得焦点、IME组合输入或存在非空白未提交草稿时暂停自动计时，保留文字；明确提交仍沿用原保存路径。App继续在动作完成后提供可选祈愿，不把文字输入变成完成门槛。

暂停、失焦或页面隐藏时不计时；退出销毁不补发完成。恢复到原末尾静看检查点会重新播放收尾，已完成存档不重复奖励；尚未完成的物件操作保持原验收。

来源继续使用 `jingmai-tea-forest`，文化支持范围不变。3秒、0.6秒、柔光、轻摆、轻浮及自动结算均为产品表现，不是传统期限、仪式动作或功效。较早记录中的“再点静看／静听／静立”及以该点按结算的说明不再是当前完成条件。现有文化事实、外链读取状态、技术ID、引擎版本与存档格式保持；逐场范围与验证边界见[自动收尾集中记录](../../../../docs/research/2026-10-31-automatic-quiet-endings.md)。

## 2026-10-19 来源核查修正

现关联改为直接对应器物、工艺或节庆行为的专卡。原地区或宗教总卡不足以单独证明本场景的文化来源；具体证据及产品动作边界见下方审阅记录。

当前来源：`content/traditions/jingmai-tea-forest.md`。核查依据与原关联的问题见[全场景来源审阅](../../../../docs/research/2026-10-19-scene-culture-audit.md)。


原创当代茶歇，借茶具欣赏布朗茶山生态；不是茶祖祭礼、村寨仪式或寺院供养程序。不提供心愿表单。

文化核对：UNESCO World Heritage Centre, *Cultural Landscape of Old Tea Forests of the Jingmai Mountain in Pu’er*: https://whc.unesco.org/en/list/1665/ （2026-10-13 阅读）。该官方资料说明布朗族与傣族长期经营茶林，以及林下种茶、山地生态与社区管理的关系；它亦说明茶祖信仰的文化地位。本场景只取公开生态欣赏层，原创器型不声称是布朗族专属传统器物。

已阅读 `content/traditions/blang-traditional.md` 并查看其 JPG。图片为佛寺讲坛，只用于观察文化边界；未复制图片、纹样、模型或素材。

操作：`tea-scoop-grip` → `tea-pot-mouth`（茶匙木柄拖向敞开壶口）；`tea-pot-handle-grip` → `tea-cup-interior`（左侧壶把拖向右侧杯内）；`tea-cup-touch`（杯壁陶质指托轻点）。三步仅在有效输入或辅助按钮共用的完成路径上持久化 1/2/3。拖动物自身暂时跨过容器时，落点射线排除手持物，仍要求容器为最前可见网格。

茶壶空心旋转体，曲嘴与环把独立建模，倒茶绕下部壶把连接点抬升、倾斜并复位。杯与茶匙、盖子均有承托。所有几何与材质本地生成；无运行时网络或新增依赖。

## 2026-10-22 网点与像素可选预览

Shader Lab 新增手动网点印刷与复古像素，默认仍为柔和卡通。保留器形、材料身份、原纹样、动作、介绍与文化来源；本轮仅调整整体显示。技术参考、显示层核查和样本验证见[网点与像素记录](../../../../docs/research/2026-10-22-halftone-pixel-rendering.md)。

两项现支持网点大小、网点强度和像素大小实时调整，按当前浏览器及场景保存，并可分别重置参数与恢复内容默认。仍只改变整体显示，不新增文化主张或改变茶具动作。

Moebius 与卡通描边也支持实时调参：前者可调粗细、亮度色阶与排线强度，后者可调粗细与漫反射色阶；默认仍为柔和卡通。实现范围及验证见 [Moebius](../../../../docs/research/2026-10-22-moebius-rendering.md)与[卡通描边](../../../../docs/research/2026-10-22-toon-outline-rendering.md)记录，茶具动作与文化关联保持。
