# 可见仪式的器物材质扩展

用户在首批四场合并后要求继续处理其他仪式。沿用已确认的柔和手作方向与共用程序材质；本轮逐场审阅当前 91 个可见仪式，记录接入部件及明确保留的部件。67 个隐藏兼容场景不作为产品铺开目标。

- 木、陶、金属、布、绳按实际部件显式接入。必要时新增哑光竹、草茎和石面，不能把竹草一律当木材、把石料当陶釉。
- 为已有材质提供原位补丁 API，保留 Physical 子类、参数、动画引用、贴图和既有 ritual-optics 透光。共享颜色同时用于不同材料时拆分引用，不按颜色自动推断材料。
- 木鱼保留原 GLB 与颜色/细节资源；只对实际木质主体与槌添加弱程序纹理。原有纸、玻璃、液体、玉、皮肤、食物等专门材质继续工作，未经明确核对不叠加新表面。
- 不改几何、碰撞、交互、状态、文案、来源分类、ID、引擎版本或存档；新纹理属于产品美术，不新增木种、陶釉、合金、纤维、传统技法、起源或功效主张。
- 无新依赖、远程素材、透射或额外渲染目标；继续使用像素足迹滤波及无高阶导数的浮雕计算。
- 验收逐场来源/材料映射，真实 WebGL 前后画面、主风格与小屏显示、源材质恢复和销毁；更新受影响 README、来源卡产品呈现、研究记录与修订索引。

方案选择沿用首批：程序表面补丁与局部物理反光。整套写实替换会扩大风格和资源变化；单纯贴图不能覆盖无 UV 场景及卡通克隆。具体强度与接入范围由逐场材料审阅和实渲染决定。
