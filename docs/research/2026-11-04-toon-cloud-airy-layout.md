# 云带分布与日景通透感

最新调整：按用户“发灰、动态不够”的反馈补足 ACES 前的云层亮度、增强分层漂移并加入轻微内部起伏。下文配色/速度属于这一轮之前的状态；横向尺度、纵向布局和通透大气仍保留。当前实现和验证见[亮度与动态](2026-11-04-toon-cloud-luminous-motion.md)。

后续澄清：用户所指为纵向分布更开。横向已恢复原来的 1 倍，当前改为纵向拉开；下方横向 1.35 倍仅保留为历史尝试。已认可的天空/云色和远景雾通透感继续保留。

日期：2026-11-04（Asia/Shanghai）。用户认可 48 像素版本后，要求云层分布宽一些、大气更通透。

## 澄清后的当前布局

- 移除横向拉伸及其相位速度补偿，恢复原来的横向轮廓与漂移节奏。
- 六层相对纵向偏移从 0、16、33、51、70、90 调整为 0、22、45、69、94、120 CSS 像素，云带内部跨度增加约三分之一；层间距现在约 22～26 像素。
- 最上沿仍距场景画布顶部 48 CSS 像素，六层上沿为 48、70、93、117、142、168。近物遮挡、相机和夜景/海岸保留规则保持。
- 亮净天空、云色与轻减远雾维持上一轮效果。只纠正分布方向，不改器物、材料、动作、文化主张、来源身份或存档；沿用本文件既有核查与读取状态。
- 真实 WebGL 先确认旧横向尺度不符合复原目标，再调整实现。最终 24 组上沿为 48～48.5 像素，18 个独立层样本的横向尺度、纵向间隔、色阶/柔边与辅助深度均通过。证据为 `artifacts/toon-cloud/vertical-*.log` 与 `vertical/`。
- 此次 240 项环境回归、应用构建、158 场修订指纹和三个实际场景预览通过；没有页面/控制台错误。前后图为 `artifacts/toon-cloud/vertical-comparison.png`，旧横向版本的验证留在下方作为历史。

## 横向展开尝试（历史）

- 云轮廓只在横向拉伸 **1.35 倍**，减少相同画布内密集的小云峰；纵向尺度、48 CSS 像素最上沿和六层相对间距保持。相位速度按拉伸比例补偿，维持原来的屏幕漂移速度。
- CPU 的可见横向求界与 GLSL 使用相同拉伸比例，所以裁切、相机和 DPR 不改变上沿定位。
- 云色略微提亮、减少灰感；不透明度由远到近改为 .84、.87、.90、.93、.95、.97，让底层天空有少量透出，保留远蓝近白和清晰的近层边缘。
- 仅 85 个已启用云的 App 日景采用更明净的蓝天渐变。远景雾从 18–55 调整为 24–80 个场景单位，减轻远树和坡地的灰雾，仍保留远处大气透视。近处器物光照、IBL、相机、操作和遮挡不改变。
- 夜景、海岸和隐藏场景沿用原天空和雾，不将这一套晴朗效果套到它们上面。
