# 纸雏祈安

`mochigase-nagashibina@1`，来源 `mochigase-nagashibina`，祝福场景，无许愿输入。

一对薄纸雏、桃枝和菱形点心置于圆形稻草托盘。向上短拖托起，向右短拖移向缓流，向下短拖放入水中，接触水面后向下游漂开。真实网格承载与最近可见物件射线；动画落定才推进，取消、多指、回退、过短／过长、斜拖及遮挡不会推进。原生辅助按钮、减少动画与0–3恢复使用同一检查点。

来源为[鸟取用瀬流雏专卡](../../../../content/traditions/mochigase-nagashibina.md)，逐项证据见[研究](../../../../docs/research/2026-10-20-mochigase-nagashibina.md)。保留祓厄、无病息灾与成长语境；只呈现放流片段，没有模拟全年陈设或另行祈祷焚纳。三短拖、2.5秒、配色、纸衣、摆放、岸边和漂移距离为产品简化，不称固定传统步骤。

水面使用共享透明波纹与Voronoi焦散，几何水位固定，纸雏在水面上。水面与河床是两张效果平面，其余器物为闭合实体；减少动画保持水面时间。验证、真实截图、实际鼠标与CDP原生触摸事件模拟、独立审阅保存在 `artifacts/mochigase-nagashibina`。触摸模拟不是真机测试。
