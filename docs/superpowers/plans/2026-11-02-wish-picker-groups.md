# 许愿仪式按解锁状态分组

用户要求已解锁的仪式单独分类并放在最上面。WishRitualPicker 在排除待继续及未用小物对应场景后，将其余仪式分为已解锁、未解锁；已解锁先显示，未解锁置后并保留“完成一次仪式后解锁”提示，空分类不显示，组内保留原目录顺序。

沿用 isWishSceneUnlocked、确切小物 ID 和旧草稿入口，不更改存档、解锁条件、器物、场景动作、来源、意义或场景文案。依照 [来源核查规范](../../scene-provenance.md)判定仅宿主列表布局变化；无新增文化主张，无需重新访问外部来源。

验证：新增混合解锁顺序回归先失败后通过；选择器、新心愿、图标与仪式联动共 84 项测试通过。浏览器实际显示已用短册的已解锁入口在首组，未解锁卡仍禁用。复用现有八语言文案。
