# 浇水敬老

`thai-songkran-elders@1`：泰国宋干家庭中向长辈双手浇清水、敬老并求新岁祝福的片段。来源 slug `thai-songkran-elders`，意图 `blessing`，不要求留言。文化核查见 `docs/research/2026-10-20-thai-songkran-elders.md` 与对应来源卡。

捧起清水碗 → 移到长辈手边 → 缓缓浇水并放回。三次短拖方向上、右、下，辅助按钮完成相同动作。水从碗低侧开口落到真实双掌，再由手前沿落入接水盆；碗最终落回石垫，余水减少。长辈、木凳、盆与垫都在场；服装、家具、器形、三段交互是产品安排，不是统一器制或完整礼仪教学。

鼠标/触摸须命中可见碗实体；空白、反向、侧滑、短拖、过长、回拖、曲折、多触点及取消不推进。暂停/失焦、恢复、减弱动态、回调重入、卸载与存档边界有独立检查。模型的水平水面由碗内壁与世界水平面相交生成，效果网格不作命中代理。

静态/逐动作构图覆盖窄屏、手机与桌面；生成三种小组件封面并同步原生映射。验收与截图、鼠标动作视频、CDP原生触摸事件模拟报告保存在 `artifacts/thai-songkran-elders`。CDP触摸模拟不称真机测试；Windows环境没有进行Swift/Kotlin原生编译。完整最终结果以验收报告为准。
