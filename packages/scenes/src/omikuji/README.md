# 签纸慢读

## 2026-11-10 器物造型与手机手感

签筒顶面由方形块改为可见的圆形签孔与木圈；签棒加粗为圆角木签，顶端涂珊瑚色，下方三个小点是抽象刻号，不是真实签号或签文。签纸与信封改用低强度纸张透光与纤维材质；信封减薄，开口处加深内衬，封舌向后倾，封点旁加一对原创叶纹，读起来是信封而非小屋。镜头略为拉近，让签筒、签棒、签纸与信封在手机画面中更大。

手机输入：按下时以整件物件（含签筒徽纸、木纹、签棒刻点、签纸折边）为目标，并在实际可见几何外加约 22 像素指尖余量，较细的签棒不必精确按中；空白庭院不会被认领。被拿起的物件轻微放大以示已拿起，松手、取消或落定后恢复原尺寸；减少动态时不放大。只在成功落定时给一次触感的原契约保持。

文化影响：只改变产品美术与输入手感。签筒、编号签棒、签纸、信封四件器物，摇筒、抽棒展纸、收封的流程，原创提醒与信封收尾的产品归属，文字、完成条件、来源 `omikuji`、引擎与存档均保持；刻点与叶纹为原创装饰，不代表某寺社的签号、签文或纹章。沿用来源卡 2026-10-19/20 已读来源的支持范围，本轮未重新访问外链。[审阅、取舍与验证记录](../../../../docs/architecture/2026-11-10-ritual-prop-visual-mobile-audit.md)。
