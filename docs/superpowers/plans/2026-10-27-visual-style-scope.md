# 视觉风格应用范围

**目标：** 在现有仪式视觉风格面板选择样式或恢复默认后，确认仅当前仪式或应用到全部仪式，避免逐个重复设置。

**设计：** 沿用现有 React 面板与共享渲染器。单纯批量写入已挂载场景会漏掉其他仪式，因此保存一个全局偏好，逐仪式偏好作为覆盖；应用全部时清除既有覆盖。保留未来打开场景、远程场景及旧存档兼容，不枚举场景 ID。

选择样式先预览，显示范围确认；取消、返回或 Escape 撤销未确认预览，先回到风格列表。确认后保存，微调沿用本次确认范围并显示说明；重新打开面板时微调默认仅当前仪式。恢复默认也确认范围：当前恢复该仪式的内容默认，全部恢复各自的内容默认。
