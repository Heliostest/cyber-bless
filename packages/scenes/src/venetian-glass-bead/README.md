# 玻珠凝彩

原创青绿玻珠、彩色装饰线与小型金属芯棒。参考意大利公开玻璃珠工艺，表现绕纹、冷却后穿线、静看的三步互动。

- 场景：`venetian-glass-bead`；来源卡：`content/traditions/italian-glass-beads.md`。
- 向上轻拖芯棒使彩纹旋绕成形，再向右移动玻珠穿入细绳，轻点静看。
- 玻璃保持透光与光泽，和陶盘、金属、细绳形成材质差异。
- 支持物体手势、键盘辅助动作、减少动态效果、暂停取消与进度恢复。
- 几何、纹样和动画由程序原创；省略退火等工序，不模拟完整热加工过程。

模块测试使用真实 Three.js 几何、投射与软卡通材质适配器，仅替代 WebGL 硬件接口。跨场景适配器、移动触摸及生产渲染由仓库验收脚本覆盖。
