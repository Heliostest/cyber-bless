# 场景提示的轻盈动效

日期：2026-11-06。范围：共享操作点、Three.js 提示标牌及连接线。

## 设计与选库

采用轻柔、克制的节奏：标牌从下方约 7px 浮入并减速停稳，正文保持清楚；操作点低幅呼吸，细连接线稍后显现。步骤切换交接新旧提示，拖动中的操作点降低存在感并暂停光圈。没有持续晃动正文、逐字打字或大幅弹跳。减少动态效果时直接显示稳定终态；暂停、隐藏和卸载时停止刷新并释放资源。

已阅读以下官方相关正文（2026-11-06）：

- [Anime.js Animation](https://animejs.com/documentation/animation/)：支持 DOM、普通对象的属性动画及手动播放控制。适合直接驱动 Three.js 材质透明度与屏幕空间位移，项目已经使用 Anime.js 4。
- [Anime.js Scope](https://animejs.com/documentation/scope/)：组件范围和减少动态效果的媒体查询示例。
- [Motion AnimatePresence](https://motion.dev/docs/react-animate-presence)：适合 React 元素的进出场，本项目的可见提示由 Three.js Sprite 绘制，接入收益有限。
- [GSAP matchMedia](https://gsap.com/docs/v3/GSAP/gsap.matchMedia()/)：支持媒体查询与动画上下文清理；本次短过渡不需要另引擎。

选用现有 Anime.js；仅在 scene-runtime 明确声明直接依赖。不改场景交互和文案。

## 实现与验证计划

1. 在标牌中加入手动采样的 Anime.js 过渡；共享提示层按需刷新，遵循宿主 active / reducedMotion 和系统偏好。
2. 细化底板、边缘、字重及连接线；操作点保持精确锚定，呼吸幅度更柔和。
3. 验证快速切换、暂停、减少动态效果、窄屏边缘与 GPU 清理；运行运行时相关测试、类型检查和构建，再用真实浏览器检查点按、拖动和多语言场景。
