# 红白寄春 · romanian-martisor@1

红白纤维春绳带两只流苏，佩戴结束后挂上开花果枝。对应罗马尼亚 Mărțișor 习俗中的片段；佩戴寄托健康与好运的信念有博物馆正文依据，不能解释为本应用带来健康。

1. 按红流苏向上短拖，提起树下已解下的春绳。
2. 向右短拖，让开放中心的绳环套过花枝自由端。
3. 向下短拖，绳环落至枝面承托，流苏垂下。

纤维双股网格、无底板绳环、树枝与两流苏均为原创几何。枝轴z、中心(.55,1.5)、半径.055，绳环上内缘距中心.208，最终环心y1.347；动作沿自由端进入后轻放。固定环形与可见收束结、树下起点、套入方法、三段方向、花形与色彩、辅助按钮和反馈是产品简化，不是传统步骤或统一次数。无固定佩戴期限、愿望输入或收益/疗效承诺。不要将单独的三次拖动登记为已证实仪式程序。

支持物件射线命中、短拖轨迹检查、取消还原、活动状态暂停、各步恢复、键盘辅助、减少动态与一次性销毁。手势完成后正常播放.85秒动作，动画落定才回调进度。祈福场景池与专用来源卡绑定，非许愿输入场景。
