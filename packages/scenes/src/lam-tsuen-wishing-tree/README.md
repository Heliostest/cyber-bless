# 林村抛愿 / lam-tsuen-wishing-tree

现代林村仿真许愿树的写愿、系橙与抛挂片段。来源卡：`content/traditions/lam-tsuen-wishing-tree.md`；逐项证据：`docs/research/2026-10-19-lam-tsuen-wishing-tree.md`。

宝牒向右短划留下示例平安字；塑料橙向右短拖系绳；再向上短拖抛挂枝头。真实不透明物件命中，普通模式落定才推进，减弱动态直接落定，键盘操作同一检查点。取消恢复字迹、绳段与物件；拒绝空白、反向、短距、横偏、往返、多触点、非有限值及仅抬手输入。0/1/2/3可静默恢复。完整释放几何、材质、事件、音频与GPU。

固定字样、三步、短拖、绳结与飞行轨迹、比例/配色/铺面为产品表达，不是统一传统动作或原址模型。仅仿真树和塑料橙；不把挂上枝头当成愿望已实现。WISH池，独立图标/意向/标题/三档原生封面。

宿主通用回访／还愿重走仅为应用内感谢记录，不声称是林村地方还愿仪式。封面采用公开固定“平安”的完成态，不涉及个人愿望数据。
