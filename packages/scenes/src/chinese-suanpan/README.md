# 拨珠见数

原创七档上二下五式算盘。三步为个位三颗下珠向上靠梁、个位一颗上珠向下靠梁、十位一颗下珠向上靠梁，依次表示 3、8、18。木珠沿各自竹杆滑动，不经过横梁、不互相穿透；具体数值由真实珠位表达。

每步拿住指定算珠沿其竹杆移动，实际靠近横梁后自动落稳；横向偏移不会把算珠从杆上摘走，不以固定像素拖距或路径历史决定成败。辅助按钮支持 Enter/Space，0–3整数进度静默恢复。错误表面、未靠梁便松手、多点以及到位前取消、失焦或暂停均不推进；到位后同一手指不能继续拨下一组珠。完成只派发一次事件，不建立心愿。

这是固定的当代数学文化场景，不是自由运算器或传统仪式。文化来源与原创范围见 content/traditions/chinese-zhusuan.md。运行证据位于 artifacts/chinese-suanpan，长期接续进度位于 artifacts/hourly-scenes/progress.md。
