本次修改标题、介绍面板、字体、场景和底栏的布局以及 textarea 自适应；未改变器物、动作、完成条件、寓意、来源或场景身份。文化影响判断沿用 [2026-10-19 核查](2026-10-19-scene-culture-audit.md) 与 [现行规范](../scene-provenance.md)。介绍文字的翻译由同源词表提供，文化语义复核与排版测试分开报告。

## 实现

- 移除按字符数除宽度的字号算法；完整标题按词/语言规则换行，装饰 ribbon 随内容增长，场景顶部栏自动增高。
- 介绍面板先限制可用宽度，再测量换行后的按钮宽高。面板、占位与正文顶部共享实测高度；字体、语言、视口与按钮尺寸变化后重测，保留焦点和介绍打开状态。
- `useAppLayout` 测量底栏的真实高度/底距；场景控件占用空间不足时，内容区域滚动，画布保留至少 224px 的交互高度。异步存储初始化后才出现的宿主也会安装测量器，语言/进度变化无需销毁场景。
- Hans/Hant/日文/韩文使用各自的本地系统字体栈，Hant/日文/韩文不再经过 SC 字体。Nunito 移除人为的 U+00FF 截断，让原字体内的扩展拉丁与标点正常使用；完整系统字体作为组合重音等字形的离线后备。
- 本轮没有新增字体文件或下载字体，因此字体资产体积不变（现有 Noto Sans SC 5,706,516 字节，三份 Nunito 合计 49,332 字节，既有 OFL 随包）。区域字体依赖平台预装字体，实际选用结果由浏览器报告记录，真机仍需检查。
- 删除 CSS 绘制的中文“辅助”，使用场景 worker 提供的 DOM 标签，并保留完整动作的无障碍名称。心愿器物架在 360px 以下和大字模式可用两列；保留当前未提交的心愿改版。
- textarea 在值、宽度、字体和文档语言变化后重新适应高度，保持草稿、选区和焦点。

### 扩展测试实际发现并修复的问题

1. **隐藏计数标签逃逸：** 法语大字计数的 `.sr-only` 绝对定位静态坐标越到 x381，令 320px 文档宽度增到 382px。让计数 pill 建立定位上下文，避免隐藏标签越出边界。
2. **收藏与目录长词溢出：** 收藏标题原在 72px 槽中有 80–111px 的文字滚动宽度；目录的 `kadomatsu` 在 160px 槽中占 171px。补正常断词/连字符与紧急换行，大字收藏网格改为两列。
3. **拉丁语铭牌沿用中式竖排：** 实际法语截图仍为 `vertical-rl` 和 3px 字距。改为横排正常字距，并在固定装饰架下方用普通流排布；大字 CJK 也回流，完整文字可随页面滚动。
4. **661 用例中的覆盖缺口：** 宿主视觉复核发现收藏数量仍显示 `6…`。此前选择器未包括 `.count-pill`，不能把该轮结果解释成所有文字均无裁切。新增计数本体的滚动宽度断言后先得到真实失败（法语 148px 内容被限制在 68px），再将标题操作区改为可换行的普通流，移除计数省略。32 用例回归确认八语言三种视图的计数 `scrollWidth === clientWidth`；法语现在完整显示 `6 souvenirs`。这次修改仅调整 `style.css`，未改译文。
5. **底栏原全称超过约定两行：** 新增 Range 实际行数检查后，收集到英文 Little World、日文小さな世界/マイページ、韩文 나만의 공간、西文 Pequeño Mundo/Mi espacio、葡文 Pequeno Mundo、法文 Petit Monde 在 320px/200% 中占 3–4 行；法语 Aujourd’hui 也由宿主先行视觉发现。宿主为底栏增加独立短标签（例如 World、Monde、世界），仍以原完整译名提供 `aria-label`。最终 32 用例硬断言全部通过；同时验证计数完整、标签 1–2 行、足够触控尺寸、视口内位置与真实按钮中心命中。未以缩小字号或省略文字处理。

### 字体与证据边界

Windows Chromium 的样本实际字体：Hans 为 Microsoft YaHei，Hant 为 Microsoft JhengHei，日文为 Yu Gothic，韩文为 Malgun Gothic 搭配 Nunito，英/西/葡/法的扩展拉丁、弯引号和组合重音均由当前 Nunito 提供。字体故障测试各中断了 3 次请求，三份 Nunito 均进入 `error`；法语回退到 Microsoft YaHei UI，Hant 回退到 Microsoft JhengHei。以上只说明当前 Windows 的实际行为，不替代 WKWebView/Android WebView 字体测试。

已抽看法语/繁体计数、韩文介绍、伪语言设置和间距截图，以及最终英文/法文底栏截图，并未声称逐张人工复核所有截图。截图来自 Vite DEV：既有 Shader Lab 浮层仍可覆盖导航局部，它属于开发工具，不代表发布版本 UI；动作断言检查的是指定按钮的可触达点击中心，不宣称整个开发页没有任何浮层遮挡。

这些执行用例有重叠复查，不能相加后称为不同功能数。浏览器仅实操一场代表场景，没有验证全部 87 个公开场景，更没有完成所有原生读屏、真实键盘、真实系统大字或母语审校。开发画廊/场景页面检查独立报告，本 worker 另读取其实际结果并抽看法语场景/日语画廊截图；该报告还确认操作一步后法语/日语→英文→原语言时 canvas、辅助按钮和 checkpoint 保留、文字变化后恢复，未将该代表检查外推为全部开发场景已验收。
