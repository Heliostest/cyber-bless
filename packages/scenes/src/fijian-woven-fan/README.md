## 实体与交互

叶面为挤出闭合几何，独立编叶条有厚度与交错起伏，芦框沿轮廓闭合，细绑线绕过前后表面，背面肋条连接木柄与边框。配色为草叶 `#d9bd7f`、芦褐 `#ad8751`、鼠尾草 `#788b63`，收口环正面有一处克制的赭色。无透明拾取平面、粒子或装饰 UI。

收口环从桌前垫面移动到木柄颈部后，归入 `fan-body`，之后随完整叶扇一起移动。初始木柄底面接触 `fan-home-seat`；完成陈列后接触 `fan-display-seat`，展座底板、立柱、承托面依次接触。

所有 cue 的局部 anchor 均为 `[0, 0, 0]`，中心指向对应实体 mesh 的首个不透明命中面：
