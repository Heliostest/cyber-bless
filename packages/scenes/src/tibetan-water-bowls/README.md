# 清水七供

ID与来源slug：tibetan-water-bowls；引擎 tibetan-water-bowls@1；grade C；sensitivity 中；gestures drag。

佛像前高供台上的七只铜碗已有少量清水。用户拿住水壶跟手移动，提到第一只供碗上方，再依次对准当前碗的倾水准备位置，最后放回供台一侧，共九个界面步骤。到位后自动接续短程落位／倾水；每次只添当前一碗，下一碗等待新的操作。每碗实际接水时水位上升，移至下一碗前停止水流；所有水面停在碗沿下。物件拾取、目标外不接受、到位前取消还原、持指不串步、九个检查点、普通与减少动画恢复、键盘44px辅助按钮及资源释放均单独验证。

这是藏传佛教七碗供水的有限添水片段。传统关联、来源正文段落、读取状态及未外推范围见[来源专卡](../../../../content/traditions/tibetan-water-bowls.md)和[研究记录](../../../../docs/research/2026-10-20-tibetan-water-bowls.md)。坐佛、陶壶、供台结构、配色、相对尺度、触屏目标与容差、日景和动画属于原创呈现；未复刻特定神圣形象、未表现完整仪轨、未声称功德或回向已完成。
