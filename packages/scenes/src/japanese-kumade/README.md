# 熊手纳福

japanese-kumade@1，C／低／drag，来源[japanese-kumade](../../../../content/traditions/japanese-kumade.md)，[核查记录](../../../../docs/research/2026-10-23-japanese-kumade.md)。

装饰熊手在日本被视为招福、祈愿生意兴隆的吉祥物。神社说明将它与把福气耙拢的愿望和神佛加护的信仰联系起来，并介绍在清净处陈设。竹熊手与装饰差异有机构采访对应，也有当代带台自立形式。上述是机构自身实践说明、采访或地方综述，不把信念写成现实财富保证。

竹色七爪熊手已安在宽底木座，依次把三枚金色椭圆纸饰从左准备架移近，贴放到左右爪身和柄上方。七爪、三枚、纸饰形状/材质配色、连续扁条示意造型、连接贴面、木座实槽、准备架、庭院和三次跟手贴饰及动画时长是产品安排；不把三步或三枚说成传统要求。没有神札、神名、神像、人物面具或授与/开光操作，也不表现实际扫入钱财或完整宗教礼仪。

真实不透明纸饰命中，纸饰随手指移动，到当前贴饰目标自动接受，短程贴稳后推进。取消回检查点，接受动画暂停冻结并恢复续行；静默还原不另存愿望。支持键盘代替，CDP触摸为事件模拟不称真机。历史证据位于artifacts/japanese-kumade/，本轮验证见下节。
