## 共同处理与证据边界

- 步骤数量以动作决定。清水七供从提壶、整排自动添水、收壶三段，展开为提壶、逐碗七次、收壶九步。其余有据三圈、三次绕行或合理的三段物件操作予以保留，不为凑数加入新礼序。
- 木齿响器、村落秋千、牵绳木偶完成首轮三次有效操作后继续可用，出现「结束仪式」；最终进度 3 只由结束按钮触发。原有进度 1、2 仍恢复相应物件姿态，旧完成 3 不重开。铁舌、竹蜓、木柶行棋已有持续机制，保留并统一收尾文案；铁舌首次演奏前隐藏结束按钮。这些最低量、保存、收尾均为产品规则。
- 竹筛、陶鸡、香炉、彩墙小板与食物篮过去仅认目的面精确射线，且缺少到位提示。本轮使用已有 `createTouchTarget` 的最大 22 CSS px 真实可见表面容差、`placementHit` 的握持偏心落点与 `createDropFeedback` 的可以松手提示；手持组合整体忽略，其他前景物仍阻挡。篮中面包和彩蛋的初始拾取仍精确区分，避免邻近食物串选。绘牌的起笔暖色点也改用已存在的触摸容差。没有增设隐形大型碰撞体。
- 柳枝祝福、抚牛仍残留 `end <= 84`、`backtrack <= 9` 等严苛旧阈值，已接共享方向判定，支持同向长拖、合理斜拖及小纠正。其他共享方向场景本轮配合宿主补足稀疏 down→up 事件，负例改成无所属指针的孤立 up，而非把有效长拖误当负例。
- 纯容错与收尾调整未改变器形、材料、宗教与节庆背景、寓意、来源归属或真实动作；沿用各 README 已链接的 2026-10-19 来源审阅、2026-10-20 介绍核查及 2026-10-23 操作记录，不把旧记录登记为本日新读来源。仅七供展开重新核对直接正文。
