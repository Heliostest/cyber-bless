# 窗布祈护 / brat-bride-cloth

圣布里吉德节前夜把布留在户外窗台、盼圣人祝福与保护的有限公开民俗语境，见[专卡](../../../../content/traditions/brat-bride-cloth.md)和[逐项研究](../../../../docs/research/2026-10-23-brat-bride-cloth.md)。求愈为历史信念，屏幕操作不承诺效果。

方布向上提离木凳，继续向上移至窗外，再向下轻落铺好。闭合双层布面与封边复用同一position/normal buffer，始末真实落在凳面.32和窗台.88，中途留足高度越过外沿。真实网格近处命中、22px边界容差、40px及持续长拖、取消全部形态恢复、暂停/重入隔离、44px键盘及完整释放遵循宿主契约。

窗框、石木造型、素面蓝绿布与浅边、形态、厚度、用量、台凳、三步路径/时长/回访均为产品安排。没有折编、系结、浸井、擦身、治疗或显示圣人；暮色不代表一夜已经过去，完成只表示布已放好。户外侧由窗框后方与向外延伸的窗台明确呈现。
