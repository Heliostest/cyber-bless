# Audio inspector implementation plan

**Goal:** Web 开发调试台开关显示可独立试听的界面音效角标。

**Architecture:** 操作处声明 cue，开发组件绘制不占布局的角标，App 提供只试听的现有播放器入口；主 App 不重建。

**Tech Stack:** React 19、TypeScript、现有 Web Audio、Vitest、Playwright。

**Spec:** ../specs/2026-11-03-audio-inspector-design.md

## Constraints and review focus

- 仅开发宿主注入控制台；默认关闭，无存档开关、无新增音频素材。
- 试听不得执行业务处理或振动；静音/后台/关闭时不补播。
- 弹层事件拦截、滚动剪裁、禁用状态、动态 cue 和当前标签均须验证。
- 弹窗内角标须在对应容器内，避免被原弹窗当作外部点击。
- 无文化主张或场景动作变化，不新增猜测的场景音色映射。
