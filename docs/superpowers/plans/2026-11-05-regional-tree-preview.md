# Regional tree preview implementation plan

**Goal:** 在现有调试台提供不同树形和有证据范围的按场景推荐。
**Spec:** `docs/superpowers/specs/2026-11-05-regional-tree-preview-design.md`
**Architecture:** 资源目录解析 + 显式景观推荐表 + 既有调试事务式加载器；正式默认不变。

- [x] 核对地区园林/具体场地与季节的直接来源，保存证据与保留原景的边界。
- [x] 取得并离线生成真实源柱形柏、垂柳、层叠针叶树和可用樱花，保留固定版本、许可与哈希。
- [x] 先写目录解析、推荐回退和按种类加载测试，再扩展注册表与加载器。
- [x] 先写调试 UI 测试，再加入场景推荐、手动树形与八语言文案。
- [x] 同步离线打包、来源 README/研究/相关场景 README 和渲染说明。
- [x] 验证资产确定性、相关回归、构建及真实 WebGL 各树种切换/取消/恢复/地区推荐。

交付：九个明确场景建议、四种手动树形、原来源选项保留。正式默认与正式分享树景保留原景；Jogoss 署名与适配通知可见。274个 scene-runtime 测试、7个相关 App 测试、202个相关场景测试、4个离线打包检查和 Web构建通过。最终十一份 GLB随两宿主打包，精修后的两个柱形柏复制哈希核对一致。最终 WebGL复核102个来源/树形×风格组合、九个推荐、冬景回退与截图隔离均通过，无 shader/page 错误和外部资源请求，重复恢复资源计数稳定。158场景测试版本检查通过。来源事实与访问限制详见研究记录，不声称已测手机帧率。
