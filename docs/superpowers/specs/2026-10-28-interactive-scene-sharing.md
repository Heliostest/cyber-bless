# 互动场景链接分享

用户希望分享接收者能看到真实 Three.js 场景，并找到 App Store 应用链接。用户已选择本轮先完成本地版本，公开网址稍后配置；不注册、部署或发布新站点。

沿用现有 Web 应用，新增静态 `share.html` 入口。对比完整 App 深链接与专用 SDK，独立网页能直接展示实际场景，无需登录、安装或新用户开场，也避免静态托管的路径重写要求。当前 App Store Connect 应用 ID 为 6821271597，入口使用 `https://apps.apple.com/app/id6821271597`；链接可配置/替换，不声称应用已在各地区上架。

页面复用正式木鱼或程序化场景引擎及环境、shader，不重新搭建简化模型。显示场景标题、可交互舞台、重新体验、声音开关及 App Store 入口；初始静音，用户主动打开声音。未知链接可恢复，后台暂停，退出释放资源。

链接仅包含版本、公开可见内置场景 ID、语言及经白名单校验的视觉设置。不得加入私人心愿、会话、收藏、身份、任意远程模型或场景代码地址。场景进度仅存于页面内存，页面不读取或修改 App 存档。

App 分享弹窗增加互动场景的预览、分享和复制链接，并保留图片分享。原生通过 RN Share 发文字和 URL，Web 用 Web Share 或复制。未配置公开 HTTPS 地址时不对外分享本机或占位网址；本地 Web 可打开本机预览，提示互动链接尚未开放。`VITE_PUBLIC_SHARE_BASE_URL` 与 `EXPO_PUBLIC_SHARE_BASE_URL` 在部署后填写。

本轮只改变分享入口和独立网页体验，不改变器物、动作、完成条件、文化介绍、来源绑定或技术 ID。遵守 docs/scene-provenance.md；沿用既有来源核查，不增加文化寓意或功效主张。新控件维护八语言；实际技术验证和文化影响分别记录。
