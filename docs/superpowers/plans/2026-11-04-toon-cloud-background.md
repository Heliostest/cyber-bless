# Toon Cloud Background Implementation Plan

**Goal:** 为经幡、鲤旗、短册加入通透的远景云层。

**Architecture:** `toon-cloud-backdrop.ts` 独立持有六层云的几何、材质与更新时间；`cozy-environment.ts` 负责限定场景、时间、释放。复用已有场景生命周期。

**Tech Stack:** TypeScript、Three.js r170、Vitest、Playwright。

**Spec:** [设计](../specs/2026-11-04-toon-cloud-background-design.md)
