# 鱼生捞起

新加坡农历新年聚餐中共同捞拌鱼生、向亲友同事互道新年祝愿的片段。前方筷子探入七彩大盘，与同桌筷子一起捞起食材，再让食材落回盘中。盘、鱼片、菜丝、脆片和手持筷子都由 Three.js 实体网格构成。

来源核查见[专卡](../../../../content/traditions/yusheng-lohei.md)及[逐项研究](../../../../docs/research/2026-10-23-yusheng-lohei.md)。采用共同捞起版本；不把潮州各自蘸食等版本合成一套统一规则。三位同桌、三段短拖、握姿、食材数量／造型、配色与动画为产品安排，未模拟完整备菜、逐项加料或用餐；无愿望输入、祷告完成或效果保证。

模型的 `pose(step, amount)` 为连续检查点，普通动画、减少动画与恢复一致。触控需对可见筷子作有效方向短拖；另提供键盘操作按钮；错误物件、过短、反向、绕行、取消、失焦与回调重入均遵循既有生命周期规范。落定才记录进度。

2026-10-24 手机容错改为接受同向长拖、合理斜拖和小幅纠正，并提示何时可松手；有效按下后，释放终点也参与采样。不新增文化动作或传统次数，仍是一次捞拌片段。见[逐场审阅](../../../../docs/research/2026-10-24-scene-interaction-review-b.md)。
