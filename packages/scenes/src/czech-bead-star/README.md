# 珠星映光 · czech-bead-star

## 当前操作（2026-10-28）

先把木托上的最后一串珠接到真实星臂接点；接好后直接进入可选查看，左右拖动可连续转看整圈，随后轻点珠星或现有辅助按钮静看。无须先向右转动、经过固定角度或转满一周。两指在同一珠星上移动、Shift 鼠标拖动、右键拖动也能查看。原生辅助按钮上的左右方向键转看，Escape 恢复规范朝向；按钮激活直接静看。

珠星始终悬在支架上，只绕吊点所在竖轴转动，不作使挂环脱钩的俯仰。普通离手保留当前朝向，旋看本身不提交进度；取消、失焦、宿主停用或尺寸变化恢复规范朝向。真实接珠保留为独立组装，完成接珠报告旧检查点 2，轻点静看报告 3。旧检查点 1／2 都可不转动直接静看。接珠、自由查看及轻点静看是本产品的表达，不声称工艺传统要求此顺序或旋看次数。

## 资料与地区边界

2026-10-14 核对 [UNESCO — Handmade production of Christmas tree decorations from blown glass beads，01559](https://ich.unesco.org/en/RL/handmade-production-of-christmas-tree-decorations-from-blown-glass-beads-01559) 的完整搜索索引正文与 [UNESCO 列入名录决定](https://ich.unesco.org/en/Decisions/15.COM/8.b.25)。资料记载：捷克北波希米亚的 Giant / Jizera 山区，以加热玻璃管吹制珠串，经镀银、着色和装饰后裁成短串或单珠，穿到铁线上组合成饰物。它是专门的玻璃工艺，2020 年列入代表作名录。

当前采用 `czech-glass-bead-ornaments` 专卡，来源为北波希米亚空心玻珠工艺。已阅读该本地地区卡，未使用卡片照片作为模型或贴图。内部 C/低分类不代表 UNESCO 对应用的认可或授权。

六角开放星体、银蓝配色、珠体比例、穿线路径、木托和交互均为原创简化；不复制任何现有工匠作品的装饰图样，不是完整的吹珠制作教程。仅从机构资料采用材料与连接方式。

## 实体结构

67 个不透明珠壳使用带内壁和切口边缘的旋转几何。每颗珠的轴向贯穿孔保持开放；真实射线可穿过孔，而侧面仍命中实体珠壳。珠串之间留有空隙，细铁线穿过轴孔并连接星臂、中心环与挂环。没有实体填满星体内部，也没有透明拾取代理。

银白 `#dce8e8`、浅蓝 `#739daf`、淡金 `#c8b779`、木色 `#bfa587`。银蓝珠体保留低粗糙度与适量金属反射；`toonSurface` 显式保留这些参数，避免生产环境的 `toon-soft` 默认材质覆盖光泽。暖日光与冷色边光显出圆珠体积，透明画布由宿主接入日光环境。

独立珠串先停在小木托上。接合后，它属于 `bead-star-body`，其铁线两端分别到达既有银珠接点与星臂尖端。随后整个星体及最后一串珠一起绕竖轴旋转；它始终通过顶部铁线环与木支架相连。

## 浏览器动作与提示

所有 cue 使用实体 mesh 的局部 `[0, 0, 0]`。珠孔轴位于星体平面内，因此正面中心射线落在珠壳侧壁，提示没有落在空孔中。

| 检查点 | 来源 mesh | 操作 / 目标 |
| --- | --- | --- |
| 0 → 2 | `bead-strand-grip` | 拖至 `bead-star-arm-joint`，真实锚点到位自动接合 |
| 旧 1／2 保持 | `bead-star-center` 或其他实际珠星表面 | 任意左右拖转；两指／Shift／右键也可查看，无须固定方向、角度或圈数 |
| 旧 1／2 → 3 | `bead-star-center` 或其他实际珠星表面 | 轻点静看，或激活现有辅助按钮 |

每次横向移动即时改变星体朝向，累计角度不限，纵向移动不使星体俯仰。普通离手停留当前角度；旋转、纵向绕路、回到起点均不自动静看。取消、捕获丢失、失焦、宿主停用及 ResizeObserver 尺寸变化恢复规范朝向而不提交。原先右移 45 CSS px、至少 0.45 rad、强制停在 0.65 rad 的验收属于历史实现，已经移除。

来源必须是场景中实际可见不透明物体的首个射线命中。接合时仅排除手中珠串自身，其他不透明物体仍会阻挡目标。背景空白、木托和错误落点不会推进。完整组名为 `bead-star-body`、`bead-loose-strand`，整体根为 `bead-workbench`。

## 生命周期和验证

0–3 检查点静默恢复。指针使用 `createFreePlacementPointer`；同物两指允许旋看，无关第二触点或第三触点仍取消本次输入。取消、捕获丢失、失焦与宿主暂停不会提交新进度；离手后的查看姿态在停用／失焦／resize 时同样恢复。已接受的接珠过渡在暂停时冻结，恢复后最多提交一次。准备反馈、进度、触觉及完成回调期间锁住输入和递归更新；指针事件的捕获保护也阻止同步派发的移动事件取消原动作。宿主在回调中暂停或销毁后，不再渲染、播放声音、触发额外触觉或发出完成事件。

销毁幂等释放几何、材质、灯光阴影、渲染器、交互 cue、观察器、窗口与局部监听器。没有外部模型或贴图资产。
