# 月下一灯

## 2026-10-26 移除旧图片仪式

旧灯笼会话现使用本 Three.js 引擎的点灯、挂木牌与静看，移除参考图片的点击递增入口。原有三段进度、会话及结算 ID 兼容；隐藏策略不变。沿用下文 `product-original` 的器物与动作说明，无新增文化主张。故障处理与验证范围见[清理记录](../../../../docs/research/2026-10-26-threejs-only-rituals.md)。

`lantern@1` 呈现木架、竹骨纸灯和可悬挂木牌。点按灯身点亮，挂起木牌，再点按灯身静看结束；留言可选。灯留在架下，不升空、不入水。

## 2026-10-20 介绍核查

用户介绍在 [`scene-narratives/original.ts`](../../../core/src/scene-narratives/original.ts) 维护。它介绍当代小景的器物、动作与个人心愿，没有国家、节庆、起源或祈福效力的主张。最终分类继续为 `product-original`，宿主省略 `traditionSlug`；无需为原创动作组合创建传统来源卡。

实际实现、产品表达和不适用项见[研究记录](../../../../docs/research/2026-10-20-scene-narratives-original.md#六个产品原创场景)。本次未改技术 ID、存档、隐藏策略、交互或完成条件。


## 2026-10-26 当前跟手安放

本轮只将木牌挂灯下改为跟手到目标自动落稳；其他旋转、描线、抚触或结束动作保留原语义。不再以固定方向、最短拖距或必须松手判断摆放成功。同一根手指的后续移动与释放不操作下一步；取消只撤回尚未接受的拿取。键盘辅助、减少动画、旧检查点和原有文化语境保留。此前段落中关于这些搬运步骤的短拖、20%预览和松手才接受描述为旧实现，以本节为当前机制。屏幕落区、吸附和短程落稳是产品输入安排，不新增传统礼序、次数或功效。[逐步审阅和本轮验证](../../../../docs/research/2026-10-26-spatial-placement-audit-a.md)。
