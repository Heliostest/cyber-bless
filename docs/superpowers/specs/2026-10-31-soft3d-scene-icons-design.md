# 仪式图标柔和 3D 风格

用户已确认 `assets/design-previews/ritual-soft3d-samples-v1.png`，并明确要求把全部仪式图标替换成这一风格。本次授权包含生成与接入，无需再次确认风格。

范围是现有 SceneIcon 的全部 158 个技术 ID（91 个当前可见、67 个旧收藏兼容）。保持 SceneBadge、SceneArt 的调用与现有 Animal Island 皮肤。采用真实生成的单物透明图与 256px WebP，保留原生成 PNG、提示词及物件清单。柔光、统一视角、清楚轮廓与柔和体积统一；纸、木、玻璃、金属、织物各自保留材料身份。

物件依据现有 SVG 与场景实现，不新增器形、纹样、文字、传统步骤、寓意或来源。生成结果不是文化事实证据。来源、场景实现、原生标题、存档与引擎版本保持；仅 UI 装饰性图像改变。按 `docs/scene-provenance.md` 核对最终图像，明显多造的符号、错物件、材料或状态必须重做。

沿用既有 assetUrl/静态素材打包链路，兼容 Vite Web 和 Expo DOM 离线。未知 ID 保持叶子后备；图片失败有安全后备。图片装饰性 alt 为空，不重复朗读标题。无文字附在正式图像里。

方案比较：CSS/SVG 加阴影无法达到用户已选效果。生产采用六张独立生成源及规则透明九宫格图集，统一同批光照后按透明间隙确定性裁切成独立文件；图集和原切片均保留。对串格、器形、数量、状态和符号偏差逐项复核并重生成修复图集，防止直接拆图把错误带入正式素材。

验收：158/158 素材存在、透明且尺寸一致；App 测试与生产构建通过；检查今日、场景目录、心愿选择及收藏后备；320/390px 下小图清楚且无溢出；输出总览供复查。
