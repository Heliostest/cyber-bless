# 柊鰯守门 / hiiragi-iwashi

有限呈现日本节分的柊鰯：已烤鰯头插在带尖叶的日本柊枝上，设置入口，寄托魔除与护家的传统心意。主来源为村松山虚空蔵堂、光市公开食文化卡及日本玩具博物馆的实际设置记录；日本柊对生叶参考同志社女子大学教授说明。详见[专属来源卡](../../../../content/traditions/hiiragi-iwashi.md)与[研究记录](../../../../docs/research/2026-10-20-hiiragi-iwashi.md)。

## 实物与交互

- 0→1：按住成对尖叶的柊枝向上短拖，提起并转为直立。
- 1→2：按住备好的烤鱼头向左短拖，抬高、移到枝端上方再插合。
- 2→3：按住柊枝向上短拖，把整件移到门边，枝底落入承托座。
- 每步为2.5秒连续动画。按住时仅预览当前动作；取消、失焦与失去指针归属恢复检查点。物件的真实网格决定命中，支持44px键盘辅助按钮。
- 鱼头的闭合体有真实插入孔；枝上凸起承接鱼头，托座内底承接枝端。尖叶是有厚度的闭合几何；没有图片平面替代器物。

三段分镜、朝向、刺入孔位置、承托凸起与托座、叶数、门和石阶造型、比例、日景均为产品安排，不宣称传统制式、全国统一期限或完整节分礼序。没有愿望输入、应验保证或计分。标题、宿主、模块、图标、祈福池和原生小组件一致采用本ID；旧撒豆场景保持原状。
