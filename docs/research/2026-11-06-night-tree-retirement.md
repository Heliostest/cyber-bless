# 移除夜景简模树并复用不同树形

2026-11-06，用户要求删除特别简单的原树，替换为不同的新树木。实际检查确认：日景的原树为两种非对称 KayKit 阔叶模型；七个夜景仍通过 `nature-kit.data.json` 的 `tree-round`、`tree-pine` 使用球状树冠／锥形松树。此记录接续 [Komorebi 默认画风及恢复原树](2026-11-06-komorebi-defaults.md)，只替换这套夜景简模；不统一换成 Komorebi 树。

## 实际呈现与实现

| 场景 | 器物及原交互范围 | 新背景树形 |
| --- | --- | --- |
| `brat-bride-cloth` | 窗、布与展示操作 | 绿色槭形 |
| `scottish-first-footing` | 门、煤块与炉边摆放 | 层叠针叶形 |
| `chinese-shadow-puppet` | 影偶、操纵杆与灯幕 | 椿形复叶 |
| `diya-oil-lamp` | 油灯盘与点灯 | 绿色槭形 |
| `votive-candle-catholic` | 烛架与摆放点灯 | 柱形柏形 |
| `lantern` | 灯架、灯笼与点亮 | 绿色槭形 |
| `yeondeunghoe` | 莲灯、悬挂与上浮 | 椿形复叶 |

直接复用已离线打包的 Just a simple tree 分枝／叶簇模型及现有产品改编，沿用两份种子变体、近景构图、阴影、风和资源管理。没有生成或下载新模型。源模型与 MIT 许可、原始读取范围及改编边界见 [资源说明](../../assets/environments/trees/simple-tree/README.md)。

`getSceneTreeRecommendation` 的九个地区／季节候选保持原样；另以 `getSceneTreeDefault` 组合既有推荐和七个夜景的纯美术搭配。界面提示改为背景树形搭配，不再把所有场景搭配都描述为经地区核实的物种。场景目录标签按实际显示更新。Komorebi 树仍仅为可选树种，选择后才加载；现有草地、光照与调色保持。

两份退役简模从运行时 JSON 移除，离线生成器也跳过其输出，保留原始许可与来源档案。其余自然道具经深比较保持一致。夜景的原树比较／加载失败回退复用日景的两种详细 KayKit 阔叶模型，不再构建退役简模。夜景原种植位置和大致高度保留，中央器物、局部灯火与操作区域不变。分享与重置使用新的逐场默认树形，分享后恢复当前临时比较。

## 文化关联核查

依照 [场景来源规范](../scene-provenance.md)核对实际器物、操作与背景：本轮七个树形均为产品布景选择，不声称是某地原生／优势物种、仪式规定植物、节期景观或园林复刻。保留 [既有文化核查](2026-10-19-scene-culture-audit.md)、各场景 README 与 [地区证据记录](2026-11-05-regional-tree-evidence.md)的支持范围；本轮未重新访问外部文化链接，不改变其实际读取状态，不把已有代码作为新增文化事实的证据。

窗布、炉边煤块、影偶、油灯、烛架、灯笼与莲灯的器形、实质材质、动作、数量、顺序、完成条件、介绍、寓意和来源身份不变。日景已有推荐与排除项、菩提树／许愿树／竹等主题植物、海岸留空保持。七份场景 README、资源说明、调试文档、目录树形标签与回归同步；来源卡、宿主注册与模块 metadata 的文化字段、标题、技术 ID 和存档不变。

规范清单：实际呈现已核对；没有新增传统主张；没有按地区或视觉相似绑定来源；没有新增功效、起源、资格或节期；产品背景树与主题植物分清；来源字段一致且沿用原记录；技术验证单独报告，不用于证明文化事实。

## 验证

新增夜景默认与资源失败回退测试先失败，再实现替换。验证日志和截图位于 `artifacts/night-trees/`。

- scene-runtime 全量 32 个文件、343 项测试通过，包含七个夜景资源失败、原树比较与捕获回退；App 全量 69 个文件、1708 项测试通过。
- `npm run build` 通过，国际化、TypeScript 与 Vite 无失败；保留现有大分块体积提示。
- `node scripts/prepare-nature-props.mjs --report artifacts/night-trees/nature-report.json` 校验原始源文件哈希、几何属性和索引后，输出 11 份剩余道具、87961 字节（gzip 13631）、1075 三角形；与删除前除退役两树外的全部数据深比较相等。
- `node scripts/verify-komorebi-defaults.mjs` 检查 21 个代表场景，包含全部七个夜景及日景旧树、樱花、柳形、针叶形、玻璃、主题树、水面与空海岸，另检查 21 个窄屏视口；没有浏览器错误或渲染风格回退。
- 默认进入不加载 Komorebi 树，可选加载成功；正式分享使用逐场树木与 Komorebi 默认草地／调色，之后恢复临时比较；重置恢复 `scene`，未写入 localStorage。
- 人工查看全部七个夜景的桌面／窄屏联系表，核对灯火、器物、交互区和枝叶构图。`overview.png` 为替换后，`comparison.png` 上排为原简模、下排为新树形。
- `npm run scene:revisions:check` 覆盖 158 个场景通过；`git diff --check` 通过。未执行正式 iOS 构建／上传或真机 GPU 基准。
