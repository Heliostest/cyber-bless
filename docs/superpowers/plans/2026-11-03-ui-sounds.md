# UI Sounds Implementation Plan

> **For agentic workers:** Use superpowers:executing-plans with independent leaf tasks delegated in parallel. Steps use checkbox (`- [x]`) syntax for tracking.

**Goal:** 为 Three.js 内部操作以外的正式 App 界面提供统一、轻柔可爱的声音反馈。

**Architecture:** 使用 Kenney Interface Sounds 的 CC0 短音，离线打包为 WAV，App 内独立的 UI 播放器复用已有 AudioContext 和声音总开关。界面在明确语义边界调用 `uiSound`，现有保存／收下／完成音保持原实现，结果操作的导航静默。

**Tech Stack:** React、TypeScript、Web Audio、现有 Vite／Expo public 资源打包、Vitest、Playwright。

**Spec:** [操作映射](../../research/2026-11-03-ui-operations-audio-audit.md)。用户已明确选择“按推荐直接接入并验证，音色细节由你决定，无需再审方案”。

## Global Constraints

- 不修改 Three.js 内部交互及其声音、场景文案、文化归属或存档格式。
- 沿用 `settings.sound`，UI 声音不自动增加震动；关闭立即停止、后台不补播。
- 保留 `saved/collect/complete`，同次语义操作不叠一般点击与导航声。
- 输入、滚动、拖动、自动导航、初始恢复、无变化与禁用操作保持安静。
- 无新依赖、无在线音频请求、无原生音频桥接；内测工具和独立分享网页保持安静。
- 使用当前工作目录的新分支 `codex/ui-sound-feedback`；直接执行授权下不再询问工作区／计划。用户后续已授权提交、合并和推送至 `master`；不开正式原生构建、不发布。

## Review Focus

- `go/back` 同时被主动操作和 effect 调用：显式 UI 调用才发声，自动路径不响。
- 关闭菜单有 pointerdown、click、Esc 和 native back 多路径：只在真实开→关时响一次。
- 异步复制／写入失败、静音或后台后返回：无迟到成功音。
- 首次解锁与资源解码：只预加载本地资源，不排队补响，缺失音频安静降级。
- 风格滚动、滑块、小物拖动尾部 click：无误发声；现有材质音不叠通用 UI 音。

### Task 1: 本地音频播放器和素材

**Files:** `packages/app/src/ui-sounds.ts`、`ui-sounds.test.ts`、`ui-sound-assets.ts`，`assets/ui-sounds/`，`scripts/prepare-app-assets.mjs` 与打包测试。

**Interfaces:** 导出 `UiSound = 'navigate'|'back'|'select'|'open'|'close'|'toggleOn'|'toggleOff'|'notice'|'saved'`。`createUiSoundPlayer({context:()=>AudioContext|null, enabled:()=>boolean})` 返回 `preload/prepare/play/stop/dispose`；`play` 接受排除 `saved` 的短音，`saved` 由 App 复用既有结果播放器。`preload` 只拉取本地音频字节，`prepare` 在用户手势解锁后解码；未就绪的播放丢弃、不延迟补播。

- [x] 用失败测试固定静音、资源未就绪、解码完成不自动发声、并发／限频和 stop/dispose 行为。
- [x] 从已核对的原始包转换短 WAV，保留许可／来源／hash，限峰值并柔化音头。
- [x] 实现播放器并让测试通过；加入两个宿主的资源清单和 hash 验证。

### Task 2: App 集成与核心页面

**Files:** `context.tsx`、`App.tsx`、`pages.tsx`、`wishes.tsx`、`home.tsx`、`wish-ritual-picker.tsx`、`wish-ritual-rack.tsx`、`legal.tsx`、`widget-navigation.tsx` 与行为测试。

**Interfaces:** Context 新增可选 `uiSound?(sound: UiSound): void`（测试与独立宿主可缺省）。`go(route, options?: {sound?:'navigate'|'back'|false})` 与 `back(options?: {sound?:boolean})` 默认无声音，真实用户入口显式选择；不在 updater/effect 中发声。App 统一处理 `settings` 与 `scene.favorite/wish.archive` 的有效变化，组件不重复加声。显式保存／收下后的 go 不传声音。

- [x] 用集成测试先固定同页静音、自动导航静音、开关生效与后台取消。
- [x] 集成 UI 播放器与生命周期；首次用户手势 prepare；总开关关闭停止；`uiSound('saved')` 走现有结果播放器。
- [x] 为核心页面主动导航、筛选、展开与浏览接线，保留小物触碰既有材质音。
- [x] 运行相关 App 测试与 TypeScript 检查。
