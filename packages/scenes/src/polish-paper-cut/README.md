# 剪纸开花

## 2026-10-19 来源核查修正

现关联改为直接对应器物、工艺或节庆行为的专卡。原地区或宗教总卡不足以单独证明本场景的文化来源；具体证据及产品动作边界见下方审阅记录。

当前来源：`content/traditions/polish-wycinanki.md`。核查依据与原关联的问题见[全场景来源审阅](../../../../docs/research/2026-10-19-scene-culture-audit.md)。


以波兰民间剪纸的折叠、剪切与对称镂空为背景，制作原创花叶轮廓的当代工艺欣赏场景。只完成预先剪好图案的最后一道纸边，再展开折纸；这是缩略的材料体验，不是完整手艺教学，也不复刻特定地区、匠人或馆藏的纹样。当前来源为 `polish-wycinanki` 剪纸专卡，C / 低是本应用的设计分级。

深青色纸置于平放在木桌上的奶白切割垫上，垫面有浅色网格；俯视镜头让纸花成为主体，宽桌面延伸出画面边缘。纸张采用有真实厚度及孔壁的挤出几何，活动半幅绕中央折轴展开；最后一道连接边会随剪刀经过而缩短，放手后才释放边角料。刀刃、铆钉、手柄颈与两个中空柄环均为可见实体。剪刀手柄与边角料落在垫面上。场景采用便于理解的现代枢轴剪刀，不声称重建历史上使用的剪羊毛剪刀。

## 三个动作

1. 从右侧真实剪刀开始，向屏幕上方拖动至少 **42 px** 后松手。需要实际 `pointermove`；横向最大偏移不得超过 `max(20 px, 向上距离 × 0.55)`。推荐自动化拖动 **64 px**。剪刀沿纸边移动并开合，边角料落至切割垫右下。
2. 在折纸右边缘向屏幕左方拖动至少 **48 px** 后松手。起点必须先命中活动纸幅，局部坐标满足 `x ≥ 0.72`、`-0.10 ≤ y ≤ 0.45`；垂直最大偏移不得超过 `max(20 px, 向左距离 × 0.45)`。推荐自动化拖动 **72 px**。两半纸幅在展开后保持相同厚度并形成左右镜像。
3. 轻点展开的任一纸幅静看，或通过现有心愿表单明确提交 1–40 字的心意。轻点的全程位移及终点位移都必须小于 **12 px**。草稿、恢复与还愿回访不会另存心愿。

原生辅助按钮至少 44×44 px，支持 Enter / Space，与物体手势完成相同步骤。减少动态模式接受相同手势并立即得到等价结果。手势起点和静看终点只接受最近的可见不透明物体；空白处、其他实体、错误方向、短拖动、只改变松手位置和拉回起点均不完成。

## 公开几何与自动化锚点

坐标均为具名物体的局部坐标，使用 `localToWorld` 后投影到画布。水平工作组 `paper-cutting-mat-group` 的位置为 `[0, 0.715, 0]`、X 旋转为 `-Math.PI / 2`。以下交互锚点与屏幕动作保持稳定。

| 检查点 | 实体名称 | 提示锚点 | 动作 |
| --- | --- | --- | --- |
| 0 | `paper-scissors-grip` | `[0, 0, 0.024]` | 向上 64 px |
| 1 | `paper-folded-half` | `[0.84, 0.20, 0.016]` | 向左 72 px |
| 2 | `paper-fixed-half` | `[0.32, 0.59, 0.016]` | 原位轻点 |

其他可观察实体包括 `paper-scissors`、`paper-final-cut-edge`、`paper-offcut`、`paper-fold-hinge`、`paper-cream-board` 与 `paper-workbench`。完整展开时 `paper-fold-hinge.rotation.y = -Math.PI`。辅助按钮在已接受动作的过渡中禁用，取消中的未接受动作复原并可重试。

## 来源与边界

- [Culture.pl / Adam Mickiewicz Institute — A Brief Guide to Paper Cutouts](https://culture.pl/en/article/kurpie-lowicz-kashubian-architectural-a-brief-guide-to-paper-cutouts)：折叠纸张后剪切形成对称镂空，地区风格存在差异。
- [华沙国家民族志博物馆 — Kobiece ręce](https://ethnomuseum.pl/kobiece-rece/)：彩纸、剪羊毛剪刀与室内装饰的工艺背景。

两篇机构材料用于解释材料与动作关系，未使用其图片或复制纹样。界面中的心愿是当代可选输入，不代表剪纸本身是宗教仪式，也不承诺结果或效力。
