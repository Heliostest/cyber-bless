## 当前操作（2026-10-26）

把大圆饼送到纸面、小圆饼送到大饼顶部，再把橙送到小饼顶部；每次到位后短落座，保持上下承托。

操作 0、1、2 在持有移动中按真实物件锚点或布面覆盖核对目标，到位即接续落定，不再以指定方向、固定拖距或松手作为摆放成功条件。未到位的取消恢复当前检查点；已经接受的同次触摸不能操作下一步。辅助按钮、减弱动态、暂停恢复和旧整数／variant 存档保持。

本次只更新产品输入及对应提示，器物、材料、动作顺序、文化含义与来源身份保持；没有新增传统规则。下方较早记录中关于方向、固定拖距和摆放松手验收的说明属于历史实现，当前输入以本节为准。具体逐场边界、来源状态与验证见[本轮 B 组记录](../../../../docs/research/2026-10-26-spatial-placement-audit-b.md)。

来源：日本正月迎接年神时的镜饼供物。两层圆饼相叠、顶放橙（だいだい），寄托家族代代兴盛的祝愿。见[专卡](../../../../content/traditions/kagami-mochi-offering.md)与[逐项核查](../../../../docs/research/2026-10-19-kagami-mochi-offering.md)，两条农林水产省相关正文已实际读，失败PDF未引用为证据。

呈现准备供物的片段：向上短拖大圆饼至纸面中央、小圆饼叠上、橙置顶。预备食品、三步短拖、轨迹、尺寸、配色和低木纸面支撑是产品简化，无完整祭祀、固定日期或应验宣称，不挪用镜开食用求健康。BLESSING场景，无许愿框。

物件射线只接受当前可见实体，遮挡、明显反向、过短拖动、纯横移、退回起点、取消及跨指针输入不推进；同向长拖、合理斜拖与小幅纠正可完成。松手后完成落座才记录一步；暂停冻结，恢复精确，还原检查点不发反馈。支持44px键盘按钮、减少动画、音效开关与资源清理。场景与模型测试覆盖这些行为和实际承托关系；来源与视觉另行独立审查。
