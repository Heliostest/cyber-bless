# 云层亮度与动态

日期：2026-11-04（Asia/Shanghai）。用户反馈当前云层发灰、动态不足，继续调整已接入的共享日景背景。

## 实际呈现与技术判断

既有 WebGL 外观夹具仅使用 NoToneMapping，未反映应用直接 ACES 和默认 toon-soft 后处理中的亮度压缩。在包含蓝天的真实色调映射测试中，旧版近层白色显示亮度约 .881/.882，远层约 .800/.809，静态场景截图也呈灰白。

- 云色改为淡蓝到亮白，六层输入线性辐亮度倍率为 1.65、1.75、2、2.3、2.7、3.2。保留现有 ACES，不改变前景曝光或全局渲染风格，不添加泛光；远层的蓝色与色阶继续承担景深。
- 相位时间系数 .08→.22，即原漂移的 2.75 倍，保持远慢近快和原圆盘轮廓。CPU 求界与 GLSL 使用同一常数。真实轮廓配准的两秒位移从远层约 3、近层约 13 CSS 像素，变成约 7、34 像素。
- 内部五层按各自频率正弦起伏，振幅最多 1.25 CSS 像素。最上层不加入起伏，仍在画布顶端 48 像素附近；横向原尺度与纵向相对偏移 0、22、45、69、94、120 保留。
- 继续复用环境时钟；暂停、缩略图不推进时钟，减少动态仍静止。不增加定时器、纹理、网格、材质或逐帧资源分配，辅助深度用的远处代理位置保留。
