# 菩提供水 / sri-lankan-bodhi-puja

关联斯里兰卡 Bodhi-pūjā 的菩提树供水片段，保留敬佛、作福与祈求护佑的宗教背景，不承诺现实效果。直接依据与读取状态见[专卡](../../../../content/traditions/sri-lankan-bodhi-puja.md)；逐项支持范围、访问缺口和去重见[研究记录](../../../../docs/research/2026-10-24-sri-lankan-bodhi-puja.md)。

本场将菩提树（Ficus religiosa）、根旁土壤、预备清水的有嘴水壶与承台置于一般化的寺院树旁空间：UP 提起水壶，RIGHT 移近树根，DOWN 倾水供养。水流朝可见树根周围土壤落下，完成时壶落稳于树根旁另一座承台。树形、壶型、材质与配色、比例、三向输入、时长、含水量、土色变化及完成反馈均为产品安排，不是规定的三步传统。

BPS 综述直接记述香水浴树，教育出版署教材的印刷第 16 页另明确记持壶向树根供水；本产品以透明清水简化表示气味，没有添加未制作的花瓣或香料。心形至阔卵形、细长叶尖和灰色树皮由 NParks 物种正文核对；不以植物形态资料证明仪式流程，也不声称某件供器或某株圣树的复刻。

本场不标阿努拉德普勒古树，不重建受限制的上层台地，不模拟供花、灯香、旗幡、诵偈、绕树或回向。这里只选取供水局部；完成仅确认屏幕动作结束，不表示完整仪式完成、功德认证或愿望应验。个人祝愿属于此刻表达。没有固定次数、期限、节期、资格或健康长寿保证。

## 模型与技术验证（2026-10-24）

`createBodhiPujaModel()` 返回 `bodhi-puja-subject` 与同一 `bodhi-water-pitcher`。浅灰分叉树干、可见树根、144 片封闭实体心形长尖叶及 144 条相连叶柄组成原创树木，三组叶片、叶中脉与叶柄共使用 5 个 InstancedMesh 批次。陶色水壶有连续中空腔体、真实内底与壶嘴，浅石色围边和两座承台落在同一块石板上；没有用封口圆盘冒充壶内空间。

水壶起始直立于左前承台，提起后绕开树干、围边和承台，第三段倾倒并回正落在另一座树旁承台。水流连接实际壶嘴与根旁土壤，局部湿润保留至完成态；液面在倾倒时保持水平并下降，结束仍留部分水，不暗示全部倒空。倾斜角、剩余水量、落水范围及湿土深浅只是模型参数，不是传统规范。环境对此场景使用 `floor=-.14`，自有石板从 `y=-.14` 到 `y=0`，承台与石板实体接触。

本场 76 项测试通过：8 项模型、66 项交互、2 项目录；场景 TypeScript 检查及正式构建通过。模型测试覆盖有限、外向封闭、无退化几何，中空壶体、全部叶片与叶柄连接、初末承托、动作路径采样避碰、真实壶嘴到土壤的水流、水平液面及持续湿土、连续端点与直接存档恢复、输入截断和重复资源释放。交互测试包含实际壶体拾取、三方向拖动、取消、回访及生命周期；技术一致性不代替来源审阅。
