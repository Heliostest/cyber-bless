# 折一只纸鹤

## 2026-10-19 来源核查修正

纸鹤的日本折纸与广岛和平文化有关联依据，现复用已有折纸鹤与千羽鹤专题卡；不再归为无来源的产品创作，也不将单只纸鹤说成千羽鹤实践。

当前来源：`content/traditions/origami-crane-senbazuru.md`。核查依据与原关联的问题见[全场景来源审阅](../../../../docs/research/2026-10-19-scene-culture-audit.md)。

## 2026-10-20 当前介绍核查

已按实际器物与用户提示扩充介绍。纸折颈尾双翼→托起→可留和平愿望；单只纸鹤。

核查重点：1955属于具体人物/纪念史，不是折纸鹤工艺起源；不称一只等同千羽、数量保证康复；留言和简化折法是产品。

逐项证据、实际阅读位置和访问状态见[本轮介绍研究记录](../../../../docs/research/2026-10-20-scene-narratives-a.md#crane)。

## 2026-10-22 Moebius 可选预览

Shader Lab 加入 Moebius 手绘漫画，可手动切换细墨线、色块与暗部排线。默认仍为柔和卡通，器物、纹样、材料身份、动作、介绍与文化来源保持。技术参考、产品表达边界和验证见[Moebius 渲染记录](../../../../docs/research/2026-10-22-moebius-rendering.md)。

## 2026-10-22 卡通描边可选预览

Shader Lab 新增手动卡通描边（三段明暗与深色外轮廓），默认仍为柔和卡通。器物、材料身份、纹样、操作与文化来源保持；技术参考及显示层核查见[卡通描边记录](../../../../docs/research/2026-10-22-toon-outline-rendering.md)。

## 2026-10-22 网点与像素可选预览

Shader Lab 新增手动网点印刷与复古像素，默认仍为柔和卡通。保留器形、材料身份、原纹样、动作、介绍与文化来源；本轮仅调整整体显示。技术参考、显示层核查和样本验证见[网点与像素记录](../../../../docs/research/2026-10-22-halftone-pixel-rendering.md)。

Moebius 现可调描边粗细、色阶与排线强度，参数按场景保存与重置；默认仍为柔和卡通。纸张正反面、折叠动作、介绍和文化来源保持。技术范围和本轮验证见 [Moebius 记录](../../../../docs/research/2026-10-22-moebius-rendering.md#同日追加可调参数)。
