# 薄饼相祝

`polish-oplatek-sharing@1`，来源卡同ID，grade C，敏感度低，进入祝福池。

平安夜家人分享 opłatek 薄饼、彼此祝愿。只呈现其中一次分取：递出整饼；家人接触后分一角；携小片收下祝愿。两位家人以不同来向、肤色和连续袖口表达。无桌、留言表单或普通手作附加寓意。

来源及访问状态：[来源卡](../../../../content/traditions/polish-oplatek-sharing.md)与[逐项研究](../../../../docs/research/2026-10-20-polish-oplatek-sharing.md)。三拖、庭院、几何星纹、断口与动画为原创产品表达，不教授完整 Wigilia 或圣餐。

## 几何与交互

主饼和分角是共用初始边界的两块闭合薄实体；分角移动前接收者手掌到达其底面，离开后跟随手部保持支撑。两组手从画面近处与远侧相对进入。袖口和前臂可有意延伸至画外，手掌／手指／薄饼逐顶点保持在画面内。星纹和边纹为实体浅浮雕。

鼠标／单指短拖方向上、右、上；真实最近不透明物件射线检测；错误方向、过短、长路径、折返、多触控、取消均不推进。释放后完成动画才存进度。原生按钮提供键盘路径；减少动态立即到同一终点；0–3进度可静默恢复。暂停冻结，返回释放GPU、事件与DOM。

晴朗柔和色阶由项目渲染器处理。不加载网络图像、字体或服务。小组件仅使用真实场景完成状态渲染的三种公共封面。

验收证据保存在 `artifacts/polish-oplatek-sharing/`，含三宽全步骤、鼠标与CDP触摸模拟、自然动作视频、独立审阅、构建离线报告。CDP模拟不是真机测试。

## 2026-10-23 操作容错
