# 仪式图片分享：文案与文化影响核对

核查日期：2026-10-28。

本次文案对应[图片分享设计](../superpowers/specs/2026-10-28-ritual-image-sharing.md)：仪式完成后生成本地场景图片，用户先预览，再选择系统分享或保存图片。新增分享、保存、关闭、重新生成、生成失败及设备不支持等产品提示，共 11 条；更新隐私政策既有分享段落，明确文字和场景图片都由用户主动选择分享、复制或保存。

这些控件和提示属于产品新增功能，不陈述器物、地域、社群、传统动作、顺序、期限、数量、起源或功效。沿用[场景来源与文化关联核查规范](../scene-provenance.md)及[既有场景来源审阅](2026-10-19-scene-culture-audit.md)；本次不调整来源卡、场景标题、宿主目录、注册表、模块 metadata、原生组件标题或技术 ID，也不借产品分享动作证明传统。图片仅在本地生成，不增加开发者分享服务器；用户仍自行决定接收者。

简体中文、繁体中文、英文、日文、韩文、西班牙文、葡萄牙文和法文均填写独立翻译。自审范围为这 11 条控件与提示和既有隐私分享段落：保留主动选择的含义，区分生成失败、暂时无法分享和设备不支持，不提示「发送成功」，不加入疗效、宗教功效或社交平台兼容承诺。未声称母语审校或真机显示验收。

复用已有「一日一念」「已完成」「取消」消息，隐私分享段落沿用既有消息 ID `app.legal-content.e89d2ed9ee`。其他工作区已有场景文案不在本次翻译审阅范围内，review manifest 仅更新 `app` 分组的内容哈希。

- `npm.cmd run i18n:check`：8 语言各 3037 条消息，缺失 0，ID、ICU、参数及 review 哈希校验通过。
- `npm.cmd run i18n:extract`：561 个文件的字面量注册检查通过；动态用户／远程内容仍由原有单独核查范围约束。
- `node scripts/i18n-compile.mjs --check`：生成内容一致。
- `npm.cmd run i18n:test`：22 个运行时国际化测试与 20 个目录／提取器测试通过。
- `npm.cmd run typecheck -w @wbr/i18n`：通过。

以上是分享界面整合中的本次运行结果，最终源文件变更后仍应进行集成验证；国际化结构测试不替代文化事实核查，也不证明系统分享目标在每台设备上均可用。
