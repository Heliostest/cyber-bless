# Eight-language i18n Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development or superpowers:executing-plans. Track steps using checkboxes.

**Goal:** Complete the approved offline localization and layout design across app, scenes and widgets.
**Architecture:** Pure @wbr/i18n owns locale resolution, ICU formatting and catalogs. React and imperative DOM adapters translate trusted product copy while preserving user text and engine identity. Native resources share the same catalogs.
**Tech Stack:** TypeScript, React 19, FormatJS, Expo SDK57, Swift/Kotlin, Vitest, Playwright.
**Spec:** [Approved design](../specs/2026-10-27-i18n-design.md), approved 2026-10-27.

## Shared interfaces

@wbr/i18n exports SupportedLocale, LocalePreference, SUPPORTED_LOCALES, LOCALE_NAMES;
resolveLocale(preference, preferredLocales) returns {locale, formatLocale};
getLocale(), getFormatLocale(), configureLocale(preference, preferredLocales?), subscribeLocale(listener);
message(id, values?, locale?), translate(source, values?, locale?), formatDate(at, options?), formatNumber(value), graphemeLength(text).
translate is exclusively for trusted source copy indexed to stable IDs. User text never goes through source lookup.

Catalogs: packages/i18n/src/catalogs/<locale>/{app,scenes,narratives,native}.json.
Root owns foundation/app/app-source.json and dependency lockfile. Scene worker owns scene/narrative catalogs and scene-source.json. Native worker owns native catalogs. Source index maps source to stable ID with source hash and context. Missing translations fail checking rather than being populated with source copies.
