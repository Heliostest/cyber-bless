# 煤火迎年 / scottish-first-footing

苏格兰 First-footing 携煤新年祝福片段。实际首屏和介绍明确：新年午夜后，你作为首位来客，向主人家送上煤礼及温暖安康的祝愿。煤从室外布垫拿起，经真实敞开的门框进入木地板区域，再从炉膛正面送入主人炉火；不是捡煤为自己取暖。

手势依次上、上、左；拾取只接受无遮挡的真实煤块网格。辅助按钮支持键盘。正常、减少动画与静默存档恢复共享同一姿态；取消、暂停、失焦恢复物件，落定后才报进度，销毁释放网格、材质、灯光、音效、提示和监听器。正确方向长拖及完成后的合理纠正可以松手，不设过拖上限。

三分镜、匿名视角、单块煤、布垫、建筑、火焰与动画为原创简化，不是固定仪轨、数量或资格；不声称整场拜访已完成或好运必然发生。[来源卡](../../../../content/traditions/scottish-first-footing.md)与[逐项研究](../../../../docs/research/2026-10-23-scottish-first-footing.md)分别记录传统事实和产品表达。

验收覆盖实际煤块顶点及结构净空、门槛空间、生命周期、主物拾取与遮挡、三宽全步骤鼠标、原生触摸事件模拟、离线和原生小组件封面；模拟不是真机测试。详细报告位于本工作区 `artifacts/scottish-first-footing/validation.md`。本次只开发一项，完成后停止。
