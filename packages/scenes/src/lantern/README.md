## 2026-10-28 纸面透光层次二次调校

纸罩采用与原有七条横向竹骨对齐的八段遮光近似：骨架位置减弱纸面漫反射与自发光，骨架间的纸面保留透光散射和纤维细节，灯芯附近较亮、上下收口较暗。纸张仍不透明，不增加独立透明壳层。加强纸面散射、降低整片纸罩的自发光上限，并将竹骨调为较深棕色，以保留点亮前后可见的骨架层次；点光源与夜间光晕继续随点亮进度变化，竹骨自身不发光。

这是实时材质的技术近似，不是纸材透射率或工艺结构的测量复原。默认柔和卡通中的纸罩保留平滑受光与曲面掠射衰减，使纸面亮度不再整片一致。仅调整纸面光学响应与竹骨明度，器形、骨架数量与位置、木架、木牌、动作、文案、来源身份及存档均沿用既有实现；文化影响继续采用上文来源核查，本次没有新增文化主张。场景测试核查遮光周期与实际骨架对齐、纸面不透明、点亮明暗变化及骨架不发光；最终明暗观感另以浏览器实渲染比较确认。[调校与真实前后对比记录](../../../../docs/research/2026-10-28-paper-lighting-refinement.md)。
