# 场景单屏与仪式反馈动效

> **For agentic workers:** 按下列任务实施；共享文件由主代理集成，组件和行为测试并行。

**Goal:** 仪式全程保持手机一屏，介绍由按钮连续展开为悬浮阅读框，完成小物在前景下方浮现并上浮隐去。

**Architecture:** 延续 React、现有岛屿界面与 SceneArt。场景路由建立固定视口高度链，画布适应剩余空间；介绍使用固定左上锚点的同一圆角外壳，完成反馈采用独立的非交互覆盖层。

**Tech Stack:** React / TypeScript / CSS transitions & keyframes / Vitest / Playwright。

**Spec:** 用户本轮明确的三项交互要求。

## 约束与设计决定

- `scene`、`ritual`、`complete` 的页面外层不滚动；阅读正文、技术详情和长文本仅在自己的框内滚动。
- 保留现有字体、薄荷色、暖纸底和场景图标。主要视觉变化集中在同壳展开与小物浮现。
- 介绍展开/收回均为 420ms ease-in-out；同一 22px 圆角与左上坐标不变，不对外壳做 scale。
- 完成小物约 4s：下方柔和浮现，停留约 2s，再向上淡出；不接管触摸和焦点，不重复发放奖励。
- 支持应用和系统减少动态、Escape、框外关闭、快速反转，以及 320px 宽和短屏。
- 文化影响仅为布局、阅读方式和产品完成反馈；引用现有 [场景核查](../../research/2026-10-24-scene-interaction-review.md)，不改变器物、动作、验收、正文与来源身份。

## Review Focus

- 已经完成的记录重新进入不得再次播放新完成反馈。
- 快速开合介绍时不能闪回端点或让关闭点击穿透场景。
- 软键盘打开后提交/取消可见，关闭后视口尺寸恢复。
- 小屏长提示及九步进度不能挡住手势目标或结束按钮。
- 离开仪式后恢复原有页面滚动和滚动位置。
