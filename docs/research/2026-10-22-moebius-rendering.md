# Shader Lab 可选 Moebius 手绘漫画

日期：2026-10-22。用户要求把前面已讨论的 Moebius 方向接入实际场景供手动切换，明确不设为默认。

## 技术参考与实现边界

Maxime Heckel，[Moebius-style post-processing and other stylized shaders](https://blog.maximeheckel.com/posts/moebius-style-post-processing/)，2024-03-26。2026-10-22 已读相关正文：深度读取、法线内轮廓、暗部阈值、交叉排线与背景抑制。本项目自行实现这些思路的轻量预览，不移植文章 shader，不复刻其全部科幻场景、抖动、完整 Sobel 核或高光图案。

- `moebius-effect.ts`：色调映射后处理，保留原色相的亮度色阶、静态线宽变化、三档暗部交叉排线。深度与法线相邻差异生成主体墨线，天空不处理，远景细节逐渐减弱。排线基于画面暗部，包括深色颜料，不声称是独立测量的真实投影阴影。
- `moebius-normals.ts`：仅为已有适配器的可描线主体生成法线／深度。保留单材质和材质数组各组的正面、背面、双面与几何位移设置；绘制后恢复材质。与主场景深度比较，避免遮挡物后面的主体透出墨线。
- 背景、草叶不逐片描墨；已有玻璃、金属、釉面、原纹样及动画通过共享适配器保留。透明材质不强行换成卡通材质，最终输出保留 alpha。
- `render-style.ts` 在手动选择 `moebius` 时分配附加缓冲；退出、切换和失败时沿用资源清理及原始渲染回退。
- Shader Lab 增加 `Moebius 手绘漫画`，内容白名单增加 `moebius`；旧值、缺省、存档与技术 ID 保持兼容。程序化场景、环境注册和木鱼的默认仍为 `toon-soft`，水粉 `gouache` 仍可手动选择。

## 同日追加：可调参数

Shader Lab 为 Moebius 增加描边采样宽度 0.25–3 CSS px、亮度色阶 2–12 级、排线强度 0–100%。初始 0.85 px／8 级／50% 与原 shader 常量相同；0 强度关闭排线，细墨线与明暗处理仍保留。参数每帧更新现有 uniform，DPR 变化时同步像素比例，不重建 composer。沿用已有按场景存储、范围检查与当前风格参数重置，旧记录缺少字段时补齐初值；默认仍为 `toon-soft`。

仍属于上述整体显示层产品表达，器形、材料身份、纹样、动作、介绍、寓意和来源不变。茶具与纸鹤 README 同步记录；沿用本文件既有文化核查，无新增传统主张。

验证：scene-runtime 138 项、生产构建和移动端类型检查通过。`test-shader-parameters.mjs` 的真实 UI／GPU 用例覆盖五项漫画／卡通参数各自改变画面、重置、切换与刷新保留、手机视口以及重复调整纹理数量稳定。Moebius 探针另覆盖背面纸张、最大描边／排线的前景遮挡和异常回退。

扩大遮挡检测区域后，旧 z=1 前景出现两个混色样本；强制 shader 原样输出、关闭主体墨线，乃至直接原始渲染时仍出现，不能据此判断墨线泄漏。将测试前景前移到 z=2 后通过；临时去掉 shader 深度门控的负对照仍可靠失败，确认修正后的检查能捕获被遮挡墨线。产品 shader 未因这一测试现象而改动。实际茶具与纸鹤的默认、切换、交互与手机视口复测记录位于 `artifacts/moebius-review/`；新滑杆截图及报告在 `artifacts/shader-parameters-review/`。
