## 2026-10-20 介绍扩充核查

适用场景：`spanish-castanets`；最终来源：`spanish-castanets`。

当前物件与动作：无手的两副系绳凹木壳，先左合、右合，随后可持续双壳合拍；点击「结束仪式」才收尾。
