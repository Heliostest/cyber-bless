# 柳枝祝春 / finnish-virpominen

## 2026-10-24 方向容错

取消旧84px上限与9px回退限制，采用共享方向判定，支持同向长拖、合理斜拖、小幅纠正和稀疏触摸事件，到位显示可以松手。明确反向、回起点、取消、多指与遮挡仍不推进。未改变器物、动作、寓意与来源；沿用本 README 的已有文化核查记录。[逐场审阅与验证](../../../../docs/research/2026-10-24-scene-interaction-review-a.md)。

基于thisisFINLAND现场报道的当代芬兰埃斯波邻里拜访：挥装饰猫柳枝送健康祝愿，递枝，再收下主人放入篮中的包装巧克力蛋。[来源卡](../../../../content/traditions/finnish-virpominen.md)与[核查记录](../../../../docs/research/2026-10-23-finnish-virpominen.md)区分具体实例、正教版本差异和产品简化。

按住柳枝向右短拖挥枝；再次向右短拖递给主人；按住巧克力蛋向左短拖，主人将谢礼放到篮底、松手并退出。全部为真实网格。纸花、配色、房门、手掌、编篮、摆放与三段2.5秒动画为原创分镜，不是传统固定次数或制式。柳枝交接与礼物落篮具有连续轨迹，取消恢复检查点，暂停冻结动作；44px辅助按钮支持键盘。
