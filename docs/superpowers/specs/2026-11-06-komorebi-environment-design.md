# Komorebi 环境比较

用户要求把当前 Komorebi 草地、树木、调色复用到 Cyber Bless，先在调试台切换，并实际截图审阅。

采用现有共享环境与调试注册机制：草地新增独立的 `original / komorebi` 会话覆盖；树木现有来源列表增加 `komorebi`；色调增加 `komorebi`。不重建业务场景，不写正式存档，折叠保留，调试台卸载和正式分享恢复现有默认。无草地/树木的环境不凭空增加对应内容。

直接固定并复用 Komorebi 的草叶/色场源代码、树木骨架和叶片生成源码。树木离线导出 GLB，运行时继续用现有实例化加载与事务式释放；不引入 Babylon 运行时依赖，不依赖相邻工作目录。调色复用当前日光、冷阴影及颜色曲线参数，按 Three.js 渲染链适配。

其他选择：直接跨仓库引用会破坏独立构建；整套迁入 Babylon 会新增引擎与生命周期。均不采用。保留当前 Three.js 和调试外壳。

这次仅变更产品背景植被与光色。没有新增树种地域、文化起源、寓意或仪式步骤主张；不替换文化主题树。依照 docs/scene-provenance.md，沿用既有 2026-10-19 全场景核查，另记录技术改动范围。

验收：共享日景、夜景、河岸及手机尺寸；独立切换与组合；相同 canvas、存档不变；跨场景保留草地/调色；恢复/分享/卸载清理；实际 WebGL 无错误；保存同镜头前后截图并人工查看。
