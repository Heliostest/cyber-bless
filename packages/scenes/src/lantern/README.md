## 当前产品收尾（2026-10-31）

进入独立的末尾静看／静候段后，使用悬挂物的轻摆（`sway`），只作小幅转动，不让物件离开挂点漂走。该段累计活动时间为3秒，减少动态为0.6秒并关闭共享收尾的位移／旋转；进度结束自动完成，无须再点物件或辅助按钮。前面的真实操作和既有动作动画不包含在这3秒内。

本场目标：`pivot`。

独立模块若提供原生写愿表单，输入框获得焦点、IME组合输入或存在非空白未提交草稿时暂停自动计时，保留文字；明确提交仍沿用原保存路径。App继续在动作完成后提供可选祈愿，不把文字输入变成完成门槛。

暂停、失焦或页面隐藏时不计时；退出销毁不补发完成。恢复到原末尾静看检查点会重新播放收尾，已完成存档不重复奖励；尚未完成的物件操作保持原验收。

来源仍为 `product-original`，不新建传统卡。3秒、0.6秒、柔光、轻摆、轻浮及自动结算均为产品表现，不是传统期限、仪式动作或功效。较早记录中的“再点静看／静听／静立”及以该点按结算的说明不再是当前完成条件。现有文化事实、外链读取状态、技术ID、引擎版本与存档格式保持；逐场范围与验证边界见[自动收尾集中记录](../../../../docs/research/2026-10-31-automatic-quiet-endings.md)。

## 2026-10-28 纸面透光层次二次调校

纸罩采用与原有七条横向竹骨对齐的八段遮光近似：骨架位置减弱纸面漫反射与自发光，骨架间的纸面保留透光散射和纤维细节，灯芯附近较亮、上下收口较暗。纸张仍不透明，不增加独立透明壳层。加强纸面散射、降低整片纸罩的自发光上限，并将竹骨调为较深棕色，以保留点亮前后可见的骨架层次；点光源与夜间光晕继续随点亮进度变化，竹骨自身不发光。

这是实时材质的技术近似，不是纸材透射率或工艺结构的测量复原。默认柔和卡通中的纸罩保留平滑受光与曲面掠射衰减，使纸面亮度不再整片一致。仅调整纸面光学响应与竹骨明度，器形、骨架数量与位置、木架、木牌、动作、文案、来源身份及存档均沿用既有实现；文化影响继续采用上文来源核查，本次没有新增文化主张。场景测试核查遮光周期与实际骨架对齐、纸面不透明、点亮明暗变化及骨架不发光；最终明暗观感另以浏览器实渲染比较确认。[调校与真实前后对比记录](../../../../docs/research/2026-10-28-paper-lighting-refinement.md)。
