日期：2026-11-08。范围为共用的 `packages/scene-runtime/src/cue-placard.ts`。

## 实际呈现与文化影响

本次仅调整提示卡与操作白点之间的连接线：由普通 WebGL 单像素线改为屏幕空间 2.5 CSS 像素的圆头线，颜色从 `#648b7b` 调为 `#527b68`，稳定态不透明度从 0.44 提高到 0.8。保留原有端点投影、随物体移动、进退场和减少动态处理；零长度的入场起始帧隐藏连接线。

依据[场景来源与文化关联核查规范](../scene-provenance.md)第 1 节，本次属于纯显示调整。沿用[既有场景来源核查记录](2026-10-19-scene-culture-audit.md)与各场景现有来源记录；器物、材料、操作、完成条件、提示文字、标题、寓意及来源绑定均未改变，没有新增文化事实，也没有将本次本地实现检查记为外部来源重读。来源卡、场景 README、宿主目录、注册表、模块 metadata 和原生标题无须因线宽调整而改写；技术 ID 与存档保持原状。
