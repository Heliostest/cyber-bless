# 迎风场景的远景云层

最新用户反馈：云层发灰、动态不足。按[亮度与动态记录](../../research/2026-11-04-toon-cloud-luminous-motion.md)补足 ACES 前亮度、提高远慢近快的漂移并为内层加入微弱起伏；保留 48 像素顶部、原横向尺度、已拉开的纵向层次和通透大气。下文减慢速度/降低饱和度等为初次移植时的历史设计。

后续调整：用户要求继续处理其他场景，适用范围已扩展为 App 可见的共享白天环境；排除夜景、海岸和隐藏历史场景。最终范围与镜头限制见[扩展核查](../../research/2026-11-04-toon-cloud-daylight-expansion.md)。下文保留首批三场的设计依据。

用户目标：将 Shader Gallery 的 `Three.js · Toon Cloud` 移植为合适场景的远处背景，提高通透感。

选择 App 当前可见的 `tibetan-prayer-flags`、`japanese-koinobori`、`tanzaku-tanabata`。器物处于户外挂起的空间，适合开阔天空。云层只表达产品布景，不构成地域、节庆或信仰主张。沿用各 README 中的已有来源核查。纸风车和纸鸢目前隐藏，不在本轮接入范围。

实现选择：保留原 shader 的圆盘轮廓、六层渐变与不同层速，适配为远景平面。相较直接复制 Gallery 的满屏青蓝云海，降低饱和度、减慢漂移、降低云边位置并留出蓝天；相较所有场景统一添加，仅对上述三场启用，保持适用范围明确。

云在草地和树林之后，不遮器物，不进入射线交互；天空材质不受场景雾二次覆盖。使用天空深度避免各场景短远裁面裁掉背景；保留位置透视。云时间复用环境已有的暂停、减少动态和缩略图冻结机制。场景独立持有资源并幂等释放，不引入远程依赖。

验收：三个场景的手机与桌面画面中主体清楚、天空有留白、云处远景；其他场景无云；暂停/减少动态/预览不推进时间；退出资源释放；相关测试、构建及场景修订指纹检查通过。
