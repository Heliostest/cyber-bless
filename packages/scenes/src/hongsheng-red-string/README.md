# 红绳自持

## 2026-10-19 来源核查修正

月老赤绳的文学故事不能证明绕架、合扣、自爱留言是一套传统手作。现保留红绳手作的个人心意，移除文学与当代民俗的来源暗示。

当前来源：`product-original`，App 目录省略 traditionSlug。核查依据与原关联的问题见[全场景来源审阅](../../../../docs/research/2026-10-19-scene-culture-audit.md)。

## 2026-10-20 介绍扩充

介绍补充线轴、槽道、绳环与合扣的关系，把照看自己的心意作为当代个人表达，不用月老文学为这套动作背书。正文在 [`scene-narratives/original.ts`](../../../core/src/scene-narratives/original.ts) 维护，逐项核对与文化归属不适用项见[本轮研究](../../../../docs/research/2026-10-20-scene-narratives-original.md#六个产品原创场景)。来源分类、隐藏策略、动作和可选留言行为均未改变。

## 2026-10-23 产品交互容错修正

绕线沿原有支架路线累计有序覆盖；低频移动事件和半步错相也按经过的线段计入。轻微偏出槽道再回正保留本次已绕部分，完成的绳段、变色圆点和百分比共同提示进度。

小对象起点采用可见表面附近的触摸容差，遮挡物仍会阻止拾取。取消、失焦或宿主暂停会丢弃未提交的本次手势，恢复后需重新拾取；辅助按钮仍可完成相同步骤。

本次仅调整产品输入容错、进度反馈和生命周期处理，不新增或改变文化主张、器物、原有动作次序及次数。技术 ID、来源分类和已保存检查点保持兼容；不把容错阈值写成传统要求。核查范围与验证见[本轮交互修复记录](../../../../docs/research/2026-10-23-scene-interaction-fixes.md)，文化事实仍沿用本 README 所链接的既有核查记录。

完整覆盖原有路线后，末点接受可见标记附近的 22 CSS 像素触摸余量；忽略手中物件及本次绘制的颜料，其他前景遮挡仍会阻止提交。走完路线后若离开末点，提示返回标记附近松手，不会把已有覆盖量显示成尚未描绘。


## 2026-10-26 当前跟手安放

本轮只将合扣改为跟手到目标自动落稳；其他旋转、描线、抚触或结束动作保留原语义。不再以固定方向、最短拖距或必须松手判断摆放成功。同一根手指的后续移动与释放不操作下一步；取消只撤回尚未接受的拿取。键盘辅助、减少动画、旧检查点和原有文化语境保留。此前段落中关于这些搬运步骤的短拖、20%预览和松手才接受描述为旧实现，以本节为当前机制。屏幕落区、吸附和短程落稳是产品输入安排，不新增传统礼序、次数或功效。[逐步审阅和本轮验证](../../../../docs/research/2026-10-26-spatial-placement-audit-a.md)。
