# 轻柔操作与结果音效

用户已授权按上一轮审计建议直接实现：先补完成、收下、保存成功，再补木鱼、纸鹤、倒水等操作音；整体轻柔可爱，遵守现有音效开关。

## 方案与范围

沿用 Web Audio，在 `@wbr/shared` 提供小型合成音库，App 与场景各自复用已有 AudioContext。相比录音资源，合成可保持离线、体积和统一音量；相比继续只调正弦短音，加入有限带通噪声与短共鸣可以区分纸、水和木材。此实现选择由代理按现有架构确定，不增加依赖或下载资源。

- complete：短上扬铃音；collect：轻落与圆润尾音；saved：两声轻音。
- woodfish：温和木质共鸣；paper：轻纸张摩擦；water：短水流与水滴；woodTap：木碰；beans：分散颗粒碰撞。
- App 在本次进度首次完成时发 complete；收下／奖励飞行触发 collect；心愿、心情和还愿的有效保存触发 saved。恢复存档、重复动作、失败保存不重播。
- 木鱼保留外部音频包能力，内置无录音时改为 woodfish；纸鹤折叠替换旧短三角波；清水七供、浇水敬老、泉水净币、开樽祝愿、节分撒豆、鱼生捞起在实际动作阶段加入对应声音。
- 不给导航和静看持续加声音，不更改场景可见范围、动作、规则或文化主张。

## 生命周期与验证

所有新声音每次活读当前开关；静音、暂停、后台、失焦、销毁时停止排程，不在恢复时补播。共享音库限制音量、时长与并发并回收节点，缺少 Web Audio 时安静降级。

先写会失败的测试，再实现：覆盖去重、恢复静音、失败操作、实时开关与后台取消，保持原有场景交互与原生桥接。完成后运行相关包、全仓测试与生产构建，浏览器实际操作检查合成调度及试听页导出。

文化影响：声音为产品风格化拟声，不称现场录音、传统曲调或完整复原。沿用 `docs/scene-provenance.md` 与 `docs/research/2026-10-19-scene-culture-audit.md`，不新增来源事实。
