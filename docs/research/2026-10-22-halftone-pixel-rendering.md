# Shader Lab 可选网点印刷与复古像素

日期：2026-10-22。用户选定两项技术参考，延续之前的手动预览方式加入 Shader Lab；默认仍为 `toon-soft`，保留水粉、Moebius 和卡通描边。

## 已读参考与实现

- Maxime Heckel，[Shades of Halftone](https://blog.maximeheckel.com/posts/shades-of-halftone/)，2026-02-10。2026-10-22 已读相关正文：圆点网格、单元中心取样、覆盖率与点半径、CMYK 通道及 15°／75°／0°／45° 旋转网格。本项目据此自行实现 `halftone-effect.ts`，采用四通道叠印、暖纸色、抗锯齿与原色混合；没有复制文章整套演示，也不加入随机动画或纸张抖动。
- Three.js，[Pixelation pass with optional single pixel outlines](https://threejs.org/examples/webgl_postprocessing_pixel.html)。2026-10-22 已读页面说明及本机 Three.js r170 `RenderPixelatedPass.js` 实现（MIT）。`pixel-art-pass.ts` 复用该版本的像素化着色器、目标与全屏四边形，桥接到现有 pmndrs 管线；保留约 3 CSS 像素的色块、深度边缘和法线边缘。没有复制最新官网版本或其场景、相机吸附和交互。

两项均保留源材质，不先替换为卡通材质：贴图、玻璃、金属、釉面和动态颜色继续来自实际场景。网点在色调映射后处理；像素化先以低分辨率渲染，再完成统一色调映射。透明画布保留 alpha，不给周围页面铺纸色。

像素法线复用按材质组保留正反面的 `MoebiusNormals`；与主画面深度比较，拒绝遮挡物后面的法线。无效样本使用固定单位法线，避免原版算法把零向量判作整片高光。r170 原 shader 的边缘强度会同时乘 alpha，本轮只让它影响 RGB，确保实体暗边仍不透明。每帧清空目标，避免移动物体留下旧影像。切换、卸载和失败时释放缓冲并恢复原始状态。

## 同日追加：实时调参

用户要求可在 Shader Lab 调整网点大小、效果强度与像素大小，仍不改默认风格。选中网点时显示 2–16 CSS px、0–100% 两项滑杆；选中像素时显示 1–12 CSS px。初值保持 4 px／58%／3 px，均可单独恢复当前风格的参数。`render-style-parameters.ts` 集中定义范围、步进与初值，加载和运行时均检查有限数值并限制范围。

`debug-styles.ts` 使用独立的 `wbr.debug.scene-parameters.v1` 按场景保存参数；保留原有风格选择存储格式，存储被禁止时仍能现场调整。参数变化沿既有 `invalidate` 请求新帧，不重置仪式进度；调整网点只更新 uniform，调整像素尺寸只按需重设已有目标。切换风格会保留调试参数，“恢复内容默认”仍回到 `toon-soft`。普通生产模式不启用调试参数，内容包、用户存档和来源字段保持。
