# 蓝珠祈安

ID/引擎：`turkish-nazar-bead` / `turkish-nazar-bead@1`。来源：`turkish-nazar-bead`；C级、低敏感、drag。

在土耳其公开护眼珠使用背景下，寄托日常避厄护佑的心意。备好的蓝玻璃扁圆珠有白/浅蓝/黑眼形与真实上孔，原创刚性金属挂环穿过珠孔；放在陶托上，整体提起，移到侧立木架，再让挂环落在横轴上悬稳。

1. 按住蓝珠向上短拖，从陶托提起。
2. 向右短拖，把挂环移到木架横轴上方。
3. 向下短拖，让挂环落稳，珠体悬起。

真实第一不透明命中、可取消的方向拖动，落定后上报进度。44px按钮支持键盘，减少动态直接落位；未完成拖动在失焦、取消或停用时回到当前检查点；已接受的动画暂停时冻结，恢复后继续落位。静默恢复不保存或重放反馈；无愿望表单。模型与材质引用不在逐帧更换。

玻璃眼形、配色、悬孔与护佑背景有直接正文；本场具体尺寸/比例/金属挂环与木架/陶托/三拖/方向/时长/声音/庭院/结束语属于产品。不是制珠教学、完整宗教礼法或某件馆藏复刻，也不保证护佑实现。物类跨多国使用，不能说成土耳其独有或统一伊斯兰教义。
