# 地区树形调试预览实现

本文保留初版交付快照。用户随后选择所有特色树形使用 Just a simple tree，外部樱花已退出选择及离线打包；当前实现见[同库特色树形更新](2026-11-05-simple-tree-specialties.md)。下文初版署名 UI、单个樱花文件和十一份 GLB 的描述不再代表当前实现。

日期：2026-11-05。用户要求樱花、柏树等树形并按场景地区匹配，随后明确选择「先在调试台预览」。正式默认不变。

## 实现与事实范围

- 原有来源档位继续保留；新增「按场景推荐」、樱花树（春景）、柱形柏树、垂柳、层叠针叶树。未知／受限场景推荐为保留原景，用户仍能手选任一已安装树形。
- `tree-models.ts` 解析实际资源路径，`tree-profiles.ts` 只记录九个明确场景 ID，不按国家前缀推断。场地、季节、传统器物与美术选择分别核对，完整已读正文／访问失败／支持范围在[证据记录](2026-11-05-regional-tree-evidence.md)。
- 岐阜纸伞及四个通用寺社场景可试春樱；厄尔士山胡桃夹子试层叠针叶；北京空竹试垂柳；那不勒斯角符及瓦伦西亚折扇试柱形柏。这是园林配景的产品选择，不是这些仪式的用树规则，也不宣称某树是整个国家最具代表性或最美的树。
- 正月、特定梅花、草原、季节冲突及没有充分对应证据的场景保留原景。前景菩提树、许愿树等主题器物不参与替换；不改来源 slug、文化分类、引擎、技术 ID 或存档。九个受影响场景 README 已同步调试美术说明；来源卡既有事实与 metadata 无新增文化主张，不重复改写。

## 真实素材与授权

- [Just a simple tree](../../assets/environments/trees/simple-tree/README.md)：同一固定 MIT 提交的真实 cypress、willow 和 pine CPU 几何路径，新增六个 GLB；保留原有两个橡树的字节。cypress 源码描述意大利柱形柏；pine 实际为 fir-like 层叠针叶形，界面没有把它误称日本松或具体松属树种。
- 柱形柏经实际背景距离检查，使用源码已有参数扩大叶冠、增加重叠，可见宽高比约为0.29／0.32，并单独记录产品深绿配色，避免明亮草地前过细、过浅。最终两棵为6,878／7,882三角形；不改变其他六棵 MIT 树的字节，也不将改色说成某地区的真实植物品种鉴定。
- [Quaternius 免费 Standard](../../assets/environments/trees/quaternius/README.md)：逐项核对固定 ZIP 的459条记录，只有 Common／Dead／Pine／Twisted 树族，没有樱花、白桦、棕榈或柏。保留已有两个模型，不能根据完整付费包宣传虚构免费素材。
- [Jogoss Sakura Tree 01](../../assets/environments/trees/regional/README.md)：实际樱花整树，7,007三角、683,924字节，原始枝干／花卡几何、法线、UV保留，嵌入纹理缩小，花材质从 BLEND 改为双面 MASK0.3。原作者 API、原许可、固定镜像提交、原件哈希与改动记录均留存。CC BY4.0，调试台展示作者／原作／许可和已适配说明；加载别的树期间，只要樱花仍可见就保留署名。

共十一份可选 GLB及许可随 Web/Expo 离线打包，无新 npm依赖或购买。共享单个樱花文件的两种放置变体只加载一次；异步竞争与逐项释放沿用原实现。暂停、减动态和场景截图不推进风。

## 调试与正式分享隔离

正式截图只在编码期间临时恢复原有环境树，随后同步恢复并重绘当前调试预览。不会改变调试选择、进度或正式偏好，也不会把未附署名的樱花调试模型带入正式分享图片。普通调试截图中的素材署名可通过控制台和打包通知查看；正式发布与授权范围依据来源文件。

## 验证

- 原始模型检查与三个生成器的确定性 `--check`，核对真实来源、许可、哈希、几何、纹理和重新导入；两宿主资源复制／自包含 GLB 的4项检查通过。最终精修的两个柱形柏在源文件、Web public及Expo public之间再次比对SHA-256完全一致。
- scene-runtime 全部274项，调试 UI与正式分享图片相关7项、纸伞／胡桃夹子／空竹等相关场景202项通过。
- Web构建、八语言完整性／ICU／自审记录／编译检查、158场景版本检查通过；文案自审不声称母语认证。
- `scripts/verify-tree-debug.mjs` 的实际 App 日夜切换、九个推荐、正月保留原景、署名／适配通知链接、同一画布、无存储写入与正式截图隔离通过。六种来源／树形 ×17种视觉风格共102组合无shader错误；无运行时外部资源请求。四轮替换恢复后GPU计数稳定为2geometry／5textures（含预热style资源），没有随轮数增长。
- 报告与截图在 `artifacts/tree-debug/`。这是 Chromium／WebGL 与移动尺寸布局验证，尚未做 iOS／Android真机帧率或正式发布。
