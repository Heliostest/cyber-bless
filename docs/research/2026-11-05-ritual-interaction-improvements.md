# 小物与仪式：连续把玩、悬挂后欣赏和自主收尾

日期：2026-11-05。用户在风铃增加把玩／悬挂之后，要求落实本次交互抽查提出的全部改进。

## 范围与实际呈现

| 场景 | 当前产品体验 |
| --- | --- |
| `paper-pinwheel` 纸翼转风 | 托起木柄，反复拨动纸翼；转角与转速跟随手势，松手后减速，可继续续转；主动移回原位或用辅助按钮放回才完成 |
| `uchide-wishing-mallet` 振槌寄愿 | 从木托提起，槌身与绳穗随连续手势运动，可反复轻摇；向下送回木托或用辅助按钮放回才完成 |
| `turkish-nazar-bead` 蓝珠祈安 | 拿近转看后挂到现有木架；挂稳记录 2，仍可轻拨摆动或微调朝向，选「结束欣赏」才完成为 3 |
| `romanian-martisor` 红白寄春 | 拿近转看后把绳环挂到原有花枝；挂稳后仍可轻拨／转看流苏，选「结束欣赏」才完成 |
| `spanish-castanets` 木壳轻拍 | 先熟悉左、右两副木壳，再自由轻点或下压松开，左右可快速交替；碰合时反馈，回弹不锁下一次输入，主动结束才完成 |

共用 `close-inspection.ts` 改为默认等待「继续安放」。首次约 6 秒的自动环绕结束后，近景仍保留；手动转看可随时接管，减少动态时静止查看。自动返回仅能由显式选项开启，目前这批场景均不启用。

受该共用行为影响的 15 场：`alasita-miniature-house`、`brat-bride-cloth`、`chinese-fu-paper`、`chinese-longevity-lock`、`chinese-ruyi-scepter`、`japanese-hamaya`、`japanese-kadomatsu`、`korean-sotdae`、`lanna-sand-pagoda`、`mochigase-nagashibina`、`pucara-rooftop-bulls`、`romanian-martisor`、`scottish-first-footing`、`shichigosan-chitose-ame`、`turkish-nazar-bead`。其中两场与重点改进重叠，本次共影响 18 场。风铃上一轮已使用手动继续，本次保留。

## 存档与生命周期

- 五个重点场景继续保存 0..3：准备、拿起／基础操作、可持续把玩、主动完成。旧完成值 3 静默恢复，不重播、不重新奖励。
- 两个挂件的 2 现在表示挂稳后可欣赏。旧的部分进度 2 恢复为同一挂架／花枝上的挂稳姿态，可以继续把玩或主动结束；旧 0／1 仍能继续拿近及安放。没有把旧完成记录改回未完成。
- 两个玩具拿起后可以直接放回，不强迫先重复若干次；已操作后继续把玩不重复提交进度。放回动作与最后一次拨动分开，减少误触收尾。
- 暂停、失焦、第二指针、取消、尺寸变化和销毁按所在阶段恢复或停止未提交操作；回调中暂停／销毁后停止后续进度和反馈。
- 物件动作、完成事件与辅助按钮支持减少动态。静音仅控制声音，触感保留独立设置的原有契约。

八语言说明同步当前产品操作；原事实段落保留，仅替换已过时的操作尾段。公共界面自然描述动作，研发归属记录保存在本记录和来源卡中。
