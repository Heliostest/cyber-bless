# 奥兰群岛教堂船模

## 文化与器物

- 奥兰伦帕兰堂区的圣安德烈教堂保存捐赠船模。
- 克卡尔市镇记述圣安娜教堂木船模型，并把它与当地海上遭遇传说联系；教堂船各有献置背景。

## 场景对应与范围

场景以拼接桅杆、安放船模及可选感谢留言欣赏海洋记忆，不模拟真实教堂捐献。各地船模献置背景不同，不能把所有船模一概解释为遇险获救后的还愿。

对应场景：`aland-votive-ship`。

## 2026-10-20 当前介绍核查

当前可支持范围：芬兰奥兰伦帕兰教堂1836年船模、1837年商人捐赠；克卡尔教堂船模及1733年海盗遭遇的地方叙事。年代分别属于器物/捐赠和传说中的事件。

实际呈现：原创木船模、帆桅、黄铜桅座与船架；插桅杆→整船放架→静看/可选感谢。

边界与缺口：没有证实所有教堂船都为海难脱险还愿；组装、桌面安放、留言均非已证实献置程序。旧 UI returning 的“向海上谢恩传统致意”由主代理本轮改为“记录航海记忆的小景”，撤回无据泛化。教堂页网页工具超时，改以同 URL 的 HTTP 200 实际正文读取，未引用失败索引日期。
