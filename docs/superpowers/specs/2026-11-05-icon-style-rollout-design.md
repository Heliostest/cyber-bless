# 小物向图标风格靠拢

用户已确认四件可操作样例，并明确要求继续改进各个小物。沿用该方向，正式接入所有场景共用的 `toon-soft` 默认呈现，不再停留在试做宿主。

目标是保留材料身份、器形、文字与操作，让小物有连续柔和体积、温润颜色、宽柔反射与细微手作表面。当前 91 个可见场景逐场查看实际前后画面；67 个保留场景接受同一渲染通路的兼容检查。

选择：在现有材质适配器中为 soft 使用 Standard/Physical 连续明暗、保留 craft/optics/法线和源纹理，并降低描边。按每张图标的色彩锚点，在保持原色相的前提下限幅轻调明度/饱和度；带贴图、顶点色、黑白文字和低饱和面不自动改色。四件已选样例采用明确的器物/部件校准，其中守袋体积一次性接入原几何。

比较过的方案：直接复用试做页整套覆盖渲染会绕过用户风格设置、夜景与后处理；逐场替换为新 GLB 会扩大造型和文化核查范围。共用适配器方案覆盖现有小物、保持其他预设和源资源所有权，也可保留每件真实区别。

约束：不新增材质身份、木种、织法、合金、纹样、宗教/民俗事实或步骤；图标仅为产品美术参照。来源、ID、引擎版本、记录兼容保持；有变化的是产品显示，按现行 provenance 规范记录实际支持范围。原图、墨线及其他预设仍按原规则工作。纸/布透光、玻璃/水、火光与动态反馈保留，不能冻结动画颜色或把夜景照成白天。

性能：沿用现有 HDR 与 composer，不为每件小物增加反射场景、独立动画循环或新渲染目标。派生材质只在源变化时生成，每帧同步动态属性，异常时精确恢复源状态并释放自有资源。

验收：有对应图标的全部 158 项色彩数据存在；91 个当前小物实际前后画面及 67 项兼容渲染；木/纸/布/陶/金属/玻璃/有机物和白天/夜晚、320/390px 代表检查；实际交互、风格切换/恢复/退出；相关与全套测试、正式构建、修订检查。技术与文化审阅分别报告。
